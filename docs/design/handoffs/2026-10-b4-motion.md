# Handoff — движение в интерфейсе (B-4)

Единый язык движения Duplexn't и его применение к пяти местам из `briefs/motion.md`
(карточка B-4): смена экранов, лента последних страниц на `scan`, поворот миниатюры и превью
в `editor`, модалки (открытие, закрытие, высота при смене содержимого) и тост, подсказка про
Ctrl/Shift в инспекторе. Варианты смены экранов и поворота выбраны автором на странице
вариантов (`mock/variants.html`): **1a — растворение**, **2a — лист поворачивается целиком**.
Утверждён в моке 2026-10-26 (`mock/index.html`).

Язык движения в одной фразе: **приходящее проявляется и встаёт на место кривой
`--ease-out`, уходящее гаснет быстрее, чем пришло, ничего не ждёт конца анимации.** Три
длительности: 120 мс — уход, 180 мс — приход, 240 мс — поворот листа; плюс существующие
150 мс (микропереходы) и 200 мс (высота модалки).

Общие правила для всех пяти мест:

1. **Не блокирует.** Действие выполняется в момент нажатия; анимация — только показ.
   Повторное действие во время анимации продолжает движение с текущего положения, а не с
   конечного и не с начала.
2. **Не копится.** У элемента одновременно идёт одна анимация данного вида: новая
   отменяет предыдущую, сняв с неё текущее положение (FLIP от фактического вида).
3. **Конечное состояние — классами, движение — поверх.** Классы и раскладка ставятся сразу,
   как сейчас; анимация — Web Animations API (`element.animate`) от прежнего вида к новому.
   Без анимации интерфейс в каждом кадре такой же, как сейчас.
4. **`prefers-reduced-motion: reduce`** — ничего не едет, не крутится и не мигает. Остаётся
   только проявление `--duration-exit` (120 мс) там, где иначе была бы вспышка (экран,
   модалка, тост, новое содержимое модалки), остальное — мгновенно.

Отменяется конвенция «модалки, плашки, тосты — без анимации» (`handoffs/2026-10-m3-states.md`,

## Anatomy

Разметка экранов, ленты, превью, модалок и тоста **не меняется**. Новое — два модификатора:

```html
<!-- подсказка: на время привлечения внимания -->
<p class="inspector__note inspector__note--attention">
  Границы не отмечены: всё сохранится одним файлом. Чтобы разделить, наведите курсор на верх
  миниатюры и нажмите «+ Новый документ» — или выделите страницы подряд (Shift — диапазон, Ctrl — по
  одной) и нажмите «Выделить в документ».
</p>

<!-- под reduced-motion вместо мигания — ровная подсветка -->
<p class="inspector__note inspector__note--attention-static">…</p>

<!-- лента scan: выталкиваемая карточка на время ухода -->
<li class="strip__card strip__card--leaving" style="left: 0px; top: 2px">…</li>
```

На время смены экранов уходящий экран остаётся в DOM под новым с атрибутом `inert` и снимается
по окончании растворения:

```html
<div class="app">
  <main class="setup-screen" inert>…</main>
  <!-- уходит: под новым, ввод не принимает -->
  <main class="scan-screen" tabindex="-1">…</main>
  <!-- приходит: поверх, opacity 0 → 1 -->
</div>
```

## Tokens

Новые — заносятся в `DESIGN_SYSTEM.md` → «Движение» и в `tokens.css`.

| Токен                    | Значение                     | Для чего                                                                                                  |
| ------------------------ | ---------------------------- | --------------------------------------------------------------------------------------------------------- |
| `--duration-exit`        | `120ms`                      | Уход: закрытие модалки, гашение тоста, выталкивание карточки ленты; проявление под reduced-motion         |
| `--duration-screen`      | `180ms`                      | Приход: смена экрана, появление модалки и тоста, появление и сдвиг карточек ленты `scan`                  |
| `--duration-turn`        | `240ms`                      | Поворот миниатюры и превью на 90° / 180°                                                                  |
| `--ease-out`             | `cubic-bezier(0.2, 0, 0, 1)` | Всё, что приходит и встаёт на место: подъём модалки и тоста, въезд и сдвиг ленты, поворот, высота модалки |
| `--distance-rise`        | `6px`                        | Подъём появляющейся модалки и тоста                                                                       |
| `--distance-enter`       | `12px`                       | Въезд новой карточки в ленту `scan`, уход выталкиваемой                                                   |
| `--iterations-attention` | `3`                          | Сколько раз мигает подсказка «обратить внимание»                                                          |
| `--color-bg-attention`   | `var(--color-bg-paper)`      | Подсветка подсказки на панели инспектора                                                                  |

Используются существующие: `--duration-fast` (150 мс — затемнение модалки, проявление нового
содержимого), `--duration-base` (200 мс — высота модалки; прежнее назначение «поворот превью»
снимается — поворот теперь `--duration-turn`), `--duration-loop` (1200 мс — один такт мигания),
`--duration-loop-long` (3800 мс — ровная подсветка под reduced-motion), `--ease-standard`,
`--ease-loop`.

## CSS

```css
/* — app.css: смена экранов — два экрана в одном контейнере на время перехода — */
.app {
  position: relative; /* + к существующему */
}

.app > main[inert] {
  position: absolute;
  inset: 0;
}

/* — scan-screen.css: шаги затухания ленты проявляются, а не перескакивают — */
.strip {
  position: relative; /* + к существующему: опора для выталкиваемой карточки */
}

.strip__card {
  transition: opacity var(--duration-screen) var(--ease-standard); /* + к существующему */
}

.strip__card--leaving {
  position: absolute;
  margin: 0;
  pointer-events: none;
}

/* — editor-screen.css: подсказка «обратить внимание» — */
.inspector__note--attention {
  border-radius: var(--radius-s);
  animation: attention var(--duration-loop) var(--ease-loop) var(--iterations-attention);
}

.inspector__note--attention-static {
  border-radius: var(--radius-s);
  background: var(--color-bg-attention);
  box-shadow: 0 0 0 var(--space-3) var(--color-bg-attention);
  color: var(--color-text-primary);
}

@keyframes attention {
  0%,
  100% {
    background: transparent;
    box-shadow: 0 0 0 var(--space-3) transparent;
  }

  50% {
    background: var(--color-bg-attention);
    box-shadow: 0 0 0 var(--space-3) var(--color-bg-attention);
    color: var(--color-text-primary);
  }
}

@media (prefers-reduced-motion: reduce) {
  .strip__card {
    transition: none;
  }

  .inspector__note--attention {
    animation: none;
  }
}
```

`box-shadow` того же цвета даёт подсветке поля в `--space-3` без сдвига текста — геометрия
строки не меняется (принцип 5: «hover не меняет геометрию» распространяем на внимание).

Остальное движение — WAAPI в компонентах, кадры ниже в «Behaviour». CSS-переходы на
`transform` у `.thumb__img` и `.preview__paper` **не заводить**: поворот через `transition`
снова крутил бы 270° → 0° назад.

| Подсказка: покой           | все остальные показы                           | как сейчас                                                                                   |

## Behaviour

### 1. Смена экранов — растворение (1a)

- Новый экран монтируется **поверх** прежнего и проявляется: `opacity 0 → 1`,
  `--duration-screen` (180 мс), `--ease-standard`. Прежний под ним не меняется (непрозрачный
  фон экранов одинаков — провала яркости нет), получает `inert` и снимается по окончании.
- Направления нет: вперёд по процессу, «Остановить», «Новое сканирование», «+ Добавить» —
  одинаково. Отклонено: сдвиг по направлению процесса (1b) и каскад блоков в неподвижном окне
  (1c) — выбор автора.
- Не растягивает паузы: пауза 520 мс после последней страницы и пауза `merge` (1600 /
  1200 мс, ожидание оценок) отсчитываются как сейчас; растворение накладывается на начало
  нового экрана. Кнопки нового экрана работают с первого кадра; фокус — как сейчас, на новый
  экран сразу.
- Новая смена во время перехода: текущее растворение доводится мгновенно (`finish()`),
  прежний экран снимается, начинается новое. Двух уходящих экранов не бывает.
- Модалка, открытая поверх экрана, уходит вместе с ним (она его потомок).
- Reduced-motion: то же проявление за `--duration-exit` (120 мс) — короткий fade вместо
  вспышки.

### 2. Лента последних страниц на `scan`

- Приход страницы (раз в ~300 мс) — FLIP:
  1. Запомнить фактическую позицию каждой карточки: `offsetLeft` + текущий `translateX`
     незаконченной анимации (из `getComputedStyle(card).transform`).
  2. Отменить идущие анимации карточек, снять с DOM уходящую, если она ещё гаснет.
  3. Если карточек уже пять — первую пометить `strip__card--leaving`, поставить ей `left/top`
     её фактической позиции (выходит из потока, остальные смыкаются).
  4. Добавить новую (`strip__card--loading` со скелетоном — как сейчас).
  5. Новая: `opacity 0, translateX(12px) → 1, none`, `--duration-screen`, `--ease-out`.
     Остальные: `translateX(было − стало) → none`, те же 180 мс и кривая. Уходящая:
     `opacity .32, none → 0, translateX(−12px)`, `--duration-exit`, `--ease-standard`, затем
     удаляется.
- 180 мс меньше интервала прихода (300 мс): при обычном темпе анимация успевает закончиться;
  при пачке страниц подряд каждая следующая продолжает сдвиг с текущего положения — очереди
  нет, лента не отстаёт.
- Шаги затухания (1 → .83 → .66 → .49 → .32, `nth-last-child`) меняются переходом `opacity`
  за `--duration-screen` — карточка не мигает при смене шага.
- Скелетон → картинка — без изменений (`--duration-fast`).
- Reduced-motion: сдвига и въезда нет; новая карточка проявляется за 120 мс, выталкиваемая
  снимается сразу, шаги затухания — без перехода.

### 3. Поворот миниатюры и превью — лист целиком (2a)

- Данные — как сейчас: угол в журнале по модулю 360, конечный вид — классы
  `thumb--angle-{90,180,270}`, `preview__paper--angle-*`, `preview__paper--landscape`.
- **Анимация знает команду, а не углы.** Дельта команды: ↻ `+90`, ↺ `−90`, тумблер 180°
  включили — `+180`, выключили — `−180`. Анимация всегда идёт на дельту, поэтому 270° → 0°
  по ↻ — четверть оборота по часовой, а не три четверти назад.
- Миниатюра (`.thumb__img`): новые классы ставятся сразу; поверх — `animate` от
  `rotate(новый + остаток − дельта) scale(прежний масштаб)` к `rotate(новый) scale(новый
масштаб)`; масштаб — `1` или `0.7071` (как в классах). `--duration-turn`, `--ease-out`.
  Рамка карточки остаётся портретной, сетка не прыгает — как сейчас.
- Превью (`.preview__paper`) поворачивается **целиком** — рамка, тень, кромка начала
  документа и изображение вместе: до смены классов запомнить длинную сторону листа, сменить
  классы, взять новую длинную сторону; `animate` от `rotate(остаток − дельта) scale(было /
стало)` к `none`, те же 240 мс и кривая. Лист в руке поворачивается и одновременно
  доводится до альбомного (или портретного) размера.
- Остаток: если предыдущий поворот ещё идёт — снять его прогресс `p`
  (`effect.getComputedTiming().progress`), остаток = `начальный_поворот × (1 − p)`, отменить
  и начать новый от остатка. Быстрые ↻↻↻↻ — одно непрерывное вращение по часовой.
- Выделение из нескольких: каждая выделенная миниатюра поворачивается своей анимацией
  одновременно; превью — если текущая страница в выделении. Тумблер 180° — все обороты пачки
  текущей страницы (как сейчас по данным).
- Смена текущей страницы отменяет анимацию превью (новая страница показывается сразу).
- Undo / Redo поворота — без анимации: это откат, а не команда.
- Reduced-motion: без анимации, классы мгновенно — как сейчас.

### 4. Модалки и тост

- **Открытие:** `.modal-overlay` `opacity 0 → 1` за `--duration-fast` (150 мс),
  `--ease-standard`; `.modal` `opacity 0, translateY(6px) → 1, none` за `--duration-screen`
  (180 мс), `--ease-out`. Фокус переводится сразу, как сейчас.
- **Замена** (модалка открывает модалку — «Сначала сохранить текущий» в `newscan`):
  затемнение не гаснет и не проявляется заново, поднимается только новое окно.
- **Закрытие:** ввод снимается сразу (`pointer-events: none` на затемнении, фокус —
  на место, как сейчас); затемнение вместе с окном гаснут за `--duration-exit` (120 мс),
  затем модалка размонтируется. Escape — как сейчас (во время записи не закрывает).
- **Высота при смене содержимого** — общий приём для `.modal`: замерить `offsetHeight` до,
  применить новое содержимое, замерить после; если разница больше 1 px —
  `animate({ height: [h0, h1] })` за `--duration-base` (200 мс), `--ease-out`. Новые блоки
  (секция ИТОГ, строки файлов) проявляются `opacity 0 → 1` за `--duration-fast` с задержкой
  50 мс. Новая смена во время анимации — отменить и мерить от текущей высоты. Ограничение
  `max-height: calc(100% − 60px)` остаётся: упёрлась — тело прокручивается, как сейчас.
- В `save` это: «Отдельные файлы» ↔ «Один файл» (меняется число строк); «Сохраняем…» →
  ИТОГ (появляется секция ИТОГ — UI_SPEC §7.3, разметка — `handoffs/2026-10-m3-states.md`,
  S16); ИТОГ → «Повторить неудавшиеся» → закрытие. После появления ИТОГа тело прокручивается
  к нему, если не помещается.
- **Тост:** появление `opacity 0, translateX(−50%) translateY(6px) → 1, translateX(−50%)` за
  180 мс, `--ease-out`; гашение по таймеру или кнопкой — `opacity → 0` за 120 мс. Новый тост
  вытесняет прежний **сразу**, без анимации ухода (правило «новый гасит предыдущий»). Время
  показа (2,6 / 3,6 / 6 с) — как сейчас, от начала появления.
- Reduced-motion: открытие, закрытие и тост — только проявление / гашение за 120 мс без
  подъёма; высота меняется мгновенно, новое содержимое проявляется за 120 мс.

### 5. Подсказка про Ctrl/Shift

- **Когда:** первый раз, когда человек видит в инспекторе `editor` блок «ДОКУМЕНТЫ В НАБОРЕ»
  с подсказкой `inspector.docsNoteOne` (границы не отмечены). Один раз на установку: флаг в
  настройках (предложение — `hints.docsSplitSeen`) ставится **в момент показа**, а не по
  окончании мигания — закрыли окно на середине, всё равно больше не мигнёт.
- **Как:** через 580 мс после появления `editor` (180 мс растворения + 400 мс, чтобы глаз
  успел найти экран) на строку ставится `inspector__note--attention`: три такта по
  `--duration-loop` (1200 мс, `--ease-loop`) — фон `--color-bg-attention` (бумага) на панели
  инспектора и текст до `--color-text-primary` в середине такта. Всего 3,6 с; по
  `animationend` модификатор снимается. Это тот же темп, что `pulse`, — тихо, без цвета
  тревоги (не янтарь, не акцент).
- **Раньше времени гаснет**, если человек уже занялся границами или прочёл: `pointerdown` в
  ленте или наведение на подсказку — модификатор снимается сразу.
- Не повторяется: при следующих показах блока — покой. Подсказка про «+ Добавить» в
  ПРОВЕРКЕ и другие строки так не мигают.
- Reduced-motion: без мигания — `inspector__note--attention-static`, ровная подсветка на
  `--duration-loop-long` (3,8 с), затем гаснет за 120 мс (фон → прозрачный). Те же условия
  снятия.
- Доступность: подсказка — обычный текст, не `role="status"`; подсветка — только визуальная.

## Decisions and open questions

- **Решено: смена экранов — растворение 180 мс** (1a). Отклонено: сдвиг по направлению
  процесса (1b) и каскад содержимого в неподвижном окне (1c) — выбор автора на странице
  вариантов.
- **Решено: поворот — лист целиком** (2a), 240 мс. Отклонено: изображение в
  перестраивающейся рамке (2b) и «кивок» без полного вращения (2c).
- **Решено: поворот через дельту команды, а не через углы.** Данные по модулю 360 не
  трогаем; анимация — FLIP от прежнего вида с дельтой ±90 / ±180. Отклонено: накопленный
  «экранный» угол без модуля — второй источник правды об угле.
- **Решено: кромка начала документа поворачивается вместе с листом** и встаёт наверх только в
  конце поворота — она часть листа (решение автора).
- **Решено: тумблер 180° выключили — поворот −180°**, обратно тем же путём.
- **Решено: подсказка мигает 3 раза по 1,2 с**, гаснет по первому взаимодействию с лентой
  или наведению; флаг — в момент показа.
- **Решено: модалки и тост получают движение** в той же системе (отменяет конвенцию
  исходного макета). Вытесненный тост — без анимации ухода.
- **Решено: undo / redo поворота — без анимации.**
- **Открыто:** `--duration-base` остаётся только для высоты модалки — возможно, стоит
  переименовать при следующей чистке токенов.
