# Handoff: значок приложения Duplexn't (монограмма D’)

> **В репозитории (B-7):** мастера — `build/icon.svg` и `build/icon-small.svg` (байт в байт из
> handoff'а); `build/icon.ico` генерирует `npm run icons` (`scripts/build-icons.ts`) — вместо
> справочного `build-icons.mjs` ниже. MSIX-ассеты не генерируются: приложение ставится NSIS.
> Превью размеров — `app-icon-preview.html` рядом. Журнал — `docs/solutions/0012-b-7-app-icon.md`.

## Overview

Значок Windows-приложения Duplexn't (двустороннее сканирование на сканере с односторонним автоподатчиком). Выбран вариант **«Монограмма D’»**: светлая буква D и янтарный апостроф (из «n't») на чернильной плитке со скруглёнными углами. Задача — внедрить значок везде, где его показывает Windows: exe/ярлык, панель задач, Alt+Tab, заголовок окна, «Пуск», установщик, при необходимости MSIX-пакет.

## About the Design Files

Файлы пакета — дизайн-референсы, но SVG-мастера здесь **финальные** и служат источником для генерации растров. `preview.html` и `build-icons.mjs` — справочные: растры и .ico сгенерировать инструментом, принятым в проекте, и подключить средствами сборки приложения (Electron / Tauri / WinUI / WPF и т.п.).

## Fidelity

**High-fidelity.** Геометрия, цвета, пропорции финальные. Не перерисовывать и не заменять букву шрифтом — D задана контуром.

## Мастер-файлы

Оба SVG на сетке 64×64 (1 ед. = 4 px при 256 px).

### `icon.svg` — размеры ≥ 32 px

- Плитка: `rect x=4 y=4 w=56 h=56 rx=13`, `#1c1a16`. Прозрачное поле 4 ед. (~6%) — по сетке значков Windows 11.
- Внутренний блик: обводка 1 ед. `#ffffff` @ opacity .12 — отделяет плитку от тёмной панели задач (`#202020`).
- Буква D: `M13 16H25a16 16 0 0 1 0 32H13Z` минус счётчик `M20 23H25a9 9 0 0 1 0 18H20Z` (evenodd), штрих 7 ед., `#fbfaf7`.
- Апостроф: `rect x=44 y=16 w=6 h=13 rx=3`, `#a06a2a`; верх совпадает с верхом D.
- Оптический центр композиции x ≈ 31.5.

### `icon-small.svg` — 16, 20, 24 px

Оптическая коррекция:

- Плитка почти в край: `x=1 y=1 w=62 h=62 rx=10`; блик убран.
- D толще: штрих 9 ед. (~2.25 px на 16 px), контур `M10 14H22a18 18 0 0 1 0 36H10Z`, счётчик `M19 23H22a9 9 0 0 1 0 18H19Z`.
- Апостроф крупнее: `rect x=44 y=14 w=8 h=16 rx=4`.

**Правило:** ≤ 24 px растрировать только из `icon-small.svg`, ≥ 32 px — из `icon.svg`.

## Цвета

- Плитка `#1c1a16` — `--color-ink-900`
- Буква `#fbfaf7` — `--color-sand-25`
- Апостроф `#a06a2a` — `--color-amber-600`
- Блик плитки `#ffffff` @ 12%

## Требуемые выходные файлы

1. **`app.ico`** — мультиразмерный: 16, 20, 24, 32, 40, 48, 64, 96, 256 (32-bit RGBA; 256 — PNG внутри ICO). Для exe-ресурса, ярлыков, заголовка окна, установщика.
2. **PNG** 16–512 — для фреймворков, требующих PNG.
3. **MSIX/WinUI** (если приложение пакетируется), `Assets/`:
   - `Square44x44Logo.scale-100/200.png` (44 / 88)
   - `Square44x44Logo.targetsize-{16,24,32,48,256}.png` **и** `…_altform-unplated.png` — без unplated Windows подложит акцентный цвет под значок на панели задач.
   - `Square150x150Logo.scale-100/200.png` (150 / 300), `StoreLogo.scale-100/200.png` (50 / 100).
   - В манифесте `BackgroundColor="transparent"`.

## Интеграция (выбрать по стеку)

- **Electron**: electron-builder `win.icon = "build/icons/app.ico"`; `new BrowserWindow({ icon })`.
- **Tauri**: `npx tauri icon icon.svg`, затем **заменить** 16/24-растры на сгенерированные из `icon-small.svg`; `tauri.conf.json → bundle.icon`.
- **WPF / WinForms**: `<ApplicationIcon>app.ico</ApplicationIcon>` в .csproj; `Window.Icon` — тот же ico.
- **WinUI 3 / MSIX**: Assets из п.3 в `Package.appxmanifest`; `AppWindow.SetIcon("app.ico")` для заголовка.
- **Инсталлятор (NSIS / Inno / WiX)**: тот же `app.ico`.

## Проверка

- `preview.html` — эталон рендера всех размеров на светлой (`#f3f3f3`) и тёмной (`#202020`) панели.
- После сборки: панель задач в светлой и тёмной теме, Alt+Tab, Explorer «Огромные значки» (256), ярлык на рабочем столе при 100 / 150 / 200 %. Цветной подложки быть не должно (проверка unplated).
- Сбрасывать кэш значков Windows (`ie4uinit.exe -show`), иначе виден старый.
