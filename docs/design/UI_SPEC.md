# Duplexn't — спецификация UI

Поэкранный структурный и поведенческий контракт. Обновляется в той же вехе, что меняет
экран.

**Локаль.** Контракт ведётся на русском — он задаёт раскладку (русский длиннее). Английская
локаль (B-41) обязана укладываться в те же места; копия здесь не дублируется, строки обеих
локалей — `locales/ru/common.json` и `locales/en/common.json`, английская проходит ревью
дизайн-агента по референсу `reference/` (сцены на обоих языках).

**Происхождение.** Составлено разбором макета `archive/Сканер ADF.dc.html` — разметки и класса
поведения в нём. Разбор статический: макет читался, а не запускался, поэтому числа и
переходы взяты из кода, а не с экрана. Визуальный язык — `DESIGN_SYSTEM.md`, здесь его нет.

**Как читать.** Раздел «Строительные леса макета» перечисляет то, что в продукт не едет:
демо-данные, демо-переходы и панель прыжков по экранам. Раздел «Чего в макете нет»
перечисляет дырки, которые придётся закрывать решением, а не чтением макета. Всё остальное —
контракт: так оно спроектировано и так должно работать.

## 1. Общая модель

Одно окно 1280×800, без вкладок. В каждый момент показан **один экран** из пяти: `setup`,
`scan`, `flip`, `merge`, `editor`. Поверх экрана может стоять **одна модалка**: `device` —
над `setup`, остальные (`add`, `save`, `mismatch`, `newscan`) — над `editor`. Модалка
закрывает экран затемнением и перехватывает работу целиком; двух модалок одновременно не
бывает. С M4.5 над `editor` стоит ещё модалка несовпадения набора (раздел 7.6).

Поверх всего — **тост** внизу по центру: одна строка текста, иногда с кнопкой действия.
Тостов тоже не больше одного, новый гасит предыдущий.

`setup`, `flip` и `editor` ждут человека. `scan` и `merge` — процессные: уходят сами,
`merge` вообще без единого органа управления.

**Смена экранов (B-4)** — растворение за 180 мс: новый экран проявляется поверх прежнего и
закрывает его; прежний под ним не принимает ввод и снимается по окончании. Направления нет;
паузы процесса (после прохода, `merge`) не удлиняются. Под `prefers-reduced-motion` — только
короткое проявление (120 мс), без сдвигов и поворотов.

### Граф переходов

```
setup ──«Сканировать лицевые стороны»──→ scan (проход 1)
  └─ нет сканера → модалка device, скан не начинается

scan ──проход дошёл до конца──→ пауза ──→ flip        (после прохода лиц — основных или набора)
  │                                  ├──→ merge       (после прохода оборотов — основных или набора)
  │                                  └──→ editor      (после одностороннего набора, M3.5)
  └──«Остановить»──→ экран, с которого запущен проход (setup · flip · editor)

flip ──«Листы в лотке — сканировать обороты»──→ scan (проход +1)
  └──«Обороты не нужны»──→ editor (без паузы merge — сопоставлять нечего, B-5)

merge ──сама──→ editor (несовпадение набора — модалка набора поверх, M4.5)

editor ──«+ Добавить» → модалка add → «Начать скан»──→ scan (набор: односторонний или лица пары)
  └─ отказ запуска → тост, экран остаётся editor

editor — конечный экран: сохранение, добавление скана, новое сканирование
```

Второго прохода без первого не бывает: `flip` достижим только из завершившегося лицевого
прохода. Односторонний добавленный набор (M3.5) — однопроходный: после него ни `flip`, ни
`merge`, сразу `editor`. Двусторонний набор (M4.5, `handoffs/2026-10-m4-5-states.md`) идёт теми же экранами,
что основной документ, в цвете набора: лица → `flip` набора → обороты → `merge` → `editor`;
`flip` набора выводится из снимка (набор ждёт обороты) с приоритетом над `editor`, поэтому
после перезапуска между проходами открывается он. Роль прохода — поле журнала (лица / обороты /
добавленный набор / лица и обороты набора), а не номер (ADR 0004, амендменты 2026-10-07 и
2026-10-23).

**Временное ребро M1 снято в M2:** `flip` и `merge` рендерятся, полные тексты `setup` и
`scan` возвращены (план M1, KTD-25 → план M2, U8). Экран по-прежнему выводится из снимка
чистой функцией; `merge` — эфемерная пауза поверх этого вывода (план M2, KTD-5). Состояния
сверх макета — `handoffs/2026-10-m1-states.md`, `handoffs/2026-10-m2-states.md`,
`handoffs/2026-10-m3-states.md`, `handoffs/2026-10-m3-5-states.md`,
`handoffs/2026-10-m3-6-states.md`, `handoffs/2026-10-m4-states.md` и
`handoffs/2026-10-m4-5-states.md`.

## 2. Экран `setup` — настройка и запуск

### Раскладка

Две колонки. Слева сверху вниз: кикер «НОВЫЙ ДОКУМЕНТ», заголовок «Сканируем обе стороны в
два прохода», лид с объяснением сценария, группа параметров, кнопка запуска. Справа — узкая
колонка «КАК ЭТО РАБОТАЕТ» с четырьмя пронумерованными шагами; в её нижнем углу, под
волосяной чертой, — **переключатель языка** (B-41; handoff `handoffs/2026-11-b41-language.md`):
кикер «ЯЗЫК» и две текстовые опции «Русский» / «English», каждая на своём языке и не
переводится. Виден всегда, при любом состоянии сканера; «Сбросить параметры» его не трогает.
Выбор пишется в настройки, потом экран перерисовывается на новом языке на месте, без
перезапуска и подтверждения; пока идёт запись, клики игнорируются; отказ записи — тост
«Не удалось сохранить язык — попробуйте ещё раз» на прежнем языке, выделение прежнее. После
явного выбора язык Windows при старте не учитывается. Клавиатура: опции в порядке Tab
последними на экране, Enter / Space выбирают, фокус после смены остаётся на выбранной.

### Строка устройства

Первая строка группы параметров, два состояния:

- **подключено** — имя устройства, точка статуса с подписью «готов» или «занят», справа
  текстовая кнопка «Сменить» (открывает модалку `device`);
- **не подключено** — «Сканер не подключён» и первичная кнопка «+ Добавить сканер».

### Параметры

Пять строк, каждая — подпись слева и ряд сегментов справа. У сегментов есть подсказки в
`title`.

| Параметр       | Значения                        | Подсказки                                                                                    |
| -------------- | ------------------------------- | -------------------------------------------------------------------------------------------- |
| Цвет           | Ч/б · Оттенки серого · Цвет     | —                                                                                            |
| Разрешение     | 200 dpi · 300 dpi · 600 dpi     | быстрее, мельче файл · обычный текст · мелкий шрифт и печати                                 |
| Размер листа   | A4 · Letter · Авто              | 210×297 мм · 216×279 мм · определять по листу                                                |
| Пустые обороты | Скрывать · Помечать · Оставлять | не попадут в файл · останутся, но с меткой · сохранить всё как есть                          |
| Выравнивание   | Выравнивать · Не трогать        | страницы, отсканированные с искажением, будут выпрямлены · страницы останутся как со сканера |

По умолчанию: оттенки серого, 300 dpi, A4, пустые обороты скрывать, выравнивать. Внизу группы —
текстовая кнопка «Сбросить параметры», возвращающая эти значения.

Списки значений в макете заданы константами. Цвет, разрешение и размер листа с M1 строятся
из `capabilities` устройства и меняются при смене источника — см. «Расхождения с техбазой».
Ряд «Пустые обороты» (M4) — другого рода: это настройка приложения, а не возможность
устройства (ADR 0004, амендмент 2026-10-22), значения — словарь приложения, ряд доступен и
без подключённого сканера. «Сбросить параметры» возвращает и его — к «Скрывать». Выбранный
режим замораживается в сессии при старте первого прохода и в редакторе не меняется (раздел
6.9). Ряд «Выравнивание» (M6, `handoffs/2026-10-m6-straighten.md`) — того же рода: настройка
приложения, доступна без сканера, «Сбросить параметры» возвращает «Выравнивать»; подсказки
сегментов договаривают, что режим запоминается при запуске сканирования и новый выбор
подействует со следующего (раздел 6.10).

### Запуск

Первичная кнопка «Сканировать лицевые стороны», под ней подсказка «Загрузите пачку лицом
вверх, первая страница сверху».

**Гейтинг:** если сканер не подключён, нажатие не запускает скан, а открывает модалку
`device`. Кнопка при этом не выглядит заблокированной — решение спорное, но так
спроектировано.

## 3. Экран `scan` — идёт проход

### Раскладка

По центру сверху вниз: тег прохода, иллюстрация подачи, счётчик, строка параметров, лента
последних страниц, кнопка «Остановить».

- **Тег прохода** — «СКАНИРУЕМ ЛИЦЕВЫЕ СТОРОНЫ» для прохода лиц, «СКАНИРУЕМ ОБОРОТЫ» для
  прохода оборотов, «ДОБАВЛЯЕМ СТРАНИЦЫ» на `--color-pass-added` для добавленного набора (M3.5).
  Номера прохода в теге нет (B-3, решение автора): пользователю он ничего не говорит, а после
  перезапуска оборотов или «Обороты не нужны» «ПРОХОД 3» читался бы как «второй потерян». У
  пары (M4.5, S3–S4) — тот же акцент с ролью: «ДОБАВЛЯЕМ · ЛИЦА» / «ДОБАВЛЯЕМ · ОБОРОТЫ».
- **Иллюстрация** — стопка листов, лист уходит вниз в лоток (цикл `feed`), под ним полоса
  с пульсацией. Полоса **не отражает долю**: это индикатор активности, а не прогресса.
- **Счётчик** — главная строка состояния экрана, крупнее остального (`--font-size-xl`,
  полужирный, основным цветом текста). Содержание — ниже.
- **Строка параметров** — «300 dpi · оттенки серого · A4», под счётчиком, моноширинным и
  приглушённым: подчинена ему.
- **Лента** — пять миниатюр последних страниц, затухающих к краю (непрозрачность 1 → 0,32
  шагом 0,17).
- **Ожидание первой страницы** (B-9, `handoffs/2026-10-scan-wait.md`) — пока в ленте нет
  страниц этого прохода, на её месте пульсируют три точки (`role="status"`, «Ждём первую
  страницу»). Свои у каждого прохода: на оборотах и в наборе видны заново, при досканировании
  лента начинается с прежних страниц — точек нет. Первая страница — точки гаснут за 150 мс, а
  карточка появляется как обычно, не дожидаясь. Лента и точки делят одно место 74 px, экран не
  прыгает. Reduced-motion — три ровные точки, затухание остаётся.

### Поведение

Страницы приходят по одной, пока устройство не ответит «больше нет». После последней — пауза,
затем переход: на `flip`, если проход лицевой (роль, не номер: план M2, KTD-4), на `merge`
после прохода оборотов, сразу на `editor` после одностороннего набора (M3.5, `merge` и
`mismatch` не показываются). У пары (M4.5) — как у основного документа: после лиц набора —
`flip` набора, после его оборотов — `merge`. Досканирование называет в мете, что досканируется,
без номера прохода: у основного документа — «досканируем лицевые стороны · до обрыва было N» /
«досканируем обороты · до обрыва было N» (B-3), у набора — «досканируем добавленный набор · до
обрыва было N», у пары — «досканируем набор Д1 · до обрыва было N».

### Счётчик

**Сколько листов в лотке, приложение не знает.** Сканер их не считает, страницы приходят по
одной до ответа «конец». Но сами полученные страницы считаются в реальном времени: каждая
приходит отдельным ответом. Отсюда две формы счётчика.

| Проход         | Текст                   | Почему так                                               |
| -------------- | ----------------------- | -------------------------------------------------------- |
| лица           | «Отсканировано 7»       | общего числа нет и взяться ему неоткуда                  |
| обороты        | «Отсканировано 7 из 12» | ожидаемое известно: столько листов дал предыдущий проход |
| добавленный    | «Отсканировано 3»       | как у лиц: число листов приложение не спрашивает         |
| лица набора    | «Отсканировано 3»       | как у лиц (M4.5)                                         |
| обороты набора | «Отсканировано 2 из 3»  | ожидаемое — страницы лиц набора (M4.5)                   |

Счётчик отстаёт максимум на одну страницу — ту, что сейчас едет: она засчитывается, когда
дошла целиком.

**Ожидаемое число для второго прохода — это результат первого, а не ввод пользователя.**
Нигде в интерфейсе число листов не спрашивается и не задаётся.

Счётчик может **перевалить за ожидаемое** («Отсканировано 13 из 12»): в первом проходе мог
случиться двойной захват. Прятать или подрезать это не нужно — это тот же сигнал
несовпадения, просто увиденный раньше, чем закончится проход.

### Отмена

«Остановить» прекращает проход, **отбрасывает страницы этого прохода** и возвращает на экран,
с которого он был запущен: первый проход — на `setup`, проход после разворота — на `flip`,
проход из модалки `add` — на `editor`. Завершённые проходы остаются: единица удаления — проход
([ADR 0004](../decisions/0004-data-model.md)). «Остановить» на первом сегменте добавленного
набора убирает набор целиком — лента и правки прежние. У пары (M4.5): «Остановить» на лицах
набора убирает набор; на первом сегменте его оборотов до первой страницы — снимает проход и
возвращает на `flip` набора, после первой страницы — **оставляет полученное** прерванным
проходом и ведёт в `editor` с плашкой прерванного прохода (решение автора на приёмке M4.5,
2026-10-24: лица набора уже приняты, «не те листы» здесь почти не бывает). Обороты основного
документа — по общему правилу (бэклог). При досканировании прерванного прохода «Остановить» отбрасывает только
досканированное и возвращает к прерванному проходу. В макете
«Остановить» всегда ведёт на `setup` — это расхождение с макетом, а не недосмотр спеки. Отказ
«Остановить» всегда виден тостом: несмытые страницы (файлы заняты) — «Не удалось убрать
страницы — … Проход прерван.», любой другой код — «Не удалось остановить: причина»
(B-17).

Подтверждения нет, и это решение, а не недосмотр: отменяют обычно потому, что в лоток легли
не те документы или пачка легла не той стороной, и сохранять полученное незачем. Отмена —
единственный случай, когда отсканированное пропадает; от сбоя оно не теряется.

## 4. Экран `flip` — инструкция по развороту

Самый ответственный экран: ошибка человека здесь собирает документ молча и неправильно.

### Раскладка

Центрированная колонка: кикер «ШАГ 2 ИЗ 3 · ЛИЦА ГОТОВЫ: N листов», заголовок «Разверните
листы на 180° — все разом», лид «Переворачивать не нужно: из податчика листы вышли оборотами
вверх. Возьмите все листы разом, разверните на 180° и положите обратно в лоток». Ниже — две
зоны, разделённые вертикальной линией: слева анимированная иллюстрация с подписью «все листы
разом — разворот на 180°», справа чеклист. Внизу две кнопки. Слов «пачка» и «стопка» в
текстах экрана нет (решение автора).

### Иллюстрация

Карточка-лист с подложкой, на листе стрелка `↑` и подпись «ВЕРХ» — маркер ориентации, по
которому читается поворот. Цикл `turn180`, 3,8 с: лист появляется сверху, поднимается,
поворачивается на 180° **в плоскости** (`rotate`, не переворот), опускается, держит
результат около 0,45 с и уходит вниз, оставаясь развёрнутым. Обратного поворота в цикле нет:
действие показывается один раз и не отменяется.

### Чеклист

1. Проверьте входной лоток: в нём не должно остаться листов. Оставшийся лист не отсканирован.
2. Не переворачивайте листы — из податчика они вышли оборотами вверх.
3. Не меняйте порядок листов: обороты придут в обратном порядке, приложение это учтёт.
4. Если один лист застрял — начните второй проход и вставьте его отдельно.

### Действия

Движение (B-4): новая страница въезжает справа, остальные сдвигаются от видимого места,
шестая выталкивает первую — та гаснет влево; шаги затухания меняются плавно.

- **«Листы в лотке — сканировать обороты»** (первичная) — запускает следующий проход.
  Ожидаемое число листов для него — результат первого прохода; оно идёт в счётчик (раздел 3),
  но проход не обрывается по достижении этого числа, а идёт до ответа устройства «конец».
- **«Обороты не нужны»** (текстовая) — пропускает второй проход и сразу открывает `editor`
  (паузы `merge` нет: сопоставлять нечего — решение автора на приёмке B-5). Так односторонняя
  пачка закрывается без возврата в настройки.

**`flip` набора (M4.5, S5).** Тот же экран для двустороннего набора, ждущего обороты: кикер
«ДОБАВЛЯЕМ · ЛИЦА ГОТОВЫ: 3 листа» на `--color-pass-added` вместо «ШАГ 2 ИЗ 3 …» (у добавления своих
шагов нет), число — лица набора; заголовок, лид, иллюстрация, чеклист и обе кнопки — прежние.
«Обороты не нужны» — решение по набору: набор остаётся односторонним блоком, `flip` больше не
показывается; повторный клик в полёте не уходит. Экран выводится из снимка с приоритетом над
`editor` и независимо от «Обороты не нужны» основной пачки; занятость во время прохода оборотов
набора — как у основной.

**Автоперехода здесь нет намеренно.** Пачку разворачивает и кладёт человек; когда он закончил
— знает только он, и подтверждение готовности за ним. Опрос `ScannerStatus` нужен не для
перехода, а для подсказки: увидели `ScannerAdfLoaded` — подсветили кнопку второго прохода.
Эта подсветка уехала в пост-MVP вместе с остальным опросом состояния устройства.

## 5. Экран `merge` — сборка

Редизайн B-5 (`handoffs/2026-10-b5-merge.md`, утверждён автором 2026-10-26): заголовок
«Сопоставляем лица и обороты», иллюстрация «сортировки» и одна строка состояния. Иллюстрация —
вариант «пары», без лотка: лица раскладываются в ряд, на каждое ложится его оборот, пары
собираются в одну стопку и уходят (цикл 3,8 с). **Она одна на все исходы** и работает как
индикатор «идёт сборка», а не как рассказ об исходе: пауза короче цикла, и картинка
несовпадения из handoff'а не доигрывалась до того, как открывался редактор (решение автора на
приёмке B-5, 2026-10-26). О несовпадении сообщает строка состояния и затем модалка `mismatch`.
Листов в иллюстрации всегда шесть, число — в строке. Под `prefers-reduced-motion` — стоп-кадр
«пары разложены». Диаграмма рядов, формула и подписи рядов M2 сняты. После «Обороты не нужны»
экрана нет — сразу `editor`.

Экран **полностью процессный**: ни одного органа управления, уходит сам через 1,6 с; с M4
это минимум — см. ниже. Отменить или
задержать сборку нельзя.

Статусная строка в макете — константа. С M2 это сводка фактического результата, и именно
она первой сообщает о несовпадении проходов; при несовпадении строка янтарная, с точкой.
Модалка `mismatch` и пометки ленты не меняются.

При несовпадении проходов (M3.6, `handoffs/2026-10-m3-6-states.md`, S7) документа ещё нет:
статус «не сошлось: лицевых 12, оборотов 11 — документ соберёте в редакторе» (лишние обороты —
«лишних оборотов: 1 — документ соберёте в редакторе», принятый коротким — «проход оборотов
принят коротким: лицевых 12, оборотов 7»).

**Пустые обороты (M4, `handoffs/2026-10-m4-states.md`, S12).** Статусная строка получает
хвост — отдельным узлом, при смене проявляется (B-5): «· ищем пустые обороты…», пока оценки
идут, затем «· пустых оборотов: 3» или
«· пустых оборотов: нет». Хвоста нет при режиме «Оставлять», без прохода оборотов («Обороты
не нужны») и в режиме раздельных наборов — там детектор не работал или страницы не
скрываются. Экран держится не меньше паузы, а при незавершённых оценках — дальше, до их
прихода, **без потолка** (решение автора 2026-10-22: страницы не должны исчезать из ленты
на глазах; потолок из плана отклонён). В режиме наборов ожидания нет: скрывать там нечего,
а экран без хвоста статуса выглядел бы зависшим. Оценки считаются во время прохода, так
что на живом устройстве ожидание сверх паузы практически не наступает; зависшая оценка
держит экран до перезапуска (раздел 11).

**Выравнивание (M6, `handoffs/2026-10-m6-straighten.md`).** Второй хвост статусной строки,
отдельным узлом по виду: «· выравнивание: ещё N стр.», пока измерения и коррекция идут (счёт
меняется без проявления), затем «· выровнено: N стр.» — новым узлом с проявлением (оставленные
оригиналом в счёт не входят). Хвоста нет при «Не трогать», в режиме раздельных наборов и когда
мерить было нечего. Экран держится, пока идёт выравнивание, без потолка (как с оценками
пустых), и ещё 500 мс после итога, чтобы его успели прочесть; закончилось к концу паузы —
уходит по таймеру без добавки.

**Набор (M4.5, S6).** Пауза — после оборотов набора; после «Обороты не нужны» для набора
паузы нет, как у основной (B-5). Над заголовком — тег «НАБОР Д1» в цвете набора, заголовок —
«Сопоставляем лица и обороты набора» (B-5); иллюстрация та же и в цвет набора не
перекрашивается: кромки несут сторону, не набор. Статус начинается с набора: «набор Д1:
совпало пар 3», «набор Д1: не сошлось — лиц 3, оборотов 2», «набор Д1: обороты приняты
коротким — …». Хвост «пустых оборотов» — по сводке сессии, как в M4; ожидание оценок — тоже,
и всё ожидание экран остаётся про набор. После «Остановить» на лицах набора паузы нет, после
перезапуска — тоже (как у основной).

## 6. Экран `editor` — проверка и правка

Главный рабочий экран. Четыре зоны: тулбар сверху, лента миниатюр слева, превью по центру,
инспектор справа.

### 6.1. Тулбар

Слева: «↺ Новый скан» и «+ Добавить листы» (M3.5; подписи укорочены в B-42: прежние «Новое сканирование» и «Добавить» давали кнопки разной ширины), обе поровну в левой зоне. «+ Добавить»
открывает модалку `add` (раздел 7.2) и недоступна с причиной в `title`: идёт запись
(«Документ сохраняется — дождитесь конца записи»), правка ещё в полёте («Правка ещё
записывается — секунду»), последний проход прерван («Сначала досканируйте прерванный проход
или оставьте его как есть»). К пустой ленте добавить можно. По центру: цветная метка документа, его название
и, если на текущей странице границу поставить можно, кнопка «+ Новый документ с этой
страницы»; позиция «документ 2 из 3 · стр. 4 из 9» снята в B-45 — страница есть в статусбаре,
документ подсвечен в списке инспектора. Справа (B-45, handoff `2026-11-inspector-v2.md`): пока
есть ручные правки — плашка «Есть ручные правки» без подложки и рамки на всю ширину зоны:
мигающая янтарная точка (`--duration-loop`; под reduced-motion не мигает), текст слева, кнопка
«Вернуть» справа (раздел 6.4); без правок зона пуста. Первичная кнопка «Сохранить документ» /
«Сохранить N файлов» с B-45 живёт в инспекторе под ДОКУМЕНТАМИ В НАБОРЕ (раздел 6.4). Точки
«не сохранено» в тулбаре с B-45 нет: сессия лежит на диске и восстанавливается при запуске, а
о несохранённом спрашивает модалка `newscan`.

**Режим раздельных наборов (M3.6, S4–S5).** Пока проходы лиц и оборотов не сошлись, по центру
вместо метки документа — живые счётчики групп: янтарная точка и «Проходы не сошлись: лицевых
12, оборотных 11», при равных ненулевых — акцентная точка и «Наборы уравнены — соберите
документ»; кнопки «+ Новый документ с этой страницы» нет. Вместо «Сохранить» — «Собрать
документ» (с B-45 — в слоте первичной кнопки инспектора под ДОКУМЕНТАМИ В НАБОРЕ, на всю
ширину), недоступная с причиной в `title` по фиксированному порядку: идёт запись → правка в
полёте → последний проход прерван → «В наборах нет страниц» → «Не хватает N оборотов» → «Не
хватает N лиц». Клик — одна команда `assemble` на нажатие, до ответа кнопка недоступна, а правки, лента и
«Вернуть» заблокированы, как при записи; успех — тост «Документ собран: N листов» и обычный
редактор с лентой лицо 1, оборот 1, …; отказ — тост с причиной. Обратной команды нет: после
сборки удаление и перенос — обычные правки, «Вернуть» возвращает к записи сборки.

### 6.2. Лента миниатюр (слева)

Лента рисуется по **показанной ленте** (M4, `handoffs/2026-10-m4-states.md`, S1): в режиме
«Скрывать» скрытых ядром пустых оборотов в ней нет, пока не включён переключатель «добавить
пустые» (раздел 6.9). Панели выделения над лентой больше нет — она переехала в подвал (ниже
и раздел 6.5), миниатюры при появлении выделения не сдвигаются.

Страницы сгруппированы по документам. У каждой группы: разделитель (у всех,
кроме первой) с пилюлей «НОВЫЙ ДОКУМЕНТ», пунктиром и кнопкой «✕» для снятия границы;
заголовок с цветным номером, редактируемым названием и счётчиком страниц; сетка миниатюр.
Документ из одних скрытых пустых оборотов в ленте не рисуется и в «документ N из M» тулбара не
считается (B-17); «✕» на разделителе за ним сливает документ с ближайшим видимым слева одной
правкой — все разрезы между ними снимаются, имя остаётся у левого, скрытые страницы входят в
слитый документ, Ctrl+Z возвращает всё разом. Если видимого слева нет (первый документ ленты —
из одних скрытых), «✕» у следующего разделителя не показывается: такой разрез снимается при
показанных «Пустых».

**Режим раздельных наборов (M3.6, S1–S3).** Пока проходы не сошлись, групп документов нет —
две группы «Лицевые стороны · 12» и «Оборотные стороны · 11» с живыми счётчиками (лица в
порядке сканирования, обороты в порядке будущего документа) и разделитель между ними:
пунктир с подсказкой капсом «перенос через границу меняет набор», не фокусируемый
(`role="separator"`, озвучен). Полей имён, пилюль, «✕», split-бара и «Выделить в документ»
нет; номера миниатюр сквозные. Перенос — те же миниатюры и то же перетаскивание: группа
перенесённых страниц — группа страницы-цели (бросок «после последней лицевой» оставляет в
лицах, «перед первой оборотной» переносит), смешанное выделение переносится целиком; верхняя
половина разделителя — «в конец лиц», нижняя — «в начало оборотов», маркер дропа показывает
сторону; пустая группа — заголовок «· 0» и зона дропа «Перетащите сюда страницы оборотов».
Перенос через границу — правка порядка с явной границей: шаг undo и плашка «Есть ручные
правки». Стрелки, Shift-диапазон, Home/End ходят сквозь разделитель как по одной ленте.

**Миниатюра:** лист с имитацией строк, номер по порядку в наборе, подпись стороны «лицо» или
«оборот». Дополнительно:

- **тег** в подвале карточки — «об» у оборотов; «Д1», «Д2» и далее у добавленных наборов
  (M3.5) цветом `--color-pass-added`: порядковый номер набора среди наборов со страницами, не
  номер прохода (номера проходов после «Остановить» прыгают). У добавленной страницы нет ни
  «лица», ни «оборота»: `aria-label` — «Страница 8, добавленный набор 1». У лиц тега нет.
  Страницы пары (M4.5, S8) — «Д1» на обеих сторонах, у оборота ещё «об» (два существующих
  тега, новых цветов нет); `aria-label` — «Страница 9, оборот листа 2 набора Д1», в подблоках
  несовпавшего набора без листа — «… оборотная набора Д1»;
- ~~**пометка непарного листа**~~ — снята в M3.6: непарных больше нет, при несовпадении лента
  делится на наборы; подпись стороны («лицевая, 3-я в наборе лиц») — по группе, тег «об» — по
  происхождению (проход оборотов) и в группе лиц не исчезает;
- **метка «ПУСТО»** (M4, S2–S3) — пилюля по центру листа на `--color-text-subtle` у
  помеченного пустого оборота и у скрытого, показанного переключателем; показанная скрытая
  дополнительно — пунктирная рамка и приглушённый лист: в файл она не попадёт. `aria-label`
  несёт суффикс «, пустая» или «, пустая, скрыта — в файл не попадёт». В режиме раздельных
  наборов (M3.6) пустые помечены, а не скрыты — скроются после «Собрать документ»;
- **split-бар** — появляется при наведении на верх миниатюры у всех страниц, кроме первой:
  «+ Новый документ» или, если граница уже стоит, «⤺ Убрать границу». Уступает выделению
  (M3.5): пока зажат Ctrl/Shift или выделено больше одной страницы, бара нет ни у одной
  миниатюры, и клик с модификатором по верхнему краю — выделение, а не граница.

**Нумерация (M4).** Номер миниатюры и «стр. N из M» — позиции в показанной ленте: это номер
в будущем файле; при включённом переключателе скрытые встают на свои места и номера
пересчитываются. «Лист N» в ДЕТАЛЯХ и `aria-label` — по полной ленте: лист — свойство записи
сборки, скрытие его не двигает. Документ из одних скрытых страниц в ленте не рисуется (в
списке ДОКУМЕНТЫ В НАБОРЕ он есть — раздел 6.4).

**Склеенный оборот (M4, B-13).** Пустой оборот (скрытый или помеченный), идущий в полной ленте
сразу за страницей того же документа, — склеенная часть её листа при любом состоянии
переключателя «Пустые» и в обоих режимах пустых; в режиме пар — только оборот того же листа и
набора (оборот, разнесённый со своим лицом поздним вердиктом или старой перестановкой, к чужому
лицу не клеится); в режиме раздельных наборов склейки нет. Лист едет целиком при переносе,
уходит целиком при удалении (одним шагом undo — Ctrl+Z возвращает обоих; тост и кнопка
«Удалить N стр.» считают страницы пользователя) и целиком входит в «Выделить в документ».
Выделение с лицом без его оборота добирает оборот; оборот без своего лица в переносе и
группировке не участвует, а удаляется сам — удаление буквальное. Склеенный оборот не
перетаскивается сам (курсор обычный, подпись «Оборот идёт вместе со своей страницей»); тянется
только в выделении вместе с лицом; при переносе лица оборот подсвечен с ним. Бросок на
склеенный оборот: левая половина — перед его лицом, правая — после листа; маркер — там же;
бросок лица на свой оборот ничего не делает. Разрез не ложится между лицом и склеенным
оборотом: у оборота нет split-бара и кнопки тулбара «Новый документ с этой страницы»; разрез,
стоящий там с прежних сессий, уважается — склейка обрывается на границе документа. «Это не
пустая страница» делает оборот обычной страницей; Ctrl+Z пометки склеивает снова. Текущая,
ставшая скрытой, переезжает на своё лицо.

**Подвал ленты (M4, S4–S6; B-8).** Постоянное место под миниатюрами, сверху вниз:

1. панель выделения — «Выделено N стр.» и кнопка «Выделить в документ» (вне режима наборов; в
   режиме наборов панель — только текст); при выделении больше одной страницы. Подсказки про
   Shift и Ctrl и кнопки «Снять» нет (B-8): выделение уже сделано, сжимают его Esc в ленте и
   щелчок без модификаторов; Esc из подвала переводит фокус на текущую страницу;
2. строка переключателей (`.rail__toggles`), слева направо:
   - «Пустые» — только в режиме «Скрывать», при проходе оборотов и вне режима раздельных
     наборов (после «Собрать документ» появляется). Без найденных — недоступен;
   - «Обороты на 180°» (M2) — по пачке текущей страницы (M4.5, S9). Текущая на пачке без
     оборотов (односторонний «Д2», основной документ без оборотов) — тумблер недоступен;
     переключателя нет, только если оборотов нет ни у одной пачки. Флаг у каждой пары свой:
     переключение — один шаг undo, смена текущей шагом не считается.

   Видимых подписей у переключателей нет (B-8). Счётчик «скрыто: N» / «показано: N» / «не
   найдено» / «оцениваются…» и цель тумблера («обороты основного документа» / «обороты набора
   Д1») или причина недоступности («у набора Д2 нет оборотов») — скрытые описания чекбоксов
   (`aria-describedby`: `blank-count`, `rotate-target`) и `title` строки: «Скрыто N пустых
   оборотов — в файл не попадут…», «Действует на обороты набора Д1. Если обороты вверх
   ногами…». При нехватке ширины второй переключатель переносится ниже.

Нет ни одной строки (лицевые без оборотов, одна выделенная) — подвала нет. Подвал растёт
вниз, лента над ним не сдвигается. Tab после ленты: «Выделить в документ» → чекбокс «Пустые»
→ чекбокс 180°. Мок подписывал включённый переключатель «N в наборе» — заменено: «набор» в
M3.5–M3.6 значит другое.

**Пометка выравнивания (M6, раздел 6.10).** У правого края подвала карточки — один
абсолютный слот: глиф «выровнено» (три ровные строки) или «не выровнено» (строки волной) с
причиной в `title`, либо три точки, пока страница в обработке (общая фаза у всех карточек —
точки не моргают вразнобой). Озвучка карточки получает суффикс: «…, выровнена», «…, не
выровнена: не по чему мерить» (или «наклон строк не сходится» — строки есть, но не ложатся на
один профиль: две колонки), «…, выравнивается». Слот вне потока — номер, «об» и тег набора
не сдвигаются. Метка «ПУСТО», split-бар, рамки выделения и пунктир скрытой не меняются; у
пустого оборота статуса выравнивания нет.

### 6.3. Превью (по центру)

Крупный лист с имитацией текста, в углу метка «ЛИСТ 7 · ОБОРОТ». Если страница начинает
документ — верхняя кромка акцентная и подпись «НАЧАЛО ДОКУМЕНТА N».

**Пустая страница (M4, S8)** показывается как есть — пустоту проверяют глазами; в левом
верхнем углу листа пилюля «ПУСТАЯ СТОРОНА» у помеченной, «ПУСТАЯ СТОРОНА · НЕ ПОПАДЁТ В
ФАЙЛ» у скрытой, показанной переключателем. Текст мока «пустая сторона листа (распознано
автоматически)» вместо строк не рисуется: строк нет, есть скан. Потерянная или не
открывшаяся страница — как прежде, без пилюли.

**Выравнивание (M6, раздел 6.10).** В том же углу пилюля «ВЫРОВНЕНО» (глиф ровных строк),
«НЕ ВЫРОВНЕНО» (глиф волной, причина в `title`) или «ВЫРАВНИВАЕТСЯ» (точки); у ровной и у
оставленной оригиналом пилюли нет; с пилюлей пустоты не пересекается — у пустой статуса нет.
«НАЧАЛО ДОКУМЕНТА» остаётся справа. Смена вида (откат, поздняя коррекция) — на месте: прежний
кадр до готовности нового, без плашки загрузки.

Под превью — статус-бар: «←», счётчик «7 из 21» (по показанной ленте; «←» и «→» ходят по ней
же), «→», кнопки поворота «↺» и «↻» (обе с направлением и числом страниц в подписи, M3.5),
кнопка удаления. Кнопка «Пересканировать» из макета не рисуется — пост-MVP (раздел 6.8).

**Все страницы скрыты (M4, S7)** — переключатель выключен, а показанная лента пуста при
непустой полной: вместо превью пустой редактор «Все страницы — пустые обороты» с текстом
«Они скрыты и в файл не попадут. Переключатель «Пустые» внизу ленты покажет их;
«Это не пустая страница» вернёт нужную в документ.», лента — «Все страницы скрыты»,
текущей нет, статус-бар «—», инструменты недоступны, фокус — на переключателе. Полная лента
пуста совсем — прежнее «Страниц не осталось» (раздел 6.8).

### 6.4. Инспектор (справа)

Блоки сверху вниз (B-45, handoff `2026-11-inspector-v2.md`): ДЕТАЛИ с подразделом ПРОВЕРКА →
ПУСТОЙ ОБОРОТ (только у пустой страницы, M4) → ВЫРАВНИВАНИЕ (только у страницы со статусом,
M6, раздел 6.10) → ДОКУМЕНТЫ В НАБОРЕ с первичной кнопкой → подвал. Инспектор — колонка,
секции не сжимаются; высоты секций анимируются (раздел 9, таблица движения):

- **ДЕТАЛИ** — сворачиваемый, по умолчанию свёрнут. Заголовок «Стр. 7 — оборот листа 4»,
  факты «Лист», «Сторона», «Поворот» и пояснение про пару словами. У пустой страницы и у
  помеченной вручную (M4, S10) — ещё факт «Содержимое»: «пустая — скрыта» / «пустая — с
  меткой» / «не пустая — ваша пометка»; у обычных страниц ряда нет. Факт «Выравнивание» (M6) — у каждой страницы сессии
  «Выравнивать», кроме пустых: «выровнена» / «оригинал — ваш выбор» / «ровная» / «не по чему
  мерить» / «не помогло» / «отложено — мало места» / «отложено — сбой» / «идёт…». Номера
  прохода нет (M3):
  номер прохода — не роль, а «проход 3» после перезапуска путает. У добавленной страницы
  (M3.5) — «Стр. 8 — добавленный набор 1», факты «Набор» и «Поворот», пояснение без пары.
  До сборки (режим наборов, M3.6, S9) листа ещё нет: заголовок «Стр. 15 — оборотная, 3-я в
  наборе оборотов» (добавленная — «добавленный набор 1, в наборе оборотов»), факты «Набор»,
  «Место» («3-я из 11»), «Откуда» («проход оборотов» / «проход лиц» / «добавленный набор 1»),
  «Поворот»; пояснение говорит, каким листом страница станет после сборки. После сборки —
  как прежде: лист по позиции в записи сборки; страница без листа (добавлена после сборки) —
  «добавленный набор K». Страница пары (M4.5, S8) — «Стр. 9 — оборот листа 2 набора Д1»
  (подблоки — «оборотная набора Д1», «Лист» — «—»), факты «Набор», «Лист», «Сторона»,
  «Откуда» («проход лиц набора Д1» / «проход оборотов набора Д1»), пояснение про пару набора
  или, в подблоках, — что обороты не сошлись и их можно переснять. С B-45 после фактов и
  пояснения — подраздел **ПРОВЕРКА** (кикер `h3`, пункты — ниже), отделён линией и виден
  только при раскрытых ДЕТАЛЯХ; пока в ПРОВЕРКЕ есть хоть один пункт с точкой, в свёрнутой
  строке перед «стр. N» стоит янтарная точка с `title` «В проверке есть замечания», при
  раскрытых точки нет. Лента пуста — ДЕТАЛЕЙ нет, а с ними и ПРОВЕРКИ: о пустых наборах
  говорят лента и причина у «Собрать документ».
- **ПУСТОЙ ОБОРОТ** (M4, S9) — только у пустой страницы: помеченной или скрытой, показанной
  переключателем. Пояснение по режиму: «Распознано автоматически: на странице нет чернил. Она
  скрыта и в файл не попадёт.» / «… Она останется в файле с меткой.» / в режиме наборов «… В
  режиме наборов она считается; после сборки будет скрыта.» — и кнопка **«Это не пустая
  страница»**. Нажатие — правка и шаг undo: страница становится обычной (метка, пилюля и
  секция уходят, в режиме «Скрывать» она возвращается в ленту и в файл), плашка «Есть ручные
  правки», тост «Страница возвращена в документ — Ctrl+Z отменит»; текущая и фокус — та же
  страница. Обратного действия («считать пустой») нет: Ctrl+Z или «Вернуть». Пометка
  переживает перезапуск. Кнопка недоступна, пока идёт запись или сборка.
- **ДОКУМЕНТЫ В НАБОРЕ** — счётчик и список документов с номером, названием и метаданными
  («9 стр. · стр. 4–12 набора», по показанной ленте); текущий подсвечен, клик переводит на
  его первую страницу. Документ из одних скрытых пустых оборотов (M4) — «только пустые
  обороты — скрыты», в ленте он не рисуется. Под списком пояснение: сколько файлов получится,
  а если границ нет — как их поставить: split-бар или выделение (Shift — диапазон, Ctrl — по
  одной) и «Выделить в документ»; «подряд» подсказка с M4 не требует (раздел 6.5). До
  сборки (M3.6) счётчика и списка нет — «Документы появятся после сборки: сейчас лица и
  обороты лежат отдельными наборами».
  Подсказка про границы (Ctrl/Shift) при первом показе на установку мигает три раза по
  1,2 с через 580 мс после появления экрана (B-4); гаснет раньше по взаимодействию с лентой
  или наведению; показанной считается сразу (`settings.json`, `seenHints`). Последний элемент
  секции (B-45) — **первичная кнопка** на всю ширину: «Сохранить документ» / «Сохранить N
  файлов» (недоступна при пустой ленте; открывает `save`), в режиме наборов — «Собрать
  документ» с причинами недоступности по разделу 6.1.
- **ПРОВЕРКА** (с B-45 — подраздел ДЕТАЛЕЙ, см. выше) — пункты со значком:
  1. лица и обороты — только при отклонении (решение автора 2026-11-03, bugs): при совпавших
     проходах и без оборотов пункта нет — модалка уже всё сказала, а прежние «Лица и обороты
     собраны: N листов» и «Обороты не сканировали» про давний выбор только путали, когда потом
     добавлялись двусторонние наборы. Набор «ДN», у которого обороты не сошлись и нажато
     «Оставить как есть», — точка словами кнопки: «Набор Д2: оборотов отсканировано 1 из 3 — вы
     оставили как есть» (при лишних оборотах — «оборотов 4, лиц 3»); модалка второй раз не
     покажется, а листы без оборотов легко забыть; числа — по проходам, правки их не меняют. В
     режиме раздельных наборов (M3.6, S8) — точка со счётчиками групп: «Наборы не уравнены:
     лицевых 12, оборотных 11 — не хватает 1 оборота» и подсказка «Досканируйте недостающее
     кнопкой «+ Добавить листы» или перенесите страницы через границу наборов, затем нажмите
     «Собрать документ»»; при уравненных — точка остаётся («Наборы уравнены: по 12 стр. —
     нажмите «Собрать документ»»): документ ещё не собран; все удалены — «Наборы пусты».
     Прежний пункт «Пар „лицо + оборот“: N из M» и подсказка про пропущенный лист сняты;
  2. пустые обороты (M4, S11) — по режиму сессии: галочка «Пустых оборотов не найдено»; в
     «Скрывать» — точка «Скрыто N пустых оборотов — в файл не попадут» с подсказкой
     «Переключатель «Пустые» внизу ленты покажет их; «Это не пустая страница» вернёт
     нужную в документ.»; в «Помечать» — галочка «Помечено N пустых оборотов — останутся в
     файле»; в режиме раздельных наборов при «Скрывать» — точка «Помечено N пустых оборотов —
     считаются в наборах, скроются после сборки». Пока оценки идут — точка «Оценка пустых
     оборотов: ещё N стр.» с приоритетом над остальными: сохранение в это время недоступно.
     Скрытие меняет состав файла без участия пользователя — поэтому точка; пометка ничего не
     убирает — галочка. При «Оставлять» пункта нет;
  3. выравнивание (M6, раздел 6.10) — пока идёт: точка «Выравнивание: ещё K стр.» с
     подсказкой «Сохранение подождёт — кнопка станет доступна сама.»; затем галочка
     «Выровнено N стр.» (с хвостом «, M — оставлены оригиналом»), «Все страницы ровные» или
     «Ни одна страница не выровнена»; невыровненные — подсказкой с причинами и числом («Не
     выровнено 3: не по чему мерить — 2, мало места — 1.»; причины — не по чему мерить, наклон
     строк не сходится, коррекция не помогла, мало места на диске, сбой), при нехватке места — «Освободите
     место на диске — при следующем запуске приложение попробует снова.», при сбое — «При
     следующем запуске приложение попробует снова.». При «Не трогать» пункта нет;
  4. порядок — галочка «Порядок соответствует сканированию» или точка «Порядок правили
     вручную — автосортировка отключена».
- **«Есть ручные правки»** — плашка с кнопкой «Вернуть» (M3; с B-45 — в правой зоне тулбара,
  раздел 6.1: без подложки и рамки, с мигающей точкой). Показывается при **любой**
  правке: перенос, поворот, удаление, граница, имя, тумблер 180°, пометка «Это не пустая
  страница» (M4). «Порядок изменён» был бы неправдой после одного поворота без переноса.
  «Вернуть» — **полный откат**: порядок, повороты, удаления, границы, имена, тумблер и
  пометки «не пустая» и «Оригинал» (M6) одним шагом, после подтверждения в малой
  модалке `revert` (начальный фокус на «Отмена»). Сам откат — шаг undo: Ctrl+Z возвращает всё.
  Добавление набора — не правка (M3.5): место вставки — свойство прохода, плашка от него не
  появляется, «Вернуть» набор не трогает.
- **Ссылка на проект** (B-42) — подвал инспектора, прижат к низу панели (при прокрутке уезжает
  с содержимым). С B-45 подвал — по правому краю рядом: логотип-монограмма D’ высотой
  `--size-beta` (геометрия `build/icon-small.svg`), он же ссылка на проект (`aria-label`
  «Duplexn't · о проекте», при наведении чуть светлее), и плашка **BETA** той же высоты
  (инверсный фон, моно `--font-size-xxs`), не интерактивна. Текстовой ссылки нет (правка
  автора на приёмке). Прежняя (B-42) — мелкая строка в цвете подсказки «Duplexn't · о проекте
  ↗», подчёркивание при наведении, `title` «Открыть страницу проекта в браузере». Открывает
  страницу проекта в системном браузере командой моста без входа — адрес знает main, из
  интерфейса не передаётся; отказ — тостом «Не удалось открыть браузер: …».

### 6.5. Выделение

- клик — выделить одну страницу и сделать её якорем;
- **shift** + клик — диапазон от якоря до текущей;
- **ctrl / ⌘** + клик — добавить или убрать одну, якорь переносится;
- клик мимо ленты — по превью, инспектору, пустому месту тулбара — сжимает выделение до
  текущей, как Esc (M3.5). Кнопки, поля и модалки исключены: «↻», «Удалить N стр.» и
  «Выделить в документ» действуют на выделение.

При выделении больше одной страницы появляется панель выделения — с M4 в подвале ленты, а не
над ней (раздел 6.2, S6): миниатюры не сдвигаются. Выделение живёт по показанной ленте:
скрытые пустые обороты в него не входят, пока не показаны переключателем.

**«Выделить в документ»** (M4, S6; B-14) работает для любого выделения из двух и больше
страниц вне режима раздельных наборов и **извлекает** выделенные, а не режет исходный документ:

- выделенные страницы (со скрытыми хвостами и склеенными оборотами своих лиц, раздел 6.2)
  уходят из своих документов в **отдельный новый документ в конце ленты**, в ленточном порядке;
  оставшиеся страницы смыкаются, их документы и имена остаются прежними — документ из десяти
  страниц без третьей пары остаётся одним документом из восьми, а не распадается на два;
- новый документ — с именем по умолчанию; выделен ровно целый документ — он переезжает в
  конец со своим именем;
- это перенос: порядок становится явным, как после перетаскивания; один шаг undo, после Ctrl+Z
  выделены перенесённые страницы. Кусок, уже стоявший в конце ленты, не переносится — ставится
  только граница перед ним; кусок, уже отдельный документ в конце, и выделение всей ленты —
  кнопка недоступна.

Фокус — в поле имени нового документа, тост «Отдельный документ из N стр. создан», плашка «Есть
ручные правки». Тост «Выделите подряд идущие страницы» снят ещё в M4.

### 6.6. Перетаскивание

Миниатюра перетаскиваемая, при перетаскивании становится полупрозрачной; склеенный пустой
оборот (раздел 6.2, B-13) сам не тянется и едет подсвеченным вместе с лицом. Позиция вставки
определяется по курсору: левее середины миниатюры — вставка перед ней, правее — после; место
показывается вертикальным маркером. Бросок переносит страницу и **отключает автосортировку**:
поднимается признак ручной правки, плашка «Есть ручные правки» и пункт проверки «Порядок».
Перетаскивание — только мышью; перестановка с клавиатуры — бэклог.

**Автопрокрутка (B-10).** У верхнего и нижнего края ленты (48 px) она сама едет в эту сторону,
пока страницы удерживаются: от 120 px/с на границе зоны до 900 px/с у края; указатель за краем
ленты (над тулбаром, подвалом) в её ширину — максимальная скорость. Останавливается, когда
указатель ушёл от края или вбок из ленты, страницы брошены или перенос отменён (Esc), лента
упёрлась в начало или конец. Маркер вставки следует за тем, что под указателем после прокрутки.
Чужое перетаскивание (файлы, текст) ленту не двигает. Встроенная прокрутка Chromium в узкой
полосе у самого края работает поверх.

### 6.7. Границы документов

Граница ставится на странице, с которой начинается следующий документ, тремя путями:
split-бар на миниатюре, кнопка в тулбаре, «Выделить в документ». На первой странице набора
граница невозможна.

Постановка границы сразу ставит фокус в поле названия нового документа и выделяет текст —
чтобы имя вводилось без лишнего клика. Название по умолчанию — «Документ N»; у единственного
документа — общее имя набора. Снятие границы удаляет и введённое название. Enter в поле
фиксирует имя и снимает фокус — на карточку текущей страницы (M3.5); пока предыдущая правка
в полёте, Enter ничего не делает, чтобы имя не выглядело принятым. Esc отменяет ввод.

### 6.8. Правка страниц

- **Поворот** — «↻» поворачивает на 90° по часовой, «↺» (M3.5) — против часовой, текущую
  страницу или всё выделение, одним шагом undo; тоста нет — поворот виден. Поворот виден **и на миниатюре** (M3): рамка
  остаётся портретной, изображение уменьшено и повёрнуто внутри неё, сетка не прыгает. Превью
  при 90°/270° становится альбомным — «как будет в PDF». Движение (B-4): лист превью и
  миниатюра поворачиваются целиком на дельту команды за 240 мс — 270° → 0° по «↻» идёт по
  часовой, а не назад; прерванный поворот продолжается с текущего положения; undo/redo — без
  анимации. Исходник
  страницы не меняется: угол — запись в журнале, применяется при сборке PDF.
- **Удаление** — помечает страницу или всё выделение удалёнными, поднимает признак ручной
  правки, показывает тост «Страница удалена — Ctrl+Z вернёт» / «Удалено N стр. — Ctrl+Z
  вернёт». Подтверждения нет. Файлы страниц не трогаются до закрытия сессии. Все страницы
  удалены — пустой редактор «Страниц не осталось» с подсказкой про Ctrl+Z и «Вернуть»,
  сохранение недоступно.
- **Undo / Redo** — Ctrl+Z, Ctrl+Y и Ctrl+Shift+Z вне текстовых полей и модалок. Стек живёт до
  перезапуска (после него пуст, правки целы). Изменение ленты или проходов не через
  правку (досканирование, «Оставить как есть» у прерванного прохода) стек очищает; «Собрать
  документ» (M3.6) — тоже: запись сборки входит в подпись ленты, Ctrl+Z сразу после сборки —
  пусто, правки целы.
  **Известное поведение (M3.5):** запуск добавления, который увёл экран на `scan`, очищает
  стек — `editor` на это время размонтирован. Это и пустой лоток, и обрыв до первой страницы,
  и «Остановить»: экран уходит на `scan` до проверки лотка. Отказ до задания (запись, предел
  проходов, прерванный проход) экран не трогает, стек цел.
- **Пересканирование** — не рисуется: пост-MVP (роадмап → «Вне этого роадмапа»).

### 6.9. Пустые обороты

Реализовано в M4 (`handoffs/2026-10-m4-states.md`; план
`../plans/2026-10-22-001-feat-m4-blank-backs-plan.md`). Режим выбирается в `setup` (раздел 2) и **замораживается в сессии** при старте первого прохода — поле сессии, в редакторе не
меняется; смена настройки действует на следующее сканирование. Оценивает страницы ядро — по
проходу оборотов, в фоне, по мере прихода; renderer порога не знает и ничего не оценивает,
он только показывает флаги снимка. Оценка — производное (ADR 0004, амендмент 2026-10-22):
исходник и журнал её не хранят; после перезапуска без кэша оценок страницы оцениваются
заново.

**«Скрывать»** (по умолчанию). Скрытые ядром страницы исключены из показанной ленты, превью,
счётчиков, сводок `save` и `newscan` и из файла. Переключатель «Пустые» в подвале
ленты **только показывает**: включённый — скрытые встают на свои места с меткой «ПУСТО»,
пунктиром и приглушённым листом, нумерация пересчитывается, текущая и выделение не меняются;
в файл они всё равно не попадают. Это состояние экрана, а не правка: не шаг undo, не
переживает перезапуск и перемонтирование `editor` (после прохода «+ Добавить», после
«Собрать документ» — выключен). Выключение убирает скрытые из ленты и выделения; текущая,
если скрыта, переезжает на ближайшую показанную справа, в конце — слева; показанная лента
опустела — «Все страницы — пустые обороты» (раздел 6.3). Вернуть страницу в документ можно
только явно — «Это не пустая страница» в инспекторе (раздел 6.4): правка, шаг undo,
переживает перезапуск. Мок подписывал включённый переключатель «они попадут в файл» —
отклонено: один переключатель молча менял бы состав файла.

**«Помечать».** Лента полная, пустые обороты несут метку «ПУСТО» и пилюлю превью, все
остаются в файле; переключателя нет — скрывать нечего; ПРОВЕРКА — галочка «Помечено N …»;
«Это не пустая страница» снимает метку так же.

**«Оставлять».** Детектор не работает: ни меток, ни переключателя, ни пункта ПРОВЕРКИ, ни
ряда в `save`, ни хвоста статуса `merge` — редактор M3.6 без изменений. Так же открываются
сессии журнала v5 и восстановленные сверкой — даже если настройка стоит «Скрывать».

**Режим раздельных наборов** (M3.6) при «Скрывать»: пустые помечены, а не скрыты — они
считаются в наборах; переключателя нет, ПРОВЕРКА — точка «считаются в наборах, скроются
после сборки». После «Собрать документ» скрытие вступает в силу, один тост «Документ собран:
N листов — скрыто M пустых оборотов» (при нуле скрытых — прежний «Документ собран: N
листов»). Оборот, добавленный через «+ Добавить» в группу оборотов, оценки не получает —
флаг только у страниц проходов с ролью оборотов.

**Обороты двустороннего набора** (M4.5) оцениваются, как обороты основной пачки: `merge`
набора ждёт оценок, скрытые входят в счётчик переключателя, тост посадки называет их («Добавлено
5 стр. — скрыт 1 пустой оборот»). В подблоках несовпавшего набора «Скрывать» скрывает: режим
сессии пара не меняет.

**Поздние оценки.** Обычно оценки приходят во время прохода, и `merge` ждёт остаток (раздел
5), так что редактор открывается сразу с правильной лентой. Вердикты, пришедшие уже в
`editor` (перезапуск без кэша оценок — версия детектора поднялась; досканирование
прерванного прохода оборотов), скрывают страницы по мере оценки — с тостом «Скрыто N пустых
оборотов — переключатель «Пустые» покажет их», один раз на снимок; текущая,
ставшая скрытой, переезжает на своё лицо (B-13; без склейки — на ближайшую показанную справа, в
конце — слева), стек undo цел, фокус возвращается на карточку текущей. Тост —
только в «Скрывать» и только когда страница вердиктом (не правкой и не Ctrl+Z) ушла из
показанной ленты; в «Помечать» ничего не исчезает — появляются метки. Пока оценки идут,
сохранение недоступно (раздел 7.3).

Файлы скрытых страниц живут до «Новое сканирование» — как у удалённых (ADR 0004).

### 6.10. Выравнивание

Реализовано в M6 (`handoffs/2026-10-m6-straighten.md`, утверждён автором 2026-10-29; план
`../plans/2026-10-28-001-feat-m6-straighten-plan.md`). Режим «Выравнивать» / «Не трогать»
выбирается в `setup` (раздел 2) и **замораживается в сессии** при старте первого прохода;
старые сессии (журнал v7 и ниже) — «Не трогать». Измеряет и выправляет ядро — по ходу прохода
и очередью после; renderer ничего не считает и показывает статус снимка. Выправленный вид —
производное (ADR 0004, амендмент 2026-10-28): исходник цел, откат возвращает его байты.

**Статусы и пометки.** Выправлена — глиф «три ровные строки» в слоте подвала карточки, пилюля
«ВЫРОВНЕНО», миниатюра и превью — выправленный вид. Не выровнена (не по чему мерить / наклон
строк не сходится / не помогло / мало места / сбой) — глиф «строки волной», пилюля «НЕ ВЫРОВНЕНО», причина — в `title`
глифа и пилюли и в озвучке карточки («…, не выровнена: не по чему мерить»); исходник. В
обработке — три точки в том же слоте (общая фаза у всех карточек) и пилюля «ВЫРАВНИВАЕТСЯ»;
исходник, сохранение подождёт. Ровная — ничего. Оригинал оставлен — пометки и пилюли нет
(открытый вопрос handoff'а оставлен по умолчанию: это выбор пользователя, не состояние
обработки). Слот вне потока: подвал не сдвигается, когда приходит статус. Смена кадра — на
месте: новый адрес декодируется вне DOM и проявляется поверх прежнего, прежний остаётся до
готовности нового, без плашки и мигания; под `prefers-reduced-motion` — простая замена.

**Действия.** Секция ВЫРАВНИВАНИЕ (сразу после ДЕТАЛЕЙ; у пустой страницы вместо неё ПУСТОЙ
ОБОРОТ): у одной страницы — текст по статусу и одна кнопка фиксированной ширины в одном слоте:
«Оригинал» у выправленной, «Выровнять» у откаченной, у остальных кнопки нет. Тексты (B-42) не
называют вид искажения, с 2026-11-04 (правка автора) короче: «Страница выровнена.» /
«Исходный скан.» / «Не удалось выровнять.» (не по чему мерить; форма не сошлась и не помогло —
«Не удалось автоматически выровнять страницу.»); у отложенных — причина (место на диске, сбой) и «при
следующем запуске приложение попробует снова». Причина как категория остаётся в `title` пилюли и
глифа, в факте «Выравнивание» ДЕТАЛЕЙ и в пункте ПРОВЕРКИ. У выделения из нескольких —
«Из N выделенных: выровнено k, оригинал по вашему выбору — m, не выровнено …» и до двух кнопок с
числом: «Оригинал — k из N выделенных» действует только на выправленные, «Выровнять —
m из N» — только на откаченные (AE17); остальные не трогаются, подпись называет, к скольким
применится; без подходящих — одна недоступная кнопка и причина («ещё выравниваются» при
ждущих, иначе «нет выровненных»). Действие — правка журнала (`keepOriginal`): один `setEdits`,
один шаг undo, плашка «Есть ручные правки», «Вернуть» снимает, переживает перезапуск. Текущая,
выделение и фокус не меняются: после перерисовки фокус — на парной кнопке. Тост — только при
действии на выделение из двух и более страниц (часть карточек вне видимости); на одну — смена
видна в превью; undo тоста не даёт.

**Поздние статусы.** Статусы, пришедшие уже в `editor` (перезапуск без кэша, досканирование,
пересчёт после обновления приложения), меняют пометки по одной; тост один на порцию, когда не
осталось ни ждущих, ни пересчёта в ходу: «Выровнено ещё N стр.» (впервые выровненные) или
«Выравнивание пересчитано[ — выровнено ещё N стр.]», если в обработку встала страница со
статусом или с файлом прежних версий. После обновления приложения (смена версии геометрии или
детектора, B-19) страница с файлом прежних версий показывается выправленной сразу, без «ждёт»;
признак «пересчёт идёт / отложен» ставит ядро — renderer версий не знает. Отложенный пересчёт
(мало места, сбой) порцию не держит и из неё выходит: тосты по другим страницам приходят, порция
из одних отложенных тоста не даёт; у такой страницы секция ВЫРАВНИВАНИЕ говорит: «Показан
выправленный вид прежней версии приложения. Пересчёт отложен: не хватило места на диске — …» /
«… Пересчёт не удался из-за сбоя — при следующем запуске приложение попробует снова.», кнопка
«Оригинал» на месте; карточка, пилюля и сводка выделения из нескольких пересчёт не
различают — страница выровненная. Пока статусы идут, сохранение недоступно (раздел 7.3); «Не
трогать» — ничего из этого раздела не рисуется, кроме ряда `setup`.

## 7. Модалки

Общая анатомия: шапка (заголовок, подзаголовок, иногда кикер со статусной точкой), тело
секциями с кикерами, футер (слева статусная строка, справа «Отмена» и первичное действие).
Движение (B-4, `handoffs/2026-10-b4-motion.md`): затемнение проявляется за 150 мс, окно
поднимается на 6 px за 180 мс; закрытие — гаснет за 120 мс, ввод снят сразу; модалка,
открывающая модалку (`newscan` → `save`), — затемнение не моргает; смена содержимого меняет
высоту окна за 200 мс. Закрытие — «Отмена» или действие. Esc (B-11) — то же, что кнопка отмены
или закрытия модалки: «Отмена», «Понятно» в `mismatch`, «Закрыть» и «Готово» в итоге `save`;
когда эта кнопка недоступна (запись в `save`, удаление в `newscan`), Esc без действия; во время
подключения в `device` «Отмена» доступна и Esc отменяет подключение. Модалка несовпадения набора
— решение без отмены, Esc её не закрывает. Обработанный Esc экрану под модалкой не достаётся.
Клик вне окна — без действия.

### 7.1. `device` — подключение сканера

**СЕТЕВЫЕ СКАНЕРЫ.** Пока идёт поиск — три скелетона с пульсацией и сдвигом фазы. Потом —
список: имя, адрес, статус справа. Устройство **без автоподачи** приглушено, со статусом
«нет автоподачи», курсор «недоступно», выбрать нельзя. Выбранное подсвечено.

**ВВЕСТИ АДРЕС** (до B-43 — «АДРЕС ВРУЧНУЮ»)**.** Поле с подсказкой «адрес сканера в сети», всегда на виду. Под ним
сворачиваемое «Дополнительно» с тремя полями: Схема — переключатель на два положения
HTTPS / HTTP (не текстовое поле), Порт — только цифры, плейсхолдер следует за схемой
(443 / 80), Путь — плейсхолдер `/eSCL`. Нетронутое поле уходит в ядро как «не названо»:
схема тогда берётся из URL в поле адреса или HTTPS, порт — по умолчанию для схемы, путь —
`/eSCL` (реализация M1 — `handoffs/2026-10-m1-states.md`, Behaviour).

**Статусная строка футера** — состояния: «Идёт поиск сканеров в сети…» · «Найдено N
устройств · поиск продолжается» · отказ подключения красным. Пустой поиск дольше 10 с (S7)
показывает текст в области списка — окончательный текст без AirPrint / Bonjour, с запросом
брандмауэра Windows (решение автора, сессия 6 M1; Copy handoff'а). Сбой поиска (S8) тоже
стоит в области списка, статусная строка при этом пустая.

**«Подключить»:** выбранное в списке устройство подключается сразу. Иначе берётся адрес из
поля; пустой — подсказка «Выберите сканер в списке или введите адрес»; негодный ввод
(не хост, не IP и не URL) — свой текст, несуществующее имя — текст причины `dns`
(Copy → `errors.*`); порт в «Дополнительно» вне 1–65535 — «Порт должен быть от 1 до 65535.»
там же, в строке статуса, до отправки команды (B-17). Успех закрывает модалку и показывает тост
«Сканер подключён: …» с именем сканера из ответа ядра; у безымянного — введённый адрес (B-17).

Выбор в списке очищает поле адреса, и наоборот — ввод адреса снимает выбор. Два источника
адреса не могут быть активны одновременно.

**Шаг подтверждения смены устройства** (B-29; handoff `handoffs/scanner-change.md`, вариант 1b).
Ядро на «Подключить» ответило «нужно подтверждение»: по адресу или имени запомненного сканера
отвечает устройство, не доказанное тем же (другой сертификат, HTTP вместо него, другой
идентификатор). Модалка та же: секция СЕТЕВЫЕ СКАНЕРЫ и «Дополнительно» скрыты, поле адреса
приглушено и недоступно с прежним вводом, под ним карточка `alertdialog`: заголовок «По этому
адресу отвечает другое устройство», имя устройства из пробы (у безымянного — «Сканер без
имени») и адрес, текст «Это не тот сканер, что использовался раньше…», строка «ЗАМЕНИТ сканер
{{имя}}» и — только когда у смены есть цена — строка последствий: прерванный проход
(«…продолжить будет нельзя. Полученные страницы останутся на месте.») или ожидание оборотов
на `flip` («…документ соберётся с двух устройств…»). Причину шаг не называет; отпечаток,
сертификат и идентификатор не показываются. Футер: «Отмена» (начальный фокус — Enter по
привычке шаг не проскакивает) и «Подключить это устройство». Подтверждение шлёт только
одноразовый токен показанной пробы; на время ожидания — `aria-busy`, статус «Подключаемся
к …», повторное нажатие ничего не делает. Успех — как у обычного подключения (тост «Сканер
подключён: …»); не записались настройки — модалка закрывается, тост «Сканер подключён, но
настройки не записались. После перезапуска приложение спросит о нём снова.» «Отмена» в шаге
возвращает к вводу с прежним адресом и гасит пробу; Esc закрывает модалку; в обоих случаях
прежний сканер остаётся запомненным, строка устройства на `setup` прежняя. Отказы
подтверждения возвращают к вводу с текстом в статусной строке: проба устарела или ответ уже не
актуален → «Не удалось подключиться: пока вы решали, приложение уже перепроверило адрес.
Подключите ещё раз.»; идёт сканирование → «Сменить сканер сейчас нельзя: идёт сканирование…».

После подтверждённой замены плашка прерванного прохода в `editor` (S17) меняет текст: сканер
готов на хосте сканера прохода, а досканировать нельзя — «Полученные страницы на месте.
Сканер, на котором начат проход, по этому адресу больше не отвечает — досканировать нельзя.
Оставьте проход как есть или начните новое сканирование.» без ссылки и без «Досканировать
остаток»; фокус — на «Оставить как есть». Другой сканер на другом хосте — прежний текст со
ссылкой «подключите заново».

### 7.2. `add` — добавить скан к документу

Реализовано в M3.5 (`handoffs/2026-10-m3-5-states.md`, S2). Заголовок «Добавить страницы к
документу», подзаголовок «Новые страницы станут отдельным набором — их можно двигать,
поворачивать и удалять, как остальные».

**ЧТО СКАНИРУЕМ** — две карточки-радио (M4.5, S1–S2): «Двустороннее сканирование» («Два
прохода с разворотом на 180°, как основной документ»; выбрана по умолчанию) и «Одностороннее
сканирование» («Один или несколько листов, обороты не сканируем»). Прежние «Односторонние
листы» и «Один лист» M3.5 слиты в одностороннюю: обе сканировали только лицо. Число листов
приложение не знает и не спрашивает (раздел 3). В режиме раздельных наборов двусторонняя
выключена (`aria-disabled`, вне кольца стрелок), заметку заменяет причина «Недоступно, пока
документ не собран — сначала соберите документ», выбрана односторонняя.

**КУДА ВСТАВИТЬ** — два сегмента: «В конец документа» и «После текущей страницы»; по умолчанию
— «В конец документа» (решение автора на приёмке M4.5, 2026-10-24; в M3.5 было «после
текущей»). При пустой ленте «После текущей» недоступна с причиной, набор
идёт в конец ленты. В режиме раздельных наборов (M3.6, S10) второй сегмент — «В конец набора»:
якорь — последняя видимая страница группы текущей; добавленный набор встаёт в группу якоря и
входит в её счётчик. Вставки «в начало набора» нет — переносом (бэклог).

**Футер без сводки** (B-44). Сводка «Двустороннее · после стр. 7 (лицо листа 4)» из M3.5 снята:
её текст менял высоту модалки при смене места и на миг давал вертикальный скролл, а место и
сценарий называют сами сегменты и карточки. Футер — только «Отмена» и «Начать скан», прижатые
вправо. Под карточками — строка сканера «готов · 300 dpi · …» или «Сканер не подключён —
подключите его в настройках»; без готового сканера «Начать скан» недоступна, карточки и
сегменты работают. Начальный фокус — «Отмена»: запуск — действие с бумагой, случайный Enter его
начинать не должен. Карточки и сегменты — по одной остановке Tab, выбор стрелками.

**Якорь.** «После текущей страницы» — ключ страницы в превью (при мультивыделении — её же).
«В конец документа» — последняя видимая страница документа текущей страницы, а не «конец
ленты»: набор остаётся в этом документе и при будущих границах. Якорь фиксируется в момент
«Начать скан» и пишется в проход журнала (ADR 0004, амендмент 2026-10-07). Пустые обороты
(M4, S16; B-13): «После текущей страницы» ставит набор после листа текущей — за её склеенными
оборотами, и с лица, и с оборота, при скрытых и при показанных пустых; вставка между лицом и
его оборотом разбила бы лист. Правило живёт в renderer: ядро получает ключ хвоста листа и
ставит блок за ним буквально.

**Размещение.** Набор встаёт сразу за якорем — перед наборами, прикреплёнными к нему раньше:
два добавления подряд с одной текущей идут в обратном порядке, чтобы продолжить за набором,
выбирают его последнюю страницу. При ручном порядке новые страницы любого прохода встают за
ближайшим предшественником по автопорядку, который есть в ручном порядке, — без шага undo,
без плашки и без тоста (пересмотр M3, где они уходили в конец ленты с тостом). Границы
документов остаются перед теми же страницами.

**Запуск.** «Начать скан» всегда закрывает модалку — экран уходит на `scan` раньше, чем ядро
начнёт задание. Один запуск на нажатие. Отказ — синхронный или после старта (лоток пуст, занят,
предел проходов) — одним каналом: тост «Не удалось начать: …», экран остаётся `editor`, плашка
прерванного прохода не появляется. После одностороннего набора — сразу `editor`: текущая —
первая добавленная страница, выделена она одна, лента прокручена к ней (фокус на её карточке),
тост «Добавлено N стр.». После пары (M4.5) — `flip` набора, обороты, пауза `merge`, затем то же:
текущая — первая показанная страница набора, один тост на набор (со скрытыми — «Добавлено 5
стр. — скрыт 1 пустой оборот»; при несовпадении — после модалки набора). Обрыв набора — плашка
«Добавление прервалось после страницы N», у пары — «Лица набора Д1 прервались после страницы
2» / «Обороты набора Д1 прервались после страницы 2 из 3» (S10), с действиями прерванного
прохода; досканирование продолжает тот же проход, пока он прерван, «+ Добавить» недоступна.

### 7.3. `save` — сохранение

**ЧТО СОХРАНЯЕМ** — два сегмента: «Отдельные файлы» (по границам) и «Один файл» (все
страницы подряд). По умолчанию — «Отдельные файлы», если документов больше одного. При одном
документе «Отдельные файлы» недоступны с подписью «границы ещё не отмечены»; нажатие —
тост «Сначала отметьте границы между документами».

**ФАЙЛЫ · N** — строки с редактируемыми именами и числом страниц (размер до сборки
неизвестен); длинный список прокручивается. В «Отдельных файлах» строки — документы, имена —
их названия из ленты. В «Одном файле» строка одна: при одном документе — его имя, при
нескольких — имя файла, по умолчанию «Скан ГГГГ-ММ-ДД». Тронутые в модалке имена документов
при «Сохранить…» сначала записываются в правки (один шаг undo) — редактор и файлы не
расходятся. Это касается строк-документов: «Отдельных файлов» или «Одного файла» при одном
документе. Имя единого файла при нескольких документах в журнал не пишется, и правки имён
документов при таком сохранении тоже не уходят. Пустое имя —
имя по умолчанию; набранное «.pdf» снимается. Запрещённые символы, длину и занятость решает
ядро: санитизация, суффикс « (2)».

**ПАПКА** — путь и «Выбрать…» (системный выбор папки; отказ ничего не меняет). Выбранная
папка помнится между запусками (настройки), по умолчанию — «Документы». Если запомненной папки
на диске нет (вынута флешка), предлагаются «Документы», а запомненная не забывается. Если путь
не прочитался (исключение моста), поле пустое, а строка статуса объясняет: «Папка не прочиталась
— запись пойдёт в папку по умолчанию; «Выбрать…» покажет путь.»; запись не блокируется — папку
знает ядро; «Выбрать…» заполняет поле и при отказе в диалоге (B-17).

**Сводка** — «Файлов», «Страниц всего», «Пустых оборотов» (M4), «Выровнено» (M6), «Формат:
PDF». Блок второстепенный (B-43): ключи — как в общей таблице фактов, значения — голосом
метаданных строки «Файлы» (`--font-size-s`, обычная насыщенность, `--color-text-hint`), а не
первичным текстом. С B-44 так выглядит вся таблица фактов, включая ДЕТАЛИ инспектора
(замечание автора: значения первичным текстом «слишком яркие»).

**Пустые обороты** (M4, `handoffs/2026-10-m4-states.md`, S14). Счёт страниц — «Страниц
всего», «N стр.» у строк, «все N стр. подряд» — по страницам, которые уйдут в файл: лента
без скрытых, независимо от переключателя «Пустые» (он только показывает). Ряд
«Пустых оборотов» — «скрыто N — не попадут в файл» / «помечено N — останутся в файле» /
«не найдено»; при «Оставлять» ряда нет. Строка документа из одних скрытых — «только пустые —
0 стр.» цветом `--color-danger`. Два отказа ядра видны **до клика** — «Сохранить…»
недоступна, статус объясняет: `documentBlank` — «Документ «Приложение» состоит из одних
пустых оборотов — покажите их переключателем или уберите границу.» (с именем документа;
«Один файл» при этом доступен, пока есть хоть одна показанная страница); `blankPending` —
«Оценка пустых оборотов: ещё N стр. — кнопка станет доступна сама.» — снимок с
завершёнными оценками снимает блок без действий пользователя. Приоритет — `documentBlank`
выше `blankPending`: ждать оценку бесполезно, нужна правка. Отказ ядра теми же кодами —
страховка от гонки, текст причины в статусе (`errorReasons.sessionConflict.*`).

**Выравнивание** (M6, раздел 6.10). Ряд «Выровнено» — «N стр.» или «нет», с хвостом «· ещё K
в обработке» или «· не выровнено M» (хвост «— уйдут как есть» снят в B-43); при «Не трогать» ряда нет. Отказ
`straightenPending` виден до клика: «Выравнивание: ещё N стр. из M — кнопка станет доступна
сама.»; вместе с оценками пустых — один статус `bothPending` «Оценка пустых оборотов и
выравнивание: ещё N стр. — кнопка станет доступна сама.» (сумма). Приоритет — `documentBlank`
выше обоих. Снимок с нулём ждущих снимает блок без действий пользователя. Повтор пакета после
отката страницы или пересчёта — отказ «данные изменились»: пакет собирается заново целиком.

**Запись и итог** (M3):

- Пока идёт запись, модалка занята: закрыть нельзя, правки редактора недоступны.
- Всё записано под запрошенными именами — модалка закрывается, тост на 6 с с кнопкой
  «Новое сканирование».
- Хоть одно имя изменено ядром (занято, санитизировано) — модалка остаётся в **ИТОГЕ** с
  фактическими именами и пометкой причины, основная кнопка «Готово».
- Частичный сбой — ИТОГ: записанные ✓, неудавшиеся ✕ с текстом ошибки, статус «Записано N
  из M.». Основная кнопка — «Повторить неудавшиеся»: тот же пакет, только недописанные файлы,
  в ту же папку. Вторичная — «Закрыть»: пакет забыт, следующее сохранение пишет всё заново,
  уже записанное не трогается. «Сохранено» ставится только при полном успехе.
- Повтор отклонён, потому что пакета больше нет (лента изменилась, другая сессия, сменились
  режим или число документов), — причина в статусе, модалка возвращается к выбору. Иной
  отказ повтора (например, папка недоступна) — причина в статусе, ИТОГ и «Повторить
  неудавшиеся» остаются.

Если модалка открыта из `newscan` («Сначала сохранить текущий»), после полного успеха сессия
закрывается сама и показывается тост «… — можно закладывать новые листы».

### 7.4. `newscan` — новое сканирование

**Единое имя действия — «Новое сканирование».** Так называются кнопка в тосте после сохранения и
заголовок этой модалки («Начать новое сканирование?»); кнопка тулбара с B-42 несёт короткую
подпись «Новый скан» (две кнопки левой зоны поровну), кнопка плашки прерванного прохода — ту же. Действие одно и то же везде: закрыть текущую сессию и вернуться на `setup` (R14
плана M1). **Слово «пачка» — рабочий термин спеки и плана, в тексты интерфейса оно не идёт**
(решение автора, сессия 6 M1): про бумагу в лотке — «листы», про отсканированное — «страницы».
Тексты макета с «пачкой» (подсказка `setup`, `flip`, карточки `newscan`) переписываются при
реализации этих экранов.

Кикер отражает состояние: «ДОКУМЕНТ ПУСТ» · «ТЕКУЩИЙ ДОКУМЕНТ СОХРАНЁН» · «ЕСТЬ
НЕСОХРАНЁННЫЕ ИЗМЕНЕНИЯ» («СОХРАНЁН» — с акцентной точкой, «ПУСТ» и «НЕСОХРАНЁННЫЕ» — с
янтарной). Один кикер на «несохранённое»
покрывает и новые страницы, и правки после сохранения: для решения разницы нет. Текст под
заголовком объясняет, что именно будет потеряно, числом страниц; удалённые из ленты страницы
названы отдельно — они тоже сотрутся окончательно. «ДОКУМЕНТ ПУСТ» — все страницы удалены, но
их ещё можно вернуть.

Скрытые пустые обороты (M4, S15): «N стр.» в тексте — по файлу, без скрытых, чтобы сходиться с
лентой; скрытые названы отдельным предложением в конце — «Скрытые пустые обороты (N стр.)
тоже будут стёрты.»: их файлы стираются вместе с остальными. Лента из одних скрытых без
удалённых — только это предложение: про Ctrl+Z говорить нечего. Кикер и карточки — как
прежде.

Варианты: «Закрыть текущий и начать новое сканирование» и — только если есть несохранённое —
«Сначала сохранить текущий». Внизу «Остаться в документе». В режиме раздельных наборов (M3.6,
S11) кикер «ДОКУМЕНТ НЕ СОБРАН» (янтарный), текст про наборы и удаление N стр.; карточки
«Сначала сохранить» нет — сохранять нечего, ядро откажет (`notAssembled`).

Начальный фокус — «Остаться в документе». «Сначала сохранить текущий» открывает `save`;
после полного успеха сессия закрывается (раздел 7.3).

Если страниц нет вообще — ни в ленте, ни удалённых, — модалка **не показывается**: терять
нечего, рабочая область очищается сразу.

Кнопка «Новое сканирование» в тосте после сохранения открывает эту модалку, а не закрывает
сессию молча: закрытие стирает страницы сессии с диска — только через модалку.

### 7.5. `mismatch` — не сошлись проходы

Кикер «НЕ СХОДЯТСЯ ПРОХОДЫ» с янтарной точкой, заголовок с фактическими числами по сторонам, без
порядковых номеров проходов (B-3): «Лицевых сторон 12, оборотов — 11», при лишних оборотах —
«Оборотов больше, чем лицевых сторон: 13 против 12»; и объяснение по исходу.

**Трёх вариантов действия, которые есть в макете, быть не должно.** Решено при разборе:
модалка только сообщает; действие одно — «Понятно». Показ выводится из снимка (план M2,
KTD-8): первый вход в `editor` за процесс при неподтверждённом несовпадении, включая вход
после перезапуска; постоянная видимость после закрытия — пометка непарного листа в ленте.

**Текст про режим (M3.6, `handoffs/2026-10-m3-6-states.md`, S6; заменил Copy M3.5).** Три
исхода — оборотов меньше, оборотов больше, проход оборотов принят коротким — объясняют, что
документ не собран, лица и обороты лежат отдельными наборами в порядке будущего документа, и
три шага: «+ Добавить листы» (или удалить лишнее) → поставить на место переносом → «Собрать
документ». Пропущенный лист текст по-прежнему **не называет**.

**Кнопки «Досканировать» нет — принятое решение** (автор, план M3.5): предвыбор «Один лист ·
После текущей» закреплял бы ложную уверенность в том, какой лист пропущен. Лист ставит
пользователь: выбирает страницу и жмёт «+ Добавить». Показ (M3.6, R20): первый вход в `editor`
за процесс, пока режим наборов активен и проход оборотов завершён или принят, — в том числе
после перезапуска и при добавленных наборах (режим активен — объяснение нужно; пересмотр
M3.5, где добавленный набор показ снимал); при прерванном проходе — после решения по плашке;
после сборки и в режиме пар не показывается.

### 7.6. Несовпадение набора (M4.5)

`modals/SetMismatchModal.tsx`, `handoffs/2026-10-m4-5-states.md`, S7. Показывается в `editor`, когда обороты
двустороннего набора завершены с неравным числом, а решения по набору нет. Кикер «ОБОРОТЫ
НАБОРА НЕ СОШЛИСЬ» с янтарной точкой, заголовок «В наборе Д1 лиц 3, оборотов 2», текст: лист,
скорее всего, не прошёл или слипся; лица и обороты лежат рядом, ничего не удалено; что делает
каждое действие — с числом удаляемых оборотов.

Действия: **«Переснять обороты набора»** (`btn--tinted`, слева) — ядро отбрасывает проход
оборотов набора вместе с правками на его страницах, модалка закрывается, экран по снимку
уходит на `flip` набора; **«Оставить как есть»** (первичная, справа, начальный фокус) — решение
пишется в журнал, подблоки остаются. Пока идёт отброс — «Убираем обороты…», обе кнопки
недоступны; отказ — строкой в модалке, модалка остаётся. Esc и клик по подложке не закрывают,
фокус заперт.

Показ выводится из снимка: закрывает модалку только решение, после которого несовпадения без
решения нет, — поэтому после перезапуска без решения она снова. Подтверждения за процесс, как у
`mismatch`, нет (отклонение от handoff'а, журнал 0008): та модалка только сообщает, эта
предлагает удалить страницы. Короткие обороты, принятые плашкой прерванного прохода, считаются
решением «оставить» — модалки нет. Прерванные обороты набора решает плашка, а не модалка: ядро
отказывает модалке в решении по ним (`passInterrupted`).

## 8. Тосты

Одна строка внизу по центру, тёмная плашка. Появляется с подъёмом за 180 мс, по сроку или
действию гаснет за 120 мс (B-4). Новый тост гасит предыдущий — сразу, без анимации ухода. Тост может нести кнопку действия (M3): нажатие гасит тост и выполняет действие.
Тост лежит поверх затемнения модалок, поэтому действие, открывающее модалку, при уже
открытой модалке ничего не делает. «Открыть папку» (M3.5, пересмотр M3) открывает в
проводнике папку последнего записанного пакета — её помнит ядро до выхода из приложения;
«Новое сканирование» осталось кнопкой тулбара (подпись «Новый скан», B-42).
