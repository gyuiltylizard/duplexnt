# Duplexn't — спецификация UI

Поэкранный структурный и поведенческий контракт. Обновляется в той же вехе, что меняет
экран.

**Происхождение.** Составлено разбором макета `mock/Сканер ADF.dc.html` — разметки и класса
поведения в нём. Разбор статический: макет читался, а не запускался, поэтому числа и
переходы взяты из кода, а не с экрана. Визуальный язык — `DESIGN_SYSTEM.md`, здесь его нет.

**Как читать.** Раздел «Строительные леса макета» перечисляет то, что в продукт не едет:
демо-данные, демо-переходы и панель прыжков по экранам. Раздел «Чего в макете нет»
перечисляет дырки, которые придётся закрывать решением, а не чтением макета. Всё остальное —
контракт: так оно спроектировано и так должно работать.

---

## 1. Общая модель

Одно окно 1280×800, без вкладок. В каждый момент показан **один экран** из пяти: `setup`,
`scan`, `flip`, `merge`, `editor`. Поверх экрана может стоять **одна модалка**: `device` —
над `setup`, остальные (`add`, `save`, `mismatch`, `newscan`) — над `editor`. Модалка
закрывает экран затемнением и перехватывает работу целиком; двух модалок одновременно не
бывает.

Поверх всего — **тост** внизу по центру: одна строка текста, иногда с кнопкой действия.
Тостов тоже не больше одного, новый гасит предыдущий.

`setup`, `flip` и `editor` ждут человека. `scan` и `merge` — процессные: уходят сами,
`merge` вообще без единого органа управления.

### Граф переходов

```
setup ──«Сканировать лицевые стороны»──→ scan (проход 1)
  └─ нет сканера → модалка device, скан не начинается

scan ──проход дошёл до конца──→ пауза ──→ flip        (после прохода лиц)
  │                                  ├──→ merge       (после прохода оборотов)
  │                                  └──→ editor      (после добавленного набора, M3.5)
  └──«Остановить»──→ экран, с которого запущен проход (setup · flip · editor)

flip ──«Пачка в лотке — сканировать обороты»──→ scan (проход +1)
  └──«Обороты не нужны»──→ merge

merge ──сама──→ editor

editor ──«+ Добавить» → модалка add → «Начать скан»──→ scan (добавленный набор)
  └─ отказ запуска → тост, экран остаётся editor

editor — конечный экран: сохранение, добавление скана, новое сканирование
```

Второго прохода без первого не бывает: `flip` достижим только из завершившегося лицевого
прохода. Добавленный набор (M3.5) — однопроходный: после него ни `flip`, ни `merge`, сразу
`editor`. Роль прохода — поле журнала (лица / обороты / добавленный набор), а не номер
(ADR 0004, амендмент 2026-10-07).

**Временное ребро M1 снято в M2:** `flip` и `merge` рендерятся, полные тексты `setup` и
`scan` возвращены (план M1, KTD-25 → план M2, U8). Экран по-прежнему выводится из снимка
чистой функцией; `merge` — эфемерная пауза поверх этого вывода (план M2, KTD-5). Состояния
сверх макета — `handoffs/2026-10-m1-states.md`, `handoffs/2026-10-m2-states.md`,
`handoffs/2026-10-m3-states.md`, `handoffs/2026-10-m3-5-states.md`,
`handoffs/2026-10-m3-6-states.md` и `handoffs/2026-10-m4-states.md`.

## 2. Экран `setup` — настройка и запуск

### Раскладка

Две колонки. Слева сверху вниз: кикер «НОВЫЙ ДОКУМЕНТ», заголовок «Сканируем обе стороны в
два прохода», лид с объяснением сценария, группа параметров, кнопка запуска. Справа — узкая
колонка «КАК ЭТО РАБОТАЕТ» с четырьмя пронумерованными шагами.

### Строка устройства

Первая строка группы параметров, два состояния:

- **подключено** — имя устройства, точка статуса с подписью «готов» или «занят», справа
  текстовая кнопка «Сменить» (открывает модалку `device`);
- **не подключено** — «Сканер не подключён» и первичная кнопка «+ Добавить сканер».

### Параметры

Четыре строки, каждая — подпись слева и ряд сегментов справа. У сегментов есть подсказки в
`title`.

| Параметр       | Значения                        | Подсказки                                                           |
| -------------- | ------------------------------- | ------------------------------------------------------------------- |
| Цвет           | Ч/б · Оттенки серого · Цвет     | —                                                                   |
| Разрешение     | 200 dpi · 300 dpi · 600 dpi     | быстрее, мельче файл · обычный текст · мелкий шрифт и печати        |
| Размер листа   | A4 · Letter · Авто              | 210×297 мм · 216×279 мм · определять по листу                       |
| Пустые обороты | Скрывать · Помечать · Оставлять | не попадут в файл · останутся, но с меткой · сохранить всё как есть |

По умолчанию: оттенки серого, 300 dpi, A4, пустые обороты скрывать. Внизу группы —
текстовая кнопка «Сбросить параметры», возвращающая эти значения.

Списки значений в макете заданы константами. Цвет, разрешение и размер листа с M1 строятся
из `capabilities` устройства и меняются при смене источника — см. «Расхождения с техбазой».
Ряд «Пустые обороты» (M4) — другого рода: это настройка приложения, а не возможность
устройства (ADR 0004, амендмент 2026-10-22), значения — словарь приложения, ряд доступен и
без подключённого сканера. «Сбросить параметры» возвращает и его — к «Скрывать». Выбранный
режим замораживается в сессии при старте первого прохода и в редакторе не меняется (раздел
6.9).

### Запуск

Первичная кнопка «Сканировать лицевые стороны», под ней подсказка «Загрузите пачку лицом
вверх, первая страница сверху».

**Гейтинг:** если сканер не подключён, нажатие не запускает скан, а открывает модалку
`device`. Кнопка при этом не выглядит заблокированной — решение спорное, но так
спроектировано.

## 3. Экран `scan` — идёт проход

### Раскладка

По центру сверху вниз: тег прохода, иллюстрация подачи, счётчик, строка параметров, лента
последних страниц, кнопка «Остановить».

- **Тег прохода** — «ПРОХОД N · ЛИЦЕВЫЕ СТОРОНЫ» для прохода лиц, «ПРОХОД N · ОБОРОТЫ» для
  прохода оборотов, «ДОБАВЛЯЕМ СТРАНИЦЫ» на `--color-pass-3` для добавленного набора (M3.5):
  без номера — «ПРОХОД 3» после «Обороты не нужны» читался бы как «второй потерян».
- **Иллюстрация** — стопка листов, лист уходит вниз в лоток (цикл `feed`), под ним полоса
  с пульсацией. Полоса **не отражает долю**: это индикатор активности, а не прогресса.
- **Счётчик** — главная строка состояния экрана, крупнее остального (`--font-size-xl`,
  полужирный, основным цветом текста). Содержание — ниже.
- **Строка параметров** — «300 dpi · оттенки серого · A4», под счётчиком, моноширинным и
  приглушённым: подчинена ему.
- **Лента** — пять миниатюр последних страниц, затухающих к краю (непрозрачность 1 → 0,32
  шагом 0,17).

### Поведение

Страницы приходят по одной, пока устройство не ответит «больше нет». После последней — пауза,
затем переход: на `flip`, если проход лицевой (роль, не номер: план M2, KTD-4), на `merge`
после прохода оборотов, сразу на `editor` после добавленного набора (M3.5, `merge` и
`mismatch` не показываются). Досканирование прерванного добавленного набора называет его в
мете: «досканируем добавленный набор · до обрыва было N».

### Счётчик

**Сколько листов в лотке, приложение не знает.** Сканер их не считает, страницы приходят по
одной до ответа «конец». Но сами полученные страницы считаются в реальном времени: каждая
приходит отдельным ответом. Отсюда две формы счётчика.

| Проход      | Текст                   | Почему так                                               |
| ----------- | ----------------------- | -------------------------------------------------------- |
| лица        | «Отсканировано 7»       | общего числа нет и взяться ему неоткуда                  |
| обороты     | «Отсканировано 7 из 12» | ожидаемое известно: столько листов дал предыдущий проход |
| добавленный | «Отсканировано 3»       | как у лиц: число листов приложение не спрашивает         |

Счётчик отстаёт максимум на одну страницу — ту, что сейчас едет: она засчитывается, когда
дошла целиком.

**Ожидаемое число для второго прохода — это результат первого, а не ввод пользователя.**
Нигде в интерфейсе число листов не спрашивается и не задаётся.

Счётчик может **перевалить за ожидаемое** («Отсканировано 13 из 12»): в первом проходе мог
случиться двойной захват. Прятать или подрезать это не нужно — это тот же сигнал
несовпадения, просто увиденный раньше, чем закончится проход.

### Отмена

«Остановить» прекращает проход, **отбрасывает страницы этого прохода** и возвращает на экран,
с которого он был запущен: первый проход — на `setup`, проход после разворота — на `flip`,
проход из модалки `add` — на `editor`. Завершённые проходы остаются: единица удаления — проход
([ADR 0004](../decisions/0004-data-model.md)). «Остановить» на первом сегменте добавленного
набора убирает набор целиком — лента и правки прежние. При досканировании прерванного прохода
«Остановить» отбрасывает только досканированное и возвращает к прерванному проходу. В макете
«Остановить» всегда ведёт на `setup` — это расхождение с макетом, а не недосмотр спеки.

Подтверждения нет, и это решение, а не недосмотр: отменяют обычно потому, что в лоток легли
не те документы или пачка легла не той стороной, и сохранять полученное незачем. Отмена —
единственный случай, когда отсканированное пропадает; от сбоя оно не теряется.

## 4. Экран `flip` — инструкция по развороту

Самый ответственный экран: ошибка человека здесь собирает документ молча и неправильно.

### Раскладка

Центрированная колонка: кикер «ШАГ 2 ИЗ 3 · ЛИЦА ГОТОВЫ: N листов», заголовок «Разверните
пачку на 180°», лид «Переворачивать не нужно: из податчика пачка вышла оборотами вверх.
Возьмите её целиком, разверните на 180° и положите обратно в лоток». Ниже — две зоны,
разделённые вертикальной линией: слева анимированная иллюстрация с подписью «пачка целиком —
разворот на 180°», справа чеклист из трёх пунктов. Внизу две кнопки.

### Иллюстрация

Карточка-лист с подложкой, на листе стрелка `↑` и подпись «ВЕРХ» — маркер ориентации, по
которому читается поворот. Цикл `turn180`, 3,8 с: лист появляется сверху, поднимается,
поворачивается на 180° **в плоскости** (`rotate`, не переворот), опускается, держит
результат около 0,45 с и уходит вниз, оставаясь развёрнутым. Обратного поворота в цикле нет:
действие показывается один раз и не отменяется.

### Чеклист

1. Не переворачивайте листы — из податчика они вышли оборотами вверх.
2. Не разбирайте пачку: обороты придут в обратном порядке, приложение это учтёт.
3. Если один лист застрял — начните второй проход и вставьте его отдельно.

### Действия

- **«Пачка в лотке — сканировать обороты»** (первичная) — запускает следующий проход.
  Ожидаемое число листов для него — результат первого прохода; оно идёт в счётчик (раздел 3),
  но проход не обрывается по достижении этого числа, а идёт до ответа устройства «конец».
- **«Обороты не нужны»** (текстовая) — пропускает второй проход и уводит на сборку. Так
  односторонняя пачка закрывается без возврата в настройки.

**Автоперехода здесь нет намеренно.** Пачку разворачивает и кладёт человек; когда он закончил
— знает только он, и подтверждение готовности за ним. Опрос `ScannerStatus` нужен не для
перехода, а для подсказки: увидели `ScannerAdfLoaded` — подсветили кнопку второго прохода.
Эта подсветка уехала в пост-MVP вместе с остальным опросом состояния устройства.

## 5. Экран `merge` — сборка

Заголовок, диаграмма из двух рядов ячеек (лица и обороты, обороты пульсируют), итоговая
полоса из 24 ячеек с чередованием цветов проходов, статусная строка «совпало пар: 12 ·
пустых оборотов: 3 · время 0,8 с».

Экран **полностью процессный**: ни одного органа управления, уходит сам через 1,6 с (1,2 с,
если пришли сюда через «Обороты не нужны»); с M4 это минимум — см. ниже. Отменить или
задержать сборку нельзя.

Статусная строка в макете — константа. С M2 это сводка фактического результата, и именно
она первой сообщает о несовпадении проходов; заголовок — «Сопоставляем проходы» (мы-форма,
как все тексты приложения). Ряд «документ» повторяет фактический порядок сборки.

При несовпадении проходов (M3.6, `handoffs/2026-10-m3-6-states.md`, S7) ряда «документ» нет —
документа ещё нет: формула «Проходы не сошлись — лица и обороты лежат отдельными наборами»,
статус «не сошлось: лицевых 12, оборотов 11 — документ соберёте в редакторе» (лишние обороты —
«лишних оборотов: 1 — документ соберёте в редакторе», принятый коротким — «проход оборотов
принят коротким: лицевых 12, оборотов 7»).

**Пустые обороты (M4, `handoffs/2026-10-m4-states.md`, S12).** Статусная строка получает
хвост: «· ищем пустые обороты…», пока оценки идут, затем «· пустых оборотов: 3» или
«· пустых оборотов: нет». Хвоста нет при режиме «Оставлять», без прохода оборотов («Обороты
не нужны») и в режиме раздельных наборов — там детектор не работал или страницы не
скрываются. Экран держится не меньше паузы, а при незавершённых оценках — дальше, до их
прихода, **без потолка** (решение автора 2026-10-22: страницы не должны исчезать из ленты
на глазах; потолок из плана отклонён). В режиме наборов ожидания нет: скрывать там нечего,
а экран без хвоста статуса выглядел бы зависшим. Оценки считаются во время прохода, так
что на живом устройстве ожидание сверх паузы практически не наступает; зависшая оценка
держит экран до перезапуска (раздел 11).

## 6. Экран `editor` — проверка и правка

Главный рабочий экран. Четыре зоны: тулбар сверху, лента миниатюр слева, превью по центру,
инспектор справа.

### 6.1. Тулбар

Слева: «↺ Новое сканирование» и «+ Добавить» (M3.5), обе поровну в левой зоне. «+ Добавить»
открывает модалку `add` (раздел 7.2) и недоступна с причиной в `title`: идёт запись
(«Документ сохраняется — дождитесь конца записи»), правка ещё в полёте («Правка ещё
записывается — секунду»), последний проход прерван («Сначала досканируйте прерванный проход
или оставьте его как есть»). К пустой ленте добавить можно. По центру: цветная метка документа, его название,
позиция («документ 2 из 3 · стр. 4 из 9») и, если на текущей странице границу поставить
можно, кнопка «+ Новый документ с этой страницы». Справа: первичная кнопка сохранения —
«Сохранить документ» или «Сохранить N файлов».

**Режим раздельных наборов (M3.6, S4–S5).** Пока проходы лиц и оборотов не сошлись, по центру
вместо метки документа — живые счётчики групп: янтарная точка и «Проходы не сошлись: лицевых
12, оборотных 11», при равных ненулевых — акцентная точка и «Наборы уравнены — соберите
документ»; кнопки «+ Новый документ с этой страницы» нет. Справа вместо «Сохранить» —
«Собрать документ», недоступная с причиной в `title` по фиксированному порядку: идёт запись
→ правка в полёте → последний проход прерван → «В наборах нет страниц» → «Не хватает N
оборотов» → «Не хватает N лиц». Точка «не сохранено» остаётся — документ правда не сохранён.
Клик — одна команда `assemble` на нажатие, до ответа кнопка недоступна, а правки, лента и
«Вернуть» заблокированы, как при записи; успех — тост «Документ собран: N листов» и обычный
редактор с лентой лицо 1, оборот 1, …; отказ — тост с причиной. Обратной команды нет: после
сборки удаление и перенос — обычные правки, «Вернуть» возвращает к записи сборки.

### 6.2. Лента миниатюр (слева)

Лента рисуется по **показанной ленте** (M4, `handoffs/2026-10-m4-states.md`, S1): в режиме
«Скрывать» скрытых ядром пустых оборотов в ней нет, пока не включён переключатель «добавить
пустые» (раздел 6.9). Панели выделения над лентой больше нет — она переехала в подвал (ниже
и раздел 6.5), миниатюры при появлении выделения не сдвигаются.

Страницы сгруппированы по документам. У каждой группы: разделитель (у всех,
кроме первой) с пилюлей «НОВЫЙ ДОКУМЕНТ», пунктиром и кнопкой «✕» для снятия границы;
заголовок с цветным номером, редактируемым названием и счётчиком страниц; сетка миниатюр.

**Режим раздельных наборов (M3.6, S1–S3).** Пока проходы не сошлись, групп документов нет —
две группы «Лицевые стороны · 12» и «Оборотные стороны · 11» с живыми счётчиками (лица в
порядке сканирования, обороты в порядке будущего документа) и разделитель между ними:
пунктир с подсказкой капсом «перенос через границу меняет набор», не фокусируемый
(`role="separator"`, озвучен). Полей имён, пилюль, «✕», split-бара и «Выделить в документ»
нет; номера миниатюр сквозные. Перенос — те же миниатюры и то же перетаскивание: группа
перенесённых страниц — группа страницы-цели (бросок «после последней лицевой» оставляет в
лицах, «перед первой оборотной» переносит), смешанное выделение переносится целиком; верхняя
половина разделителя — «в конец лиц», нижняя — «в начало оборотов», маркер дропа показывает
сторону; пустая группа — заголовок «· 0» и зона дропа «Перетащите сюда страницы оборотов».
Перенос через границу — правка порядка с явной границей: шаг undo и плашка «Есть ручные
правки». Стрелки, Shift-диапазон, Home/End ходят сквозь разделитель как по одной ленте.

**Миниатюра:** лист с имитацией строк, номер по порядку в наборе, подпись стороны «лицо» или
«оборот». Дополнительно:

- **тег** в подвале карточки — «об» у оборотов; «Д1», «Д2» и далее у добавленных наборов
  (M3.5) цветом `--color-pass-3`: порядковый номер набора среди наборов со страницами, не
  номер прохода (номера проходов после «Остановить» прыгают). У добавленной страницы нет ни
  «лица», ни «оборота»: `aria-label` — «Страница 8, добавленный набор 1». У лиц тега нет;
- ~~**пометка непарного листа**~~ — снята в M3.6: непарных больше нет, при несовпадении лента
  делится на наборы; подпись стороны («лицевая, 3-я в наборе лиц») — по группе, тег «об» — по
  происхождению (проход оборотов) и в группе лиц не исчезает;
- **метка «ПУСТО»** (M4, S2–S3) — пилюля по центру листа на `--color-text-subtle` у
  помеченного пустого оборота и у скрытого, показанного переключателем; показанная скрытая
  дополнительно — пунктирная рамка и приглушённый лист: в файл она не попадёт. `aria-label`
  несёт суффикс «, пустая» или «, пустая, скрыта — в файл не попадёт». В режиме раздельных
  наборов (M3.6) пустые помечены, а не скрыты — скроются после «Собрать документ»;
- **split-бар** — появляется при наведении на верх миниатюры у всех страниц, кроме первой:
  «+ Новый документ» или, если граница уже стоит, «⤺ Убрать границу». Уступает выделению
  (M3.5): пока зажат Ctrl/Shift или выделено больше одной страницы, бара нет ни у одной
  миниатюры, и клик с модификатором по верхнему краю — выделение, а не граница.

**Нумерация (M4).** Номер миниатюры и «стр. N из M» — позиции в показанной ленте: это номер
в будущем файле; при включённом переключателе скрытые встают на свои места и номера
пересчитываются. «Лист N» в ДЕТАЛЯХ и `aria-label` — по полной ленте: лист — свойство записи
сборки, скрытие его не двигает. Документ из одних скрытых страниц в ленте не рисуется (в
списке ДОКУМЕНТЫ В НАБОРЕ он есть — раздел 6.4).

**Скрытые хвосты (M4).** Пока скрытые не показаны, скрытый оборот, идущий в полной ленте
сразу за показанной страницей, — её хвост: едет за ней при переносе, удалении (одним шагом
undo — Ctrl+Z возвращает обоих; тост и кнопка «Удалить N стр.» считают только показанные) и
«Выделить в документ»; разрез ложится перед показанной страницей, хвост предыдущей остаётся
слева. При включённом переключателе выделение буквальное: что выделено, то и едет; удаление
показанной скрытой — обычное удаление.

**Подвал ленты (M4, S4–S6).** Постоянное место трёх строк под миниатюрами, сверху вниз:

1. панель выделения — «Выделено N стр. · Shift — диапазон, Ctrl — по одной», кнопки «Выделить
   в документ» (вне режима наборов) и «Снять»; при выделении больше одной страницы;
2. переключатель «добавить пустые» со счётчиком «скрыто: N» / «показано: N»; без найденных —
   недоступен со счётчиком «не найдено» или, пока оценки идут, «оцениваются…»; только в режиме
   «Скрывать», при проходе оборотов и вне режима раздельных наборов (после «Собрать документ»
   появляется);
3. тумблер «Повернуть обороты на 180°» (M2) — при проходе оборотов.

Нет ни одной строки (лицевые без оборотов, одна выделенная) — подвала нет. Подвал растёт
вниз, лента над ним не сдвигается. Tab после ленты: «Выделить в документ» → «Снять» →
чекбокс «добавить пустые» → чекбокс 180°. Мок подписывал включённый переключатель «N в
наборе» — заменено: «набор» в M3.5–M3.6 значит другое.

### 6.3. Превью (по центру)

Крупный лист с имитацией текста, в углу метка «ЛИСТ 7 · ОБОРОТ». Если страница начинает
документ — верхняя кромка акцентная и подпись «НАЧАЛО ДОКУМЕНТА N».

**Пустая страница (M4, S8)** показывается как есть — пустоту проверяют глазами; в левом
верхнем углу листа пилюля «ПУСТАЯ СТОРОНА» у помеченной, «ПУСТАЯ СТОРОНА · НЕ ПОПАДЁТ В
ФАЙЛ» у скрытой, показанной переключателем. Текст мока «пустая сторона листа (распознано
автоматически)» вместо строк не рисуется: строк нет, есть скан. Потерянная или не
открывшаяся страница — как прежде, без пилюли.

Под превью — статус-бар: «←», счётчик «7 из 21» (по показанной ленте; «←» и «→» ходят по ней
же), «→», кнопки поворота «↺» и «↻» (обе с направлением и числом страниц в подписи, M3.5),
кнопка удаления. Кнопка «Пересканировать» из макета не рисуется — пост-MVP (раздел 6.8).

**Все страницы скрыты (M4, S7)** — переключатель выключен, а показанная лента пуста при
непустой полной: вместо превью пустой редактор «Все страницы — пустые обороты» с текстом
«Они скрыты и в файл не попадут. Переключатель «добавить пустые» внизу ленты покажет их;
«Это не пустая страница» вернёт нужную в документ.», лента — «Все страницы скрыты»,
текущей нет, статус-бар «—», инструменты недоступны, фокус — на переключателе. Полная лента
пуста совсем — прежнее «Страниц не осталось» (раздел 6.8).

### 6.4. Инспектор (справа)

Четыре блока сверху вниз (у пустой страницы — пять, M4):

- **ДЕТАЛИ** — сворачиваемый, по умолчанию свёрнут. Заголовок «Стр. 7 — оборот листа 4»,
  факты «Лист», «Сторона», «Поворот» и пояснение про пару словами. У пустой страницы и у
  помеченной вручную (M4, S10) — ещё факт «Содержимое»: «пустая — скрыта» / «пустая — с
  меткой» / «не пустая — ваша пометка»; у обычных страниц ряда нет. Номера прохода нет (M3):
  номер прохода — не роль, а «проход 3» после перезапуска путает. У добавленной страницы
  (M3.5) — «Стр. 8 — добавленный набор 1», факты «Набор» и «Поворот», пояснение без пары.
  До сборки (режим наборов, M3.6, S9) листа ещё нет: заголовок «Стр. 15 — оборотная, 3-я в
  наборе оборотов» (добавленная — «добавленный набор 1, в наборе оборотов»), факты «Набор»,
  «Место» («3-я из 11»), «Откуда» («проход оборотов» / «проход лиц» / «добавленный набор 1»),
  «Поворот»; пояснение говорит, каким листом страница станет после сборки. После сборки —
  как прежде: лист по позиции в записи сборки; страница без листа (добавлена после сборки) —
  «добавленный набор K».
- **ПУСТОЙ ОБОРОТ** (M4, S9) — только у пустой страницы: помеченной или скрытой, показанной
  переключателем. Пояснение по режиму: «Распознано автоматически: на странице нет чернил. Она
  скрыта и в файл не попадёт.» / «… Она останется в файле с меткой.» / в режиме наборов «… В
  режиме наборов она считается; после сборки будет скрыта.» — и кнопка **«Это не пустая
  страница»**. Нажатие — правка и шаг undo: страница становится обычной (метка, пилюля и
  секция уходят, в режиме «Скрывать» она возвращается в ленту и в файл), плашка «Есть ручные
  правки», тост «Страница возвращена в документ — Ctrl+Z отменит»; текущая и фокус — та же
  страница. Обратного действия («считать пустой») нет: Ctrl+Z или «Вернуть». Пометка
  переживает перезапуск. Кнопка недоступна, пока идёт запись или сборка.
- **ДОКУМЕНТЫ В НАБОРЕ** — счётчик и список документов с номером, названием и метаданными
  («9 стр. · стр. 4–12 набора», по показанной ленте); текущий подсвечен, клик переводит на
  его первую страницу. Документ из одних скрытых пустых оборотов (M4) — «только пустые
  обороты — скрыты», в ленте он не рисуется. Под списком пояснение: сколько файлов получится,
  а если границ нет — как их поставить: split-бар или выделение (Shift — диапазон, Ctrl — по
  одной) и «Выделить в документ»; «подряд» подсказка с M4 не требует (раздел 6.5). До
  сборки (M3.6) счётчика и списка нет — «Документы появятся после сборки: сейчас лица и
  обороты лежат отдельными наборами».
- **ПРОВЕРКА** — пункты со значком:
  1. «Лица и обороты собраны: N листов» — галочка (пары и собрано; N — число пар по проходам,
     после сборки — число лиц в ленте); без прохода оборотов — «Обороты не сканировали». В
     режиме раздельных наборов (M3.6, S8) — точка со счётчиками групп: «Наборы не уравнены:
     лицевых 12, оборотных 11 — не хватает 1 оборота» и подсказка «Досканируйте недостающее
     кнопкой «+ Добавить» или перенесите страницы через границу наборов, затем нажмите
     «Собрать документ»»; при уравненных — точка остаётся («Наборы уравнены: по 12 стр. —
     нажмите «Собрать документ»»): документ ещё не собран; все удалены — «Наборы пусты».
     Прежний пункт «Пар „лицо + оборот“: N из M» и подсказка про пропущенный лист сняты;
  2. пустые обороты (M4, S11) — по режиму сессии: галочка «Пустых оборотов не найдено»; в
     «Скрывать» — точка «Скрыто N пустых оборотов — в файл не попадут» с подсказкой
     «Переключатель «добавить пустые» внизу ленты покажет их; «Это не пустая страница» вернёт
     нужную в документ.»; в «Помечать» — галочка «Помечено N пустых оборотов — останутся в
     файле»; в режиме раздельных наборов при «Скрывать» — точка «Помечено N пустых оборотов —
     считаются в наборах, скроются после сборки». Пока оценки идут — точка «Оценка пустых
     оборотов: ещё N стр.» с приоритетом над остальными: сохранение в это время недоступно.
     Скрытие меняет состав файла без участия пользователя — поэтому точка; пометка ничего не
     убирает — галочка. При «Оставлять» пункта нет;
  3. порядок — галочка «Порядок соответствует сканированию» или точка «Порядок правили
     вручную — автосортировка отключена».
- **«Есть ручные правки»** — плашка внизу с кнопкой «Вернуть» (M3). Показывается при **любой**
  правке: перенос, поворот, удаление, граница, имя, тумблер 180°, пометка «Это не пустая
  страница» (M4). «Порядок изменён» был бы неправдой после одного поворота без переноса.
  «Вернуть» — **полный откат**: порядок, повороты, удаления, границы, имена, тумблер и
  пометки «не пустая» одним шагом, после подтверждения в малой
  модалке `revert` (начальный фокус на «Отмена»). Сам откат — шаг undo: Ctrl+Z возвращает всё.
  Добавление набора — не правка (M3.5): место вставки — свойство прохода, плашка от него не
  появляется, «Вернуть» набор не трогает.

### 6.5. Выделение

- клик — выделить одну страницу и сделать её якорем;
- **shift** + клик — диапазон от якоря до текущей;
- **ctrl / ⌘** + клик — добавить или убрать одну, якорь переносится;
- клик мимо ленты — по превью, инспектору, пустому месту тулбара — сжимает выделение до
  текущей, как Esc (M3.5). Кнопки, поля и модалки исключены: «↻», «Удалить N стр.» и
  «Выделить в документ» действуют на выделение.

При выделении больше одной страницы появляется панель выделения — с M4 в подвале ленты, а не
над ней (раздел 6.2, S6): миниатюры не сдвигаются. Выделение живёт по показанной ленте:
скрытые пустые обороты в него не входят, пока не показаны переключателем.

**«Выделить в документ»** (M4, S6) работает для любого выделения из двух и больше страниц
вне режима раздельных наборов:

- **подряд** — как в M3: границы до и после выделенного куска, в начале и в конце набора
  лишние границы не ставятся;
- **не подряд** — выделенные собираются в один документ на место первой выделенной,
  остальные страницы сдвигаются вправо без изменения взаимного порядка; скрытые хвосты едут за
  своими лицами; затем границы до и после куска. Это перенос: порядок становится явным, как
  после перетаскивания. Один шаг undo; после Ctrl+Z выделены перенесённые страницы.

В обоих случаях — фокус в поле имени нового документа, тост «Отдельный документ из N стр.
создан», плашка «Есть ручные правки». Тост «Выделите подряд идущие страницы» снят.

### 6.6. Перетаскивание

Миниатюра перетаскиваемая, при перетаскивании становится полупрозрачной. Позиция вставки
определяется по курсору: левее середины миниатюры — вставка перед ней, правее — после; место
показывается вертикальным маркером. Бросок переносит страницу и **отключает автосортировку**:
поднимается признак ручной правки, плашка «Есть ручные правки» и пункт проверки «Порядок».
Перетаскивание — только мышью; перестановка с клавиатуры — бэклог.

### 6.7. Границы документов

Граница ставится на странице, с которой начинается следующий документ, тремя путями:
split-бар на миниатюре, кнопка в тулбаре, «Выделить в документ». На первой странице набора
граница невозможна.

Постановка границы сразу ставит фокус в поле названия нового документа и выделяет текст —
чтобы имя вводилось без лишнего клика. Название по умолчанию — «Документ N»; у единственного
документа — общее имя набора. Снятие границы удаляет и введённое название. Enter в поле
фиксирует имя и снимает фокус — на карточку текущей страницы (M3.5); пока предыдущая правка
в полёте, Enter ничего не делает, чтобы имя не выглядело принятым. Esc отменяет ввод.

### 6.8. Правка страниц

- **Поворот** — «↻» поворачивает на 90° по часовой, «↺» (M3.5) — против часовой, текущую
  страницу или всё выделение, одним шагом undo; тоста нет — поворот виден. Поворот виден **и на миниатюре** (M3): рамка
  остаётся портретной, изображение уменьшено и повёрнуто внутри неё, сетка не прыгает. Превью
  при 90°/270° становится альбомным — «как будет в PDF». Анимации поворота нет. Исходник
  страницы не меняется: угол — запись в журнале, применяется при сборке PDF.
- **Удаление** — помечает страницу или всё выделение удалёнными, поднимает признак ручной
  правки, показывает тост «Страница удалена — Ctrl+Z вернёт» / «Удалено N стр. — Ctrl+Z
  вернёт». Подтверждения нет. Файлы страниц не трогаются до закрытия сессии. Все страницы
  удалены — пустой редактор «Страниц не осталось» с подсказкой про Ctrl+Z и «Вернуть»,
  сохранение недоступно.
- **Undo / Redo** — Ctrl+Z, Ctrl+Y и Ctrl+Shift+Z вне текстовых полей и модалок. Стек живёт до
  перезапуска (после него пуст, правки целы). Изменение ленты или проходов не через
  правку (досканирование, «Оставить как есть» у прерванного прохода) стек очищает; «Собрать
  документ» (M3.6) — тоже: запись сборки входит в подпись ленты, Ctrl+Z сразу после сборки —
  пусто, правки целы.
  **Известное поведение (M3.5):** запуск добавления, который увёл экран на `scan`, очищает
  стек — `editor` на это время размонтирован. Это и пустой лоток, и обрыв до первой страницы,
  и «Остановить»: экран уходит на `scan` до проверки лотка. Отказ до задания (запись, предел
  проходов, прерванный проход) экран не трогает, стек цел.
- **Пересканирование** — не рисуется: пост-MVP (роадмап → «Вне этого роадмапа»).

### 6.9. Пустые обороты

Реализовано в M4 (`handoffs/2026-10-m4-states.md`; план
`../plans/2026-10-22-001-feat-m4-blank-backs-plan.md`). Режим выбирается в `setup` (раздел 2) и **замораживается в сессии** при старте первого прохода — поле сессии, в редакторе не
меняется; смена настройки действует на следующее сканирование. Оценивает страницы ядро — по
проходу оборотов, в фоне, по мере прихода; renderer порога не знает и ничего не оценивает,
он только показывает флаги снимка. Оценка — производное (ADR 0004, амендмент 2026-10-22):
исходник и журнал её не хранят; после перезапуска без кэша оценок страницы оцениваются
заново.

**«Скрывать»** (по умолчанию). Скрытые ядром страницы исключены из показанной ленты, превью,
счётчиков, сводок `save` и `newscan` и из файла. Переключатель «добавить пустые» в подвале
ленты **только показывает**: включённый — скрытые встают на свои места с меткой «ПУСТО»,
пунктиром и приглушённым листом, нумерация пересчитывается, текущая и выделение не меняются;
в файл они всё равно не попадают. Это состояние экрана, а не правка: не шаг undo, не
переживает перезапуск и перемонтирование `editor` (после прохода «+ Добавить», после
«Собрать документ» — выключен). Выключение убирает скрытые из ленты и выделения; текущая,
если скрыта, переезжает на ближайшую показанную справа, в конце — слева; показанная лента
опустела — «Все страницы — пустые обороты» (раздел 6.3). Вернуть страницу в документ можно
только явно — «Это не пустая страница» в инспекторе (раздел 6.4): правка, шаг undo,
переживает перезапуск. Мок подписывал включённый переключатель «они попадут в файл» —
отклонено: один переключатель молча менял бы состав файла.

**«Помечать».** Лента полная, пустые обороты несут метку «ПУСТО» и пилюлю превью, все
остаются в файле; переключателя нет — скрывать нечего; ПРОВЕРКА — галочка «Помечено N …»;
«Это не пустая страница» снимает метку так же.

**«Оставлять».** Детектор не работает: ни меток, ни переключателя, ни пункта ПРОВЕРКИ, ни
ряда в `save`, ни хвоста статуса `merge` — редактор M3.6 без изменений. Так же открываются
сессии журнала v5 и восстановленные сверкой — даже если настройка стоит «Скрывать».

**Режим раздельных наборов** (M3.6) при «Скрывать»: пустые помечены, а не скрыты — они
считаются в наборах; переключателя нет, ПРОВЕРКА — точка «считаются в наборах, скроются
после сборки». После «Собрать документ» скрытие вступает в силу, один тост «Документ собран:
N листов — скрыто M пустых оборотов» (при нуле скрытых — прежний «Документ собран: N
листов»). Оборот, добавленный через «+ Добавить» в группу оборотов, оценки не получает —
флаг только у страниц прохода оборотов.

**Поздние оценки.** Обычно оценки приходят во время прохода, и `merge` ждёт остаток (раздел
5), так что редактор открывается сразу с правильной лентой. Вердикты, пришедшие уже в
`editor` (перезапуск без кэша оценок — версия детектора поднялась; досканирование
прерванного прохода оборотов), скрывают страницы по мере оценки — с тостом «Скрыто N пустых
оборотов — переключатель «добавить пустые» покажет их», один раз на снимок; текущая,
ставшая скрытой, переезжает, стек undo цел, фокус возвращается на карточку текущей. Тост —
только в «Скрывать» и только когда страница вердиктом (не правкой и не Ctrl+Z) ушла из
показанной ленты; в «Помечать» ничего не исчезает — появляются метки. Пока оценки идут,
сохранение недоступно (раздел 7.3).

Файлы скрытых страниц живут до «Новое сканирование» — как у удалённых (ADR 0004).

## 7. Модалки

Общая анатомия: шапка (заголовок, подзаголовок, иногда кикер со статусной точкой), тело
секциями с кикерами, футер (слева статусная строка, справа «Отмена» и первичное действие).
Анимации открытия нет. Закрытие — «Отмена» или действие; закрытия по клику вне окна и по
Esc в макете нет.

### 7.1. `device` — подключение сканера

**СЕТЕВЫЕ СКАНЕРЫ.** Пока идёт поиск — три скелетона с пульсацией и сдвигом фазы. Потом —
список: имя, адрес, статус справа. Устройство **без автоподачи** приглушено, со статусом
«нет автоподачи», курсор «недоступно», выбрать нельзя. Выбранное подсвечено.

**АДРЕС ВРУЧНУЮ.** Поле с подсказкой «адрес сканера в сети», всегда на виду. Под ним
сворачиваемое «Дополнительно» с тремя полями: Схема — переключатель на два положения
HTTPS / HTTP (не текстовое поле), Порт — только цифры, плейсхолдер следует за схемой
(443 / 80), Путь — плейсхолдер `/eSCL`. Нетронутое поле уходит в ядро как «не названо»:
схема тогда берётся из URL в поле адреса или HTTPS, порт — по умолчанию для схемы, путь —
`/eSCL` (реализация M1 — `handoffs/2026-10-m1-states.md`, Behaviour).

**Статусная строка футера** — состояния: «Идёт поиск сканеров в сети…» · «Найдено N
устройств · поиск продолжается» · отказ подключения красным. Пустой поиск дольше 10 с (S7)
показывает текст в области списка — окончательный текст без AirPrint / Bonjour, с запросом
брандмауэра Windows (решение автора, сессия 6 M1; Copy handoff'а). Сбой поиска (S8) тоже
стоит в области списка, статусная строка при этом пустая.

**«Подключить»:** выбранное в списке устройство подключается сразу. Иначе берётся адрес из
поля; пустой — подсказка «Выберите сканер в списке или введите адрес»; негодный ввод
(не хост, не IP и не URL) — свой текст, несуществующее имя — текст причины `dns`
(Copy → `errors.*`). Успех закрывает модалку и показывает тост «Сканер подключён: …».

Выбор в списке очищает поле адреса, и наоборот — ввод адреса снимает выбор. Два источника
адреса не могут быть активны одновременно.

### 7.2. `add` — добавить скан к документу

Реализовано в M3.5 (`handoffs/2026-10-m3-5-states.md`, S2). Заголовок «Добавить страницы к
документу», подзаголовок «Новые страницы станут отдельным набором — их можно двигать,
поворачивать и удалять, как остальные».

**ЧТО СКАНИРУЕМ** — две карточки-радио: «Односторонние листы» (один проход, обороты не
сканируем) и «Один лист» (с инструкцией, как положить лист оборотом: оборотом вверх и
развёрнутым на 180°, как при проходе оборотов). В ядро уходит одно и то же намерение: число
листов приложение не знает и не спрашивает (раздел 3). **«Двусторонней пачки» из макета нет**
— паре проходов нужен свой `flip`, тумблер 180° и своё несовпадение; отдельная веха (бэклог).

**КУДА ВСТАВИТЬ** — два сегмента: «В конец документа» и «После текущей страницы»; по умолчанию
— после текущей, если она есть. При пустой ленте «После текущей» недоступна с причиной, набор
идёт в конец ленты. В режиме раздельных наборов (M3.6, S10) второй сегмент — «В конец набора»:
якорь — последняя видимая страница группы текущей, сводка называет группу («в конец набора
оборотов, после стр. 23»; «после стр. 15 (оборотная, 3-я в наборе оборотов)»); добавленный
набор встаёт в группу якоря и входит в её счётчик. Вставки «в начало набора» нет — переносом
(бэклог).

**Сводка в футере** называет якорь до запуска: «Один лист · после стр. 7 (оборот листа 4)»,
«Один проход · в конец документа «Акт», после стр. 9». Под карточками — строка сканера
«готов · 300 dpi · …» или «Сканер не подключён — подключите его в настройках»; без готового
сканера «Начать скан» недоступна, карточки и сегменты работают. Начальный фокус — «Отмена»:
запуск — действие с бумагой, случайный Enter его начинать не должен. Карточки и сегменты —
по одной остановке Tab, выбор стрелками.

**Якорь.** «После текущей страницы» — ключ страницы в превью (при мультивыделении — её же).
«В конец документа» — последняя видимая страница документа текущей страницы, а не «конец
ленты»: набор остаётся в этом документе и при будущих границах. Якорь фиксируется в момент
«Начать скан» и пишется в проход журнала (ADR 0004, амендмент 2026-10-07). Скрытые пустые
обороты (M4, S16): «После текущей страницы» ставит набор после скрытого хвоста текущей —
скрытый оборот часть листа, вставка между лицом и его оборотом разбила бы лист; сводка
называет текущую, как прежде, а номер «после стр. N» — по показанной ленте, как нумерация
миниатюр (фикс ревью M4). При включённом переключателе якорь буквальный.

**Размещение.** Набор встаёт сразу за якорем — перед наборами, прикреплёнными к нему раньше:
два добавления подряд с одной текущей идут в обратном порядке, чтобы продолжить за набором,
выбирают его последнюю страницу. При ручном порядке новые страницы любого прохода встают за
ближайшим предшественником по автопорядку, который есть в ручном порядке, — без шага undo,
без плашки и без тоста (пересмотр M3, где они уходили в конец ленты с тостом). Границы
документов остаются перед теми же страницами.

**Запуск.** «Начать скан» всегда закрывает модалку — экран уходит на `scan` раньше, чем ядро
начнёт задание. Один запуск на нажатие. Отказ — синхронный или после старта (лоток пуст, занят,
предел проходов) — одним каналом: тост «Не удалось начать: …», экран остаётся `editor`, плашка
прерванного прохода не появляется. После набора — сразу `editor`: текущая — первая добавленная
страница, выделена она одна, лента прокручена к ней (фокус на её карточке), тост «Добавлено N
стр.». Обрыв набора — плашка «Добавление прервалось после страницы N» с действиями прерванного
прохода; досканирование продолжает тот же набор, пока он прерван, «+ Добавить» недоступна.

### 7.3. `save` — сохранение

**ЧТО СОХРАНЯЕМ** — два сегмента: «Отдельные файлы» (по границам) и «Один файл» (все
страницы подряд). По умолчанию — «Отдельные файлы», если документов больше одного. При одном
документе «Отдельные файлы» недоступны с подписью «границы ещё не отмечены»; нажатие —
тост «Сначала отметьте границы между документами».

**ФАЙЛЫ · N** — строки с редактируемыми именами и числом страниц (размер до сборки
неизвестен); длинный список прокручивается. В «Отдельных файлах» строки — документы, имена —
их названия из ленты. В «Одном файле» строка одна: при одном документе — его имя, при
нескольких — имя файла, по умолчанию «Скан ГГГГ-ММ-ДД». Тронутые в модалке имена документов
при «Сохранить…» сначала записываются в правки (один шаг undo) — редактор и файлы не
расходятся. Это касается строк-документов: «Отдельных файлов» или «Одного файла» при одном
документе. Имя единого файла при нескольких документах в журнал не пишется, и правки имён
документов при таком сохранении тоже не уходят. Пустое имя —
имя по умолчанию; набранное «.pdf» снимается. Запрещённые символы, длину и занятость решает
ядро: санитизация, суффикс « (2)».

**ПАПКА** — путь и «Выбрать…» (системный выбор папки; отказ ничего не меняет). Выбранная
папка помнится между запусками (настройки), по умолчанию — «Документы». Если запомненной папки
на диске нет (вынута флешка), предлагаются «Документы», а запомненная не забывается.

**Сводка** — «Файлов», «Страниц всего», «Пустых оборотов» (M4), «Формат: PDF».

**Пустые обороты** (M4, `handoffs/2026-10-m4-states.md`, S14). Счёт страниц — «Страниц
всего», «N стр.» у строк, «все N стр. подряд» — по страницам, которые уйдут в файл: лента
без скрытых, независимо от переключателя «добавить пустые» (он только показывает). Ряд
«Пустых оборотов» — «скрыто N — не попадут в файл» / «помечено N — останутся в файле» /
«не найдено»; при «Оставлять» ряда нет. Строка документа из одних скрытых — «только пустые —
0 стр.» цветом `--color-danger`. Два отказа ядра видны **до клика** — «Сохранить…»
недоступна, статус объясняет: `documentBlank` — «Документ «Приложение» состоит из одних
пустых оборотов — покажите их переключателем или уберите границу.» (с именем документа;
«Один файл» при этом доступен, пока есть хоть одна показанная страница); `blankPending` —
«Оценка пустых оборотов: ещё N стр. — кнопка станет доступна сама.» — снимок с
завершёнными оценками снимает блок без действий пользователя. Приоритет — `documentBlank`
выше `blankPending`: ждать оценку бесполезно, нужна правка. Отказ ядра теми же кодами —
страховка от гонки, текст причины в статусе (`errorReasons.sessionConflict.*`).

**Запись и итог** (M3):

- Пока идёт запись, модалка занята: закрыть нельзя, правки редактора недоступны.
- Всё записано под запрошенными именами — модалка закрывается, тост на 6 с с кнопкой
  «Новое сканирование».
- Хоть одно имя изменено ядром (занято, санитизировано) — модалка остаётся в **ИТОГЕ** с
  фактическими именами и пометкой причины, основная кнопка «Готово».
- Частичный сбой — ИТОГ: записанные ✓, неудавшиеся ✕ с текстом ошибки, статус «Записано N
  из M.». Основная кнопка — «Повторить неудавшиеся»: тот же пакет, только недописанные файлы,
  в ту же папку. Вторичная — «Закрыть»: пакет забыт, следующее сохранение пишет всё заново,
  уже записанное не трогается. «Сохранено» ставится только при полном успехе.
- Повтор отклонён, потому что пакета больше нет (лента изменилась, другая сессия, сменились
  режим или число документов), — причина в статусе, модалка возвращается к выбору. Иной
  отказ повтора (например, папка недоступна) — причина в статусе, ИТОГ и «Повторить
  неудавшиеся» остаются.

Если модалка открыта из `newscan` («Сначала сохранить текущий»), после полного успеха сессия
закрывается сама и показывается тост «… — можно закладывать новые листы».

### 7.4. `newscan` — новое сканирование

**Единое имя действия — «Новое сканирование».** Так называется кнопка тулбара, кнопка в тосте
после сохранения и заголовок этой модалки («Начать новое сканирование?»); «Новый скан» из макета
не используется. Действие одно и то же везде: закрыть текущую сессию и вернуться на `setup` (R14
плана M1). **Слово «пачка» — рабочий термин спеки и плана, в тексты интерфейса оно не идёт**
(решение автора, сессия 6 M1): про бумагу в лотке — «листы», про отсканированное — «страницы».
Тексты макета с «пачкой» (подсказка `setup`, `flip`, карточки `newscan`) переписываются при
реализации этих экранов.

Кикер отражает состояние: «ДОКУМЕНТ ПУСТ» · «ТЕКУЩИЙ ДОКУМЕНТ СОХРАНЁН» · «ЕСТЬ
НЕСОХРАНЁННЫЕ ИЗМЕНЕНИЯ» («СОХРАНЁН» — с акцентной точкой, «ПУСТ» и «НЕСОХРАНЁННЫЕ» — с
янтарной). Один кикер на «несохранённое»
покрывает и новые страницы, и правки после сохранения: для решения разницы нет. Текст под
заголовком объясняет, что именно будет потеряно, числом страниц; удалённые из ленты страницы
названы отдельно — они тоже сотрутся окончательно. «ДОКУМЕНТ ПУСТ» — все страницы удалены, но
их ещё можно вернуть.

Скрытые пустые обороты (M4, S15): «N стр.» в тексте — по файлу, без скрытых, чтобы сходиться с
лентой; скрытые названы отдельным предложением в конце — «Скрытые пустые обороты (N стр.)
тоже будут стёрты.»: их файлы стираются вместе с остальными. Лента из одних скрытых без
удалённых — только это предложение: про Ctrl+Z говорить нечего. Кикер и карточки — как
прежде.

Варианты: «Закрыть текущий и начать новое сканирование» и — только если есть несохранённое —
«Сначала сохранить текущий». Внизу «Остаться в документе». В режиме раздельных наборов (M3.6,
S11) кикер «ДОКУМЕНТ НЕ СОБРАН» (янтарный), текст про наборы и удаление N стр.; карточки
«Сначала сохранить» нет — сохранять нечего, ядро откажет (`notAssembled`).

Начальный фокус — «Остаться в документе». «Сначала сохранить текущий» открывает `save`;
после полного успеха сессия закрывается (раздел 7.3).

Если страниц нет вообще — ни в ленте, ни удалённых, — модалка **не показывается**: терять
нечего, рабочая область очищается сразу.

Кнопка «Новое сканирование» в тосте после сохранения открывает эту модалку, а не закрывает
сессию молча: закрытие стирает страницы сессии с диска — только через модалку.

### 7.5. `mismatch` — не сошлись проходы

Кикер «НЕ СХОДЯТСЯ ПРОХОДЫ» с янтарной точкой, заголовок с фактическими числами («В первом
проходе 12 листов, во втором — 11») и объяснение по исходу.

**Трёх вариантов действия, которые есть в макете, быть не должно.** Решено при разборе:
модалка только сообщает; действие одно — «Понятно». Показ выводится из снимка (план M2,
KTD-8): первый вход в `editor` за процесс при неподтверждённом несовпадении, включая вход
после перезапуска; постоянная видимость после закрытия — пометка непарного листа в ленте.

**Текст про режим (M3.6, `handoffs/2026-10-m3-6-states.md`, S6; заменил Copy M3.5).** Три
исхода — оборотов меньше, оборотов больше, проход оборотов принят коротким — объясняют, что
документ не собран, лица и обороты лежат отдельными наборами в порядке будущего документа, и
три шага: «+ Добавить» (или удалить лишнее) → поставить на место переносом → «Собрать
документ». Пропущенный лист текст по-прежнему **не называет**.

**Кнопки «Досканировать» нет — принятое решение** (автор, план M3.5): предвыбор «Один лист ·
После текущей» закреплял бы ложную уверенность в том, какой лист пропущен. Лист ставит
пользователь: выбирает страницу и жмёт «+ Добавить». Показ (M3.6, R20): первый вход в `editor`
за процесс, пока режим наборов активен и проход оборотов завершён или принят, — в том числе
после перезапуска и при добавленных наборах (режим активен — объяснение нужно; пересмотр
M3.5, где добавленный набор показ снимал); при прерванном проходе — после решения по плашке;
после сборки и в режиме пар не показывается.

## 8. Тосты

Одна строка внизу по центру, тёмная плашка. Появления без анимации. Новый тост гасит
предыдущий. Тост может нести кнопку действия (M3): нажатие гасит тост и выполняет действие.
Тост лежит поверх затемнения модалок, поэтому действие, открывающее модалку, при уже
открытой модалке ничего не делает. «Открыть папку» (M3.5, пересмотр M3) открывает в
проводнике папку последнего записанного пакета — её помнит ядро до выхода из приложения;
«Новое сканирование» осталось кнопкой тулбара.
