# Brief — переключатель языка и ревью английской копии (B-41)

У приложения появилась вторая локаль — английская (B-41). Язык выбирается сам по языку
интерфейса Windows (`ru*` → русский, иначе английский), помнится в настройках и применяется
сразу, без перезапуска. Чего нет: способа сменить язык руками. Человек с английской Windows и
русскими документами (или наоборот) сейчас заперт в языке системы. Этот бриф закрывает две
вещи одной поездкой: **переключатель языка на экране `setup`** и **ревью английской копии
интерфейса** по референсу, который теперь рендерится на обоих языках.

Источники: план `../../plans/2026-11-03-001-feat-b-41-english-locale-plan.md` (R7, R8, R10,
R12, R13, KTD-4, KTD-8, AE3, AE5, AE6), журнал `../../solutions/0037-b-41-english-locale.md`
(U2 — решения переводчика, U3 — находка про язык системы). Контракт экранов — `UI_SPEC.md` § 2
(`setup`: строка устройства, ряды параметров, «Сбросить параметры»). Референс `../reference/`
перегенерирован 2026-11-03: **каждая сцена на двух языках**, переключатель `RU | EN` над
кадром, адрес вида `index.html#editor:en`. Тексты — `locales/ru/common.json` и
`locales/en/common.json` в репозитории.

## Что спроектировать

1. **Переключатель языка на `setup`.** Должен сказать: «интерфейс можно показать по-русски
   или по-английски, вот текущий язык». Два значения — «Русский» и «English», каждое **на своём
   языке** и не переводится (человек, попавший не в тот язык, должен узнать свой). Где жить —
   решает мок; кандидаты: ряд приложения в группе параметров рядом с «Пустые обороты» и
   «Выравнивание» (тот же компонент сегментов), подвал группы рядом со «Сбросить параметры»,
   угол `aside` «Как это работает». Это не параметр сканирования: «Сбросить параметры» его **не
   трогает**, и это должно читаться из размещения.
2. **Поведение смены.** Язык меняется сразу, без перезапуска и без подтверждения: экран
   перерисовывается на месте. Пока команда выполняется (запись настроек, доли секунды) —
   повторный выбор игнорируется. Отказ записи — тост по общему пути, выделение остаётся на
   прежнем языке. Уже показанные тосты не переводятся задним числом.
3. **Доступность.** У каждой опции атрибут `lang` своего языка (скринридер читает «English»
   английским голосом), доступное имя группы — строкой локали («Язык» / «Language»).
4. **Ревью английской копии по референсу `EN`.** Пройти все одиннадцать сцен (`setup`,
   `device`, `scan` × 2, `flip`, `merge`, `editor`, `save`, `add`, `newscan`, `mismatch`) и
   предложить правки списком «ключ → текст». Что смотреть:
   - **термин-карта** (решения переводчика, журнал U2) — утвердить или заменить:
     лист / sheet, страница / page, лицевые стороны / front sides, обороты / backs, проход /
     pass, документ / document, набор / set, «Новый скан» / New scan, «Добавить листы» / Add
     sheets, «Оригинал» / Original, «Выровнять» / Straighten, «Пустые» / Blanks, «Обороты на
     180°» / Backs 180°, «Это не пустая страница» / Not a blank page, «Оставить как есть» / Keep
     as is, «Досканировать остаток» / Scan the rest, «Собрать документ» / Assemble document,
     «Вернуть» / Revert, «Понятно» / Got it;
   - **спорные места:** тег добавленного набора «Д1» → «A1» (added) и «set A1» в текстах; тег
     оборота на миниатюре «об» → «bk»; «стр.» → полные «page / pages» (английских сокращений
     без двусмысленности нет); кикер `setup` «NEW SCAN» совпал с кнопкой «New scan»;
   - **тон:** короткие подписи кнопок и кикеров, спокойные тексты модалок, без «пачки» и
     «стопки» (по-английски — без stack / batch / pile), числа и единицы как в русском;
   - **длина в узких местах**, мерянных под русский: две кнопки тулбара редактора по 130 px
     («New scan», «Add sheets»), кнопка состояния выравнивания 128 px («Original» /
     «Straighten»), модалки `device` и `save`, плашка прерванного прохода, подписи состояний
     устройства («ready», «not responding», «another device at this address»). Английское слово
     без переноса может не влезть там, где русская фраза переносилась.

## Какое поведение сделать рабочим в моке

- Экран `setup` целиком, в обоих языках: переключатель меняет язык всего экрана на месте, без
  перезагрузки страницы; второй клик по текущему значению ничего не делает.
- Состояние «команда выполняется»: короткая блокировка переключателя и возврат к норме;
  состояние «отказ записи»: тост и прежний язык.
- «Сбросить параметры» возвращает ряды параметров и **не** трогает язык — видно по моку.
- Панель сценариев: системный язык русский / английский (стартовое значение), явный выбор.

## Стадии

**Стадия 1 — варианты размещения.** Отдельная страница с 2–3 действительно разными вариантами
переключателя на `setup` (ряд в группе параметров, подвал группы, угол `aside`), подписаны, без
контекста остальных экранов. Ждать выбора автора.

**Стадия 2 — выбранное в контексте `setup`** на обоих языках, плюс ревью копии. Итог — два
артефакта: **handoff переключателя** по `../handoff-template.md` с секцией `## Copy` в колонках
`ru | en` (строки контрола и имя группы) и **правки английской копии** списком «ключ → текст»
(можно прямо в handoff'е отдельной секцией). Правки русских строк — только если без них нельзя,
отдельным списком: русские тексты держат jsdom-тесты и UI_SPEC.

## Вне скоупа

- Третья локаль; меню приложения (в упакованном приложении снято).
- Перевод документов, README, витрины — B-40.
- Перекраивание раскладки под английский: русский задаёт раскладку; если английское слово не
  влезает — предложить другое слово, не другую ширину.
- Экраны кроме `setup` — в моке не нужны, их английские версии уже в референсе.
- Язык мастера установки NSIS.

## Открытые вопросы / допущения

- **Допущение:** переключатель — компонент сегментов, как ряды «Пустые обороты» и
  «Выравнивание» (`Segments`, `role="radiogroup"`); дизайн вправе предложить другую форму, если
  она лучше читается как «не параметр сканирования».
- **Допущение:** подписи значений — «Русский» и «English», без флагов и кодов `RU | EN` в самом
  приложении (коды — только в референсе).
- **Допущение:** переключатель виден всегда, и без подключённого сканера.
- Нужна ли подпись-подсказка под переключателем («язык интерфейса, применяется сразу»)? Если
  без неё понятно — не нужна.
