## Сессия 1 — реализация

Вход — первый handoff Claude Design по новому процессу (референс B-6 → бриф → мок → handoff):
`docs/design/handoffs/2026-10-b5-merge.md` + раскадровка `2026-10-b5-merge.sort.css`, мок —

### U1. Экран, стили, тексты, тесты — ✅

- `MergeScreen.tsx` переписан: компонент `Sort` (шесть листов и «призрак», `aria-hidden`),
  режим — из той же классификации исхода, что статус (KTD-2): пачка — `assemblyOutcome`,
  набор — решение и `backsState`; принятый длинный проход — `--extra`. Заголовок — три ключа
  (`title` / `titleSet` / `titleFronts`), тег набора `НАБОР Д{{set}}` (KTD-3: номер, как у
  остальных ключей набора). Строка: исход — `merge-screen__main`, хвост — отдельный
  `merge-screen__tail` с ключом по тексту (проявляется при смене), `aria-live="polite"`;
  при `--short` / `--extra` — `--warning` и точка.
- Стили: `merge-screen.css` по handoff'у (диаграмма снята); `merge-sort.css` — база `.sort` и
  раскадровка из handoff'а как есть (KTD-1).
- Локаль: `merge.title*`, `merge.setTag`, `merge.blank.tail` (вместо `join`); ключи рядов и
  формул сняты.
- Тесты: `MergeScreen.test.tsx` переписан (режимы, заголовки, тег, янтарная строка, хвост
  отдельным узлом). App-тесты: присутствие и уход экрана — по `.merge-screen`, а не по
  тексту заголовка (иначе «ушёл» проходило бы на «Собираем лицевые стороны» и при
  незакрытом экране); статус — по `.merge-screen__status`.
- Доки: UI_SPEC §5, рецепт экрана в DESIGN_SYSTEM и упоминания «диаграммы сборки» в описаниях
  токенов (`--opacity-soft` теперь не используется — отмечено). Референс: `merge-sort.css` в
  списке CSS, сцена `merge` с иллюстрацией.

**Отклонение от handoff'а (осознанное):** иллюстрация — не общий компонент в `components/` со
стилями в `app.css`, а внутри `MergeScreen` со своим `merge-sort.css`: `feed` и `turn` в коде
живут в своих экранах и их CSS (KTD-1). Пробел в начале хвоста « · …» во flex-строке
схлопывается — зазор даёт `gap`, как в моке.

**Готово:** typecheck + lint + test зелёные. Коммит `feat(b-5): U1 …` (`c49d6d7`).

### U2. Проверка и доки — ✅

- Референс: скриншот сцены `merge` — пары разложены, «совпало пар: 6».
- CDP-смоук `temp/smoke-b5.mjs` (dev, эмулятор): сошлось — «Сопоставляем лица и обороты»,
  `sort--ok`, «совпало пар: 3 · пустых оборотов: нет», затем `editor`; придержан лист —
  `sort--short`, янтарная «не сошлось: лицевых 3, оборотов 2…», затем модалка `mismatch`.
  **Зелёный.**
- `test:all`: unit 2228 зелёные; интеграция — флак из бэклога (`separate-sets` AE9, проход
  «прерван» посреди), повторный прогон 208/208. B-5 трогает только renderer.
- Чеклист приёмки — `docs/output/2026-10-26-smoke-checklist-b-5-acceptance.md` (вне git).

### Правка по приёмке автора (2026-10-26) — ✅

Замечание: пауза (1,6 с) короче цикла иллюстрации (3,8 с), и в части случаев картинка
несовпадения не доигрывалась — редактор открывался раньше, чем по анимации было понятно, что
что-то не так. **Решение автора:** анимация одна на все исходы — базовая «пары собираются»,
как индикатор загрузки; несовпадение — строкой состояния и модалкой `mismatch`; после
«Обороты не нужны» экрана `merge` нет вовсе.

- `App.tsx`: после «Обороты не нужны» (основной документ — `backsDeclined`, набор —
  `decision === 'declined'`) пауза не ставится; посадка набора и тост — как были.
  `MERGE_PAUSE_DECLINED_MS` снят.
- `MergeScreen`: режимы иллюстрации и «призрак» сняты, `Sort` без параметров; янтарная строка
  — по признаку несовпадения пачки или набора; ключ `merge.titleFronts` снят.
- `merge-sort.css`: только раскадровка «сошлось» (селекторы без модификатора режима).
- Тесты: экран — иллюстрация одна при любом исходе; App — «Обороты не нужны» у пачки и у
  набора без паузы, сразу `editor` (и тост набора).
- UI_SPEC: граф переходов (`flip` → `editor` по «Обороты не нужны»), §4 «Действия», §5, §9;
  DESIGN_SYSTEM — рецепт; пометка в шапке handoff'а B-5.
- CDP-смоук `temp/smoke-b5.mjs` повторён: обе ветки — `.sort` без режима, несовпадение —
  янтарная строка и модалка. **Зелёный.**
