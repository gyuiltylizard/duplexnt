# B-26 — Графика установщика и данные при удалении (журнал)

Карточка [B-26](../backlog.md): две части — графика мастера NSIS по handoff'у
`docs/design/handoffs/installer-art.md` (мастера утверждены 2026-11-03) и решение автора о
данных при деинсталляции. Плана нет: скрипт растрирования, энкодер BMP, три строки конфига,
тесты. Ветка `feat/b-26-installer`, прецедент формы — журналы 0012 (B-7, значок) и 0038.

## Что сделано

1. **Энкодер BMP 24 бит** — `scripts/bmp.ts`: BITMAPFILEHEADER + BITMAPINFOHEADER, строки BGR
   снизу вверх с выравниванием до 4 байт, без сжатия и альфы; `decodeBmp24` для тестов. Своё, а
   не `bmp-js` — пара к `ico.ts`. Там же `INSTALLER_ART`: мастер → растр → размер по NSIS
   (164 × 314 и 150 × 57).
2. **Скрипт `npm run installer-art`** — `scripts/build-installer-art.ts`: `sharp` рендерит
   SVG ровно в размер viewBox (1 ед. = 1 px, без ресэмплинга), прозрачное ложится на белый
   (`flatten`), альфа снимается, размер сверяется с ожидаемым. BMP коммитятся, как значки:
   сборка от генерации не зависит.
3. **Конфиг** — `electron-builder.yml`, секция `nsis`: `installerSidebar`, `uninstallerSidebar`
   (та же боковая) и `installerHeader` по handoff'у.
4. **Тесты** — `test/tooling/bmp.test.ts`: заголовки, порядок строк и выравнивание, разбор
   туда-обратно, отказ на чужом формате; собранные файлы в репозитории — размеры и контрольные
   пиксели по анатомии handoff'а (чернила `#1c1a16`, D `#fbfaf7`, апостроф `#a06a2a`, белый фон
   шапки, низ боковой пустой). Плитка в шапке со скруглёнными углами — точки взяты посередине
   краёв, не в углах. `electron-builder.test.ts` — три строки `nsis` указывают на существующие
   BMP.

Установщик собран с ветки для проверки автором (первая попытка `npm run dist` упала на
временном `EPERM` при переименовании `release/win-unpacked.tmp` — антивирус; повтор прошёл).

## Вопрос о данных при удалении — решение автора 2026-11-03: спрашивать

Варианты: оставить как есть и написать в README (проще, «данные священны» и так соблюдено) или
своя страница деинсталлятора с галочкой. Автор выбрал галочку. Попутный вопрос автора: установщик
на двух языках? — да, и шире: electron-builder по умолчанию кладёт в NSIS все поддерживаемые
языки (русский среди них), выбирает по языку Windows, окна выбора нет; у автора мастер
английский (язык Windows en-US).

5. **`build/installer.nsh`** — своё включение (`nsis.include`). Страница «Сканы и настройки»
   после «Добро пожаловать» деинсталлятора: текст, папка данных (`$APPDATA\duplexnt`, поле
   только для чтения — её можно скопировать), галочка «Удалить и мои сканы и настройки», по
   умолчанию снятая. Удаление — в `customUnInstall` внутри секции удаления, только при
   `${BST_CHECKED}`; тихое удаление (`/S` — обновление, winget) страницу не показывает,
   переменная пуста, данные остаются. Встроенное `deleteAppDataOnUninstall` остаётся `false`.
6. **Порядок компиляции и -WX.** electron-builder вставляет включение ДО `installer.nsi`, то есть
   до `MUI2.nsh`: всё, чему нужны макросы MUI и nsDialogs, лежит в макросах `customHeader` /
   `customUnWelcomePage` / `customUnInstall`, которые раскрываются позже. Функции `un.*` и
   переменные — под `!ifdef BUILD_UNINSTALLER`: в сборке установщика они не referenced, NSIS
   предупреждает, а `makensis -WX` превращает предупреждение в ошибку (первая сборка так и
   упала — «warning treated as error»).
7. **Языки установщика — два**, `installerLanguages: [en_US, ru_RU]`: свои строки идут
   `LangString` с числовыми LCID (1033 / 1049), как у самого electron-builder, и строка без
   перевода для любого из сорока языков уронила бы сборку под `-WX`. Язык — по языку Windows,
   прочие получают первый в списке, английский. Тест держит: каждая `LangString` включения —
   ровно на 1033 и 1049; `include` подключён; удаление только по галочке; страница после
   «Добро пожаловать».
8. **Спека** — «поставка одним установщиком» дополнена страницей деинсталлятора и языками.
   **B-40** — попутная заметка: `description` из `package.json` идёт по-русски в свойства exe и
   установщика, в английской Windows остаётся русским.
