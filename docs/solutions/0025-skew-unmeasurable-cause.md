# Две причины у «не измерена»: не по чему мерить / наклон строк не сходится (журнал)

Замечание автора после проверки [solution 0024](0024-skew-halves-vote.md) (2026-10-29): лист с
двумя колонками получает «Приложение не нашло, по чему мерить наклон» — а строки на нём есть,
все десять полос валидны; не сходится их форма. Детектор стадии отказа различал
(`bands` / `coverage` против `shape`), а наружу уходил только исход `unmeasurable`. Плана нет —
сквозная правка одного признака без развилок. ADR нет.

## Исправление

- `src/shared/skew.ts`: `SkewCause = 'content' | 'shape'`, поле `cause` у `SkewMeasure` и
  `SkewVerdict` (`null` у остальных исходов). `src/core/detect/skew.ts`: причина — по первому
  проходу 30 мм: провал формы → `shape`, даже если запасной проход 50 мм упал по числу полос
  (строки были); иначе `content`. `SKEW_DETECTOR_VERSION` 2 → 3 — новое поле записи, прежние
  записи перемеряются.
- `src/core/storage/skew-scores.ts`: `cause` в схеме кэша (строгой) и вердикте; сбой декода —
  `content`.
- `src/shared/straighten.ts`: `StraightenFact.cause`, причина статуса `shape` рядом с `measure`
  (`STRAIGHTEN_REASONS`), сводка `reasons.shape`; `straighten-flow.ts` кладёт причину в факт.
- Renderer: `EditorInspectorStraight` перечисляет `shape` в подсказке ПРОВЕРКИ; тексты в
  `locales/ru/common.json` — факт «наклон строк не сходится», секция «Строки на странице есть,
  но их наклон не сходится в одну форму — так бывает у двух колонок. Страница оставлена как
  есть.», причина в сводке «наклон строк не сходится», `title` «Не выровнено: наклон строк не
  сходится в одну форму». Прежние тексты «не по чему мерить» остались за `content`.
- Тесты: `skew-detector.test.ts` — причина по всем сканам (ловушки — `shape`, фото и чистые —
  `content`, измеренные — `null`); `straighten.test.ts` — правило статуса; jsdom
  `EditorScreen.straighten.test.tsx` — карточка, превью, секция, факт и ПРОВЕРКА с новой
  причиной; литералы фактов и вердиктов в тестах получили `cause`.
- Доки: техбаза (п. 6 алгоритма), спека (статусы), UI_SPEC (озвучка, ПРОВЕРКА, статусы),
  `bugs.md` → «Закрытые».
