# B-14 — «Выделить в документ» извлекает страницы в новый документ в конце (журнал)

Отзыв автора 2026-10-28 (бэклог B-14): команда резала исходный документ по выделенному куску —
из документа в пять пар при выделенной третьей паре получались три документа. Правильно —
извлечь выделенные в отдельный документ в конце списка, исходный остаётся одним без них. Плана
нет — правка одной чистой функции без развилок; ADR нет. Решения автора на старте: имя нового
документа — по умолчанию (фокус в поле имени); выделена вся лента — без действия. По ревью
(агент, решение без автора — флаг в приёмке): выделен ровно целый документ — он переезжает в
конец **со своим именем**, иначе имя «Б» стиралось бы молча, а тот же документ в конце ленты —
no-op с именем; кнопка недоступна там, где жеста нет.

## Было

`grouped` в `state/edits.ts`: подряд — `separated` (границы до и после куска, границы внутри
снимались вместе с именами, хвост наследовал имя); не подряд — кусок на место первой
выделенной, разрезы по арифметике `moved`, затем `separated`. Документ, из середины которого
брали страницы, распадался на «до», «кусок», «после».

## Стало

- `grouped(edits, visible, keys)`: `order` = оставшиеся + выделенные (ленточный порядок);
  разрезы сдвигаются на изъятые левее (`cutsWithout`, как у `deleted`); опустевшие документы
  схлопываются вместе с именами здесь же — `normalizeCuts` переехала из ядра в `@shared`
  (renderer не импортирует `@core`), номер нового документа для фокуса имени нужен до снимка;
  одна граница перед куском (`withCut`) — новый документ последний, имя по умолчанию; кусок —
  ровно целый документ — везёт своё имя (`wholeDocumentName`).
- Кусок уже в конце ленты — порядок не становится явным (прежний `order`, только граница);
  кусок уже отдельный документ в конце — `null` (имя не стирается); ключей нет или выделена
  вся лента — `null`; кнопка в подвале недоступна, когда `grouped` даёт `null`. `separated`
  снят вместе с тестами — вызовов не осталось.
- `EditorScreen.group` — без изменений по сути: выделение после — перенесённые, если порядок
  сменился; фокус — `result.document` (последний).
- Склейка B-13 и скрытые хвосты — как раньше: ключи разворачиваются до вызова (`movingOf`).
- Тесты: `edits.test.ts` — таблица из двенадцати случаев (середина, не подряд, через разрез,
  разрез внутри куска, документ целиком с именем, документ плюс страница соседа, первый
  документ целиком, конец документа посреди ленты) с инвариантом «оставшиеся разбиты на
  документы как прежде» (попарно), плюс «уже в конце», «уже отдельный», «вся лента»; `EditorScreen.group.test.tsx` — подряд из середины
  (два документа вместо трёх, Ctrl+Z), не подряд, кусок в конце без ручного порядка, AE10/B-13
  при скрытых и показанных.
- Доки: спека («Пустые обороты»), UI_SPEC §6.5, handoff M4 (S6 нажата, Decisions).

**Грабли:** `nameField(n)` в фикстуре экрана — с единицы, индекс документа — с нуля.

### Ревью (code-review, medium, 6 находок — все применены)

Целый документ из середины терял имя (P2) — имя едет с ним; дубль `normalizeCuts` в renderer —
функция в `@shared`, ядро и редактор импортируют одну (заодно снят риск: копия шла по `names`,
а не по границам, и при коротком `names` роняла хвостовые разрезы); инвариант табличного теста
сравнивал число документов — теперь попарную эквивалентность, добавлен случай «разрез внутри
куска из середины»; кнопка не гасла там, где жест `null`; `inPlace` — `first === rest.length`
вместо сравнения списков.
