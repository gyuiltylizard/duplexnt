# B-44 — Модалка `add` без сводки, таблица фактов тише (журнал)

Два замечания автора после приёмки B-41 на установщике 2026-11-03 ([бэклог B-44](../backlog.md)).
Плана нет: правка одной модалки с её тестами, одно правило CSS. Нового мока нет — не новый UI;
UI_SPEC обновлён (§ 7.2, § 7.3). ADR нет. Ветка `fix/b-44-add-footer-facts`, прецедент формы —
журнал 0036 (B-43).

## Что сделано

1. **Сводка из футера модалки `add` снята.** «Двустороннее · после стр. 7 (лицо листа 4)»
   меняла длину при смене «куда вставить»: модалка меняла высоту, и на миг появлялся
   вертикальный скролл. Решение автора — убрать текст совсем: сегменты и карточки называют
   место и сценарий сами. Футер — `modal__footer--end`, только «Отмена» и «Начать скан».
2. **Мёртвый код за сводкой — долой.** Якоря модалки (`AddAnchors`) теперь просто ключи
   `current` / `end` плюс `endKind`; `anchorsOf` больше не принимает `t`, имя документа, режим,
   роль прохода и `numberOf` — нумерация по показанной ленте нужна была только сводке.
   В `EditorScreen` ушёл `numberOf`. Ключи `add.summary.*` удалены из обеих локалей (паритет
   держит тест). `whatOf` остаётся у инспектора и миниатюр.
3. **Тесты пересажены с текста сводки на ключ якоря**, который уходит в `onStart` / API:
   правило «после текущей — за склеенным хвостом листа» (B-13, M4 S16, R18) по-прежнему
   проверяется ключом; три теста чисто про формулировку сводки удалены, у двух `anchorsOf`
   сценарий «after подменяет ключ» слит в тест режима пар. Заодно поправлено ожидание конца
   второго документа: обороты лежат в обратном порядке, 6-я страница — `p02-s01-0001`.
4. **Таблица фактов — голосом метаданных везде.** Правило B-43 для `.save-modal .facts__value`
   поднято в общее `.facts__value` в `app.css` (`--font-size-s`, обычная насыщенность,
   `--color-text-hint`); локальное переопределение в `save-modal.css` снято. В B-43 ДЕТАЛИ
   инспектора оставались первичными намеренно — автор посмотрел живьём и попросил выровнять.

Референс `docs/design/reference/` перегенерирован (`npm run design:snapshot`).
