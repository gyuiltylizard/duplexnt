# B-43 — Модалки device и save: вёрстка списка сканеров и таблица фактов (журнал)

Замечания автора с приёмки B-29 на установщике 2026-11-03 (`docs/input/ui-tune/`, три
скриншота; [бэклог B-43](../backlog.md)). Плана нет: одно правило CSS на регрессию, одно
правило CSS на второстепенность сводки, две строки локали. Нового мока нет — не новый UI;
UI_SPEC обновлён (§ 7.1, сводка `save`). ADR нет. Ветка `fix/b-43-modals-tune`, прецедент
формы — журнал 0034 (B-42).

## Что сделано

1. **Список сканеров наползал на кикер поля адреса — регрессия U8 B-29.** В U8 секции модалки
   `device` обернули в `div.device-modal__pick` (чтобы приглушать их разом на шаге
   подтверждения), а раскладку `modal__body` (колонка, `gap --space-9`) обёртке не дали:
   секции встали блоками вплотную, и карточка устройства (или красный текст отказа поиска)
   упиралась в кикер «АДРЕС ВРУЧНУЮ». На референсе `main` это видно, на AE1–AE3 U8 не
   заметили. Правило `.device-modal__pick { display: flex; flex-direction: column; gap:
var(--space-9) }` в `device-modal.css` — зазор вернулся, шаг подтверждения не задет
   (его правила на `.device-modal--confirming .device-modal__pick` остались).
2. **Кикер «АДРЕС ВРУЧНУЮ» → «ВВЕСТИ АДРЕС»** — `device.sectionAddress` в локали (он же
   `aria-label` поля); тесты `DeviceModal` ищут поле по новой подписи. Handoff'ы M1 и
   scanner-change не трогаются — замороженные артефакты.
3. **Сводка `save` — второстепенный блок.** `.save-modal .facts__value`: `--font-size-s`,
   обычная насыщенность, `--color-text-hint` — голос `.save-file__ext` («.pdf 6 стр.»), как
   просил автор. Ключи прежние. Переопределение локальное: `.facts` делит с ДЕТАЛЯМИ
   инспектора, где значения — основное содержимое и остаются первичными.
4. **Хвост ряда «Выровнено»** — `save.fact.straightUndoneTail`: « · не выровнено {{count}}»,
   без «— уйдут как есть»; тест `SaveModal` обновлён.

Референс `docs/design/reference/` перегенерирован (`npm run design:snapshot`); «до / после»
снято headless-Chrome по сценам `#device` и `#save` референса: на «до» карточка второго
устройства упирается в кикер, на «после» — зазор как у остальных секций, значения сводки в
цвете подсказки.
