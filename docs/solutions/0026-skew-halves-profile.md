# Две колонки: запасной профиль по половинам полосы (журнал)

Обсуждение с автором после [solution 0025](0025-skew-unmeasurable-cause.md) (2026-10-29): веер
— свойство подачи листа, а не колонки, и профиль, снятый по одной колонке, выправит обе. Бэклог
«Две колонки по отдельности» — ход «A»: без поиска колонок, по уже посчитанным половинам полос.
Плана нет — правка внутри `measurePass`, критерий — таблица фикстур. ADR нет.

## Диагноз

На двухколоночном скане автора углы половин полос чистые: левая +0,13 → +0,25 → … → −0,62°,
правая такая же, расхождение ≤ 0,2°. Шумит только угол **целой** полосы (0,40 / 0,22 / 0,32):
строки двух колонок накладываются в разных фазах. Гейт формы смотрит на целые полосы и
отказывает (остаток 0,13–0,23° при пороге 0,1); половины детектор использовал только как сторожа.

## Исправление

- `src/core/detect/skew.ts`: `measurePass` после провала формы по целым полосам строит профиль по
  среднему половин у полос, где половины согласны между собой (`halvesGap ≤
HALVES_TOLERANCE_DEG`), с теми же гейтами числа полос и покрытия и тем же порогом формы;
  подгонка вынесена в `fitProfile(points)` (дыра покрытия → прямая, иначе узлы). `SkewBand`
  несёт `halvesAngle`; `SkewMeasure` — `basis: 'whole' | 'halves' | null` для журнала и тестов (в
  снимок не идёт). `SKEW_DETECTOR_VERSION` 3 → 4.
- Результат: `fan-twocol-gray-300` — `willStraighten` по половинам, 30 мм, ×1,74, веер 4,78 мм,
  ступень +1,20 → −0,14° (как у текста того же прогона); скан автора `fan-twocol-gray-200` —
  ×1,45, веер 2,91 мм, +0,23 → −0,56°. Штриховка — по-прежнему `unmeasurable` (половины не
  согласны). `sheet-front-gray-200` теперь тоже по половинам при 30 мм (прямая +0,26 → −0,92°, та
  же, что раньше при 50 мм). Остальные 26 сканов — без изменений исхода и профиля.
- **Остаток после коррекции:** повторное измерение страницы целиком — max|θ| 0,11–0,13°, веер
  0,74–0,81 мм (само шумит наложением фаз); по колонкам порознь (обрезка выправленной страницы
  на половины, каждая — одноколоночная) — левая 0,68 / 0,47 мм, правая — / 0,13 мм при 2,7–5,0 мм
  до. Плечо половины вдвое короче, углы грубее, чем у целой полосы; допуск теста ресэмплера для
  профиля по половинам — 1 мм, как у запасного прохода 50 мм. На глаз выправленная страница
  ровная в обеих колонках.
- Фикстура `fan-twocol-gray-200` (скан автора); таблица ожиданий: обе двухколоночные —
  `willStraighten`, тест-мутация на `basis: 'halves'` при 30 мм, штриховка — `unmeasurable`;
  причина `shape` остаётся у штриховки.
- Техбаза → «Детектор перекоса»: п. 4 (запасной профиль по половинам), строки таблицы,
  «Предел метода»; README фикстур; бэклог — «Две колонки по отдельности» закрыт (остаток: три и
  больше колонок, где в половину попадает полторы, — если встретится).
