`docs/output/b-40-local-paths.md` (gitignore).

## Сессия 1 — лицензия, уведомления, чистка

### U1. Лицензия и метаданные пакета — ✅ зелёный

`LICENSE` — канонический текст с gnu.org (674 строки, SHA-256
`3972dc97…b36986`), без расширения: `license.txt` electron-builder подхватил бы как страницу
«I agree». `package.json`: `1.0.0-beta.1`, `GPL-3.0-only`, английское описание, `author`
объектом. `electron-builder.yml`: `copyright` явно, шапка без «не публикуется». Тесты:
`test/tooling/package-metadata.test.ts` (версия, лицензия, описание, автор, LICENSE, чистый
`build/`), строка `copyright` в `electron-builder.test.ts`.

**Готово:** typecheck + lint + test зелёные. Коммит `chore(b-40): U1 …` (`39ab367`).

### U2. Уведомления о сторонних компонентах — ✅ зелёный

Плагин `tooling/bundled-packages-plugin.ts` (чистая `packagesFromModuleIds` + обёртка `Plugin`,
`generateBundle` → `emitFile` в outDir каждой из трёх сборок), чистый модуль `scripts/notices.ts`,
раннер `scripts/third-party-notices.ts` (`npm run notices`, `--check` в `dist`), канонические
тексты MIT/ISC/0BSD и LGPL-3.0 в `scripts/notices-texts/`. Факты сборки: в main 15 пакетов
(zod, saxes, bonjour-service с dns-packet/multicast-dns, pdf-lib, culori, fflate, …), в renderer
8 (React, i18next, шрифты), preload пустой; из asar — `sharp`, `@img/colour`,
`@img/sharp-win32-x64`, `detect-libc`, вложенный `semver` 7.8.5. Итого 28 пакетов, у `saxes` нет
файла лицензии — канонический ISC с копирайтом из `author`; React/react-dom/scheduler и
sharp/`@img/sharp-win32-x64` схлопнуты по одинаковому тексту. `@babel/runtime` и
`html-parse-stringify`, которых ждали по дереву зависимостей, в бандле нет — список от бандла
точнее списка от package.json.

Грабли: `npm.cmd` напрямую не спавнится (Node ≥ 22 — EINVAL), npm идёт как скрипт Node через
`npm_execpath`; порядок файлов лицензий — сначала `LICENSE*`, потом `NOTICE*`, без учёта
регистра (иначе `NOTICE` вставал раньше `license.MD`).

**Готово:** typecheck + lint + test зелёные, `notices --check` актуален. Коммит
`chore(b-40): U2 …` (`65b4e8a`). Проверка `extraFiles` на собранном установщике — в U7.

### U3. Чистота идентификаторов в дереве — ✅ зелёный

Техбаза: UUID и два адреса в `curl` → заглушки стража, строка с рабочей директорией удалена.

и карточка B-40: `fan-worksheet-color-200` остаётся (сгенерированное изображение по мотивам,
решение автора 2026-11-05). Попутно сняты упоминания пути машины автора в самом плане B-40 (R6
распространяется и на него).

**Готово:** полный прогон стража без исключений и нарушений; typecheck + lint + test зелёные.
Коммит `chore(b-40): U3 …`.
