## Сессия 1 — реализация

Ветка `feat/b-45-inspector-v2` от `main` `1d01510`. Вход: handoff и мок автора
(`docs/design/mock/ui-improvement/`), три решения при внедрении (ссылка «о проекте» под
логотипом, «Собрать документ» в слот инспектора, точка в свёрнутой строке ДЕТАЛЕЙ).

### U1. Токены — ✅ зелёный

`--duration-section`, `--ease-section`, `--size-beta` в блоке `:root` и таблицах дизайн-системы,
`tokens.css` через `tokens:sync`, имена в `motion.ts`. Коммит `3eb93d6`.

### U2–U3. Инспектор и тулбар — ✅ зелёный

Пункты ПРОВЕРКИ переведены в данные (`CheckItem` в `InspectorCheck.tsx`; `pairsChecks`,
`blankChecks`, `straightChecks`, пункт порядка) — свёрнутая строка ДЕТАЛЕЙ знает про точку без
рендера списка (KTD-4). Первичная кнопка — проп `primary` (`kind`, `disabled`, `title`,
`onClick`), подпись считает инспектор по числу документов. Подвал — `AppMark` (геометрия
`icon-small.svg` без c2pa-метаданных, цвета значка литералами), ссылка, `beta-badge`. Тулбар
отдал `onSave` / `onAssemble` / `saved` / позицию, взял `hasEdits` / `revertDisabled` /
`onRevert`. Тесты (около десяти файлов): позиция страницы — счётчик статусбара «N из M»,
документ — текущий в списке инспектора (`getByRole('button', { current: true })`), кнопки —
по имени, где и были. Коммит `007b68e`.

**Отклонение от плана (осознанное):** при пустой ленте ДЕТАЛЕЙ нет, а с ними — и ПРОВЕРКИ:
прежний пункт «Наборы пусты: все страницы удалены» при всех удалённых страницах больше не
показывается; о пустых наборах говорят лента («Все страницы удалены») и причина у «Собрать
документ». Записано в UI_SPEC §6.4.

### U4. Движение секций — ✅ зелёный

`useInspectorMotion` (KTD-1…3): секции по `data-section`, замер `offsetHeight` до и после
отмены идущих анимаций, класс `inspector__section--resizing` на время движения, спейсер
`inspector__spacer` на месте ушедшей секции, `hidden` тела ДЕТАЛЕЙ по `finish` с проверкой,
что секция всё ещё закрыта. React Compiler lint: запись в ref — только внутри эффекта,
возврат скролла — отдельной функцией. Тест `EditorInspector.motion.test.tsx` на `stubAnimate` и
стабе высот по `data-section` (идущая анимация — «видимая» высота по классу). Коммит
`2a555f7`.

**Проба живьём** (`out/`, эмулятор `pass-12 --sheets 3 --http`, изолированный каталог,
`--lang=ru-RU`, CDP, замеры таймером каждые 12 мс):

| Фаза        | Высота секции, px | Класс и overflow          | Тело ДЕТАЛЕЙ                                      | Стрелка  |
| ----------- | ----------------- | ------------------------- | ------------------------------------------------- | -------- |
| раскрытие   | 41 → 443 за ~255  | resizing, hidden до конца | показано сразу, opacity 0 → 1 с ~70 мс            | 0 → 180° |
| свёртывание | 443 → 41 за ~250  | resizing, hidden до конца | видимо, opacity 1 → 0 к ~115 мс, `hidden` в конце | 180 → 0° |

Раскладка: секции `details → docs → footer` (страницы ровные — ВЫРАВНИВАНИЯ нет), «Сохранить
документ» последним элементом секции на всю ширину (267 px при 299 px секции), тулбар справа
пуст; после поворота — плашка «Есть ручные правки — Вернуть» без фона и рамки, точка
`edits-blink 1.2s`; подвал — монограмма, «Duplexn't · о проекте ↗», BETA 22 px.

**Правки автора на приёмке (2026-11-04):** подвал передизайнен в два шага — сначала логотип-ссылка
и плашка BETA рядом по правому краю без текстовой ссылки, затем одна плашка «D’ BETA»:
монограмма без плитки (`AppMark plate={false}`, плитка значка и есть `--color-bg-inverse`) и
текст на общем инверсном фоне, плашка целиком — ссылка на проект (`aria-label` «Duplexn't · о
проекте», `title` прежний); ключ `inspector.about` остался именем ссылки, без стрелки.

**Правка автора на приёмке (2026-11-04), секция ВЫРАВНИВАНИЕ:** заголовок остаётся, текст снят,
кнопка во всю ширину как «Сохранить», подписи «Вернуть оригинал» / «Выровнять»; у страниц без
действия (ровная, не померить, в обработке, отложено) и у выделения без подходящих секции нет.
`straightNoteText` и `straightSelectionText` с их ключами удалены; текст модалки `revert`
говорит «и возврат оригинала» вместо «и выбор «Оригинал»».

## Правка автора после merge — тулбар (2026-11-05, ветка `feat/toolbar-details`)

Автор: правая зона тулбара без плашки правок — «дыра» с границами. Сделано по его трём пунктам
(handoff, раздел «Правки автора 2026-11-05»): плашка правок — в центр тулбара справа; строка
ДЕТАЛИ — в правую зону с пунктирной линией, тело раскрывается в инспекторе; «+ Новый документ с
этой страницы» — по центру средней зоны (центр — сетка из трёх колонок).

Реализация: состояние `detailsOpen` и `id` тела поднялись из `EditorInspector` в `EditorScreen`
(строка и тело — в разных компонентах); пункты ПРОВЕРКИ считает экран (`inspectorChecks`) —
по ним и точка в строке тулбара, и подраздел в теле. `EditorToolbar` получил проп `details`
(`ToolbarDetails`), центр — `.editor-screen__doc` / `.editor-screen__sets` в первой колонке,
`.editor-screen__split` во второй, `.edits-bar` в третьей. Секция ДЕТАЛЕЙ в инспекторе: поля — у тела, линия
только пока тело видно (`:has(> .details:not([hidden]))`) — так на время свёртывания, когда хук
держит тело открытым, геометрия не прыгает (с полями на секции живой замер показал ступеньку
25 px в конце); свёрнутая секция — 0 px, и хук играет `0 → h`. Живой замер центра в окне
1084 px: кнопка границы и плашка правок в равных крайних колонках наезжали друг на друга —
правая колонка стала `minmax(max-content, 1fr)`, средняя `minmax(0, auto)` с обрезкой подписи
кнопки; центрирование точное, пока хватает места. Поворот стрелки — CSS-переходом (`.details-toggle__arrow`, общий с модалкой `save`),
блок WAAPI для стрелки из `useInspectorMotion` снят. Дубль handoff'а `ui-improvement.md`
(старое имя `2026-11-inspector-v2.md`, остался после переименования) удалён.

Решения при внедрении: без ленты строка ДЕТАЛИ остаётся, но `disabled` (зона не пустеет);
«стр. N» в строке сохранён; в режиме наборов счётчики — в левой колонке, плашка правок справа.
Тесты: `EditorScreen.test.tsx` — новый тест размещения; `EditorInspector.motion.test.tsx` —
высоты `0 → 300` и отсутствие WAAPI у стрелки; пустая лента — строка недоступна
(`EditorScreen.edits.test.tsx`); поиск строки `within(inspector)` → `screen` в тестах
пустых и выравнивания.
