## Сессия 1 — реализация

Ветка `feat/b-45-inspector-v2` от `main` `88c3707`. Вход: handoff и мок автора
(`docs/design/mock/ui-improvement/`), три решения при внедрении (ссылка «о проекте» под
логотипом, «Собрать документ» в слот инспектора, точка в свёрнутой строке ДЕТАЛЕЙ).

### U1. Токены — ✅ зелёный

`--duration-section`, `--ease-section`, `--size-beta` в блоке `:root` и таблицах дизайн-системы,
`tokens.css` через `tokens:sync`, имена в `motion.ts`. Коммит `1304888`.

### U2–U3. Инспектор и тулбар — ✅ зелёный

Пункты ПРОВЕРКИ переведены в данные (`CheckItem` в `InspectorCheck.tsx`; `pairsChecks`,
`blankChecks`, `straightChecks`, пункт порядка) — свёрнутая строка ДЕТАЛЕЙ знает про точку без
рендера списка (KTD-4). Первичная кнопка — проп `primary` (`kind`, `disabled`, `title`,
`onClick`), подпись считает инспектор по числу документов. Подвал — `AppMark` (геометрия
`icon-small.svg` без c2pa-метаданных, цвета значка литералами), ссылка, `beta-badge`. Тулбар
отдал `onSave` / `onAssemble` / `saved` / позицию, взял `hasEdits` / `revertDisabled` /
`onRevert`. Тесты (около десяти файлов): позиция страницы — счётчик статусбара «N из M»,
документ — текущий в списке инспектора (`getByRole('button', { current: true })`), кнопки —
по имени, где и были. Коммит `31deb42`.

**Отклонение от плана (осознанное):** при пустой ленте ДЕТАЛЕЙ нет, а с ними — и ПРОВЕРКИ:
прежний пункт «Наборы пусты: все страницы удалены» при всех удалённых страницах больше не
показывается; о пустых наборах говорят лента («Все страницы удалены») и причина у «Собрать
документ». Записано в UI_SPEC §6.4.

### U4. Движение секций — ✅ зелёный

`useInspectorMotion` (KTD-1…3): секции по `data-section`, замер `offsetHeight` до и после
отмены идущих анимаций, класс `inspector__section--resizing` на время движения, спейсер
`inspector__spacer` на месте ушедшей секции, `hidden` тела ДЕТАЛЕЙ по `finish` с проверкой,
что секция всё ещё закрыта. React Compiler lint: запись в ref — только внутри эффекта,
возврат скролла — отдельной функцией. Тест `EditorInspector.motion.test.tsx` на `stubAnimate` и
стабе высот по `data-section` (идущая анимация — «видимая» высота по классу). Коммит
`fb6a5b3`.

**Проба живьём** (`out/`, эмулятор `pass-12 --sheets 3 --http`, изолированный каталог,
`--lang=ru-RU`, CDP, замеры таймером каждые 12 мс):

| Фаза        | Высота секции, px | Класс и overflow          | Тело ДЕТАЛЕЙ                                      | Стрелка  |
| ----------- | ----------------- | ------------------------- | ------------------------------------------------- | -------- |
| раскрытие   | 41 → 443 за ~255  | resizing, hidden до конца | показано сразу, opacity 0 → 1 с ~70 мс            | 0 → 180° |
| свёртывание | 443 → 41 за ~250  | resizing, hidden до конца | видимо, opacity 1 → 0 к ~115 мс, `hidden` в конце | 180 → 0° |

Раскладка: секции `details → docs → footer` (страницы ровные — ВЫРАВНИВАНИЯ нет), «Сохранить
документ» последним элементом секции на всю ширину (267 px при 299 px секции), тулбар справа
пуст; после поворота — плашка «Есть ручные правки — Вернуть» без фона и рамки, точка
`edits-blink 1.2s`; подвал — монограмма, «Duplexn't · о проекте ↗», BETA 22 px.
