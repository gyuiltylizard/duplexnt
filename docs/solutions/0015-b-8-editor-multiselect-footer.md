## Сессия 1 — реализация

План прошёл ревью трёх рецензентов: связность, выполнимость, дизайн. В план до старта вошли:

- недостающие файлы с «Снять» (`EditorScreen.sets.test.tsx`, `selection.ts`);
- обёртка кнопок панели выделения рендерится только при «Выделить в документ»;
- Esc из подвала переводит фокус на миниатюру (KTD-7);
- `flex-wrap` у строки переключателей;
- удаление прежних ключей `toggleTitle.off` / `on`;
- компромисс видимости сведений (KTD-6).

### U1. Тулбар: split только при одной странице — ✅

`canSplitHere` в `EditorScreen.tsx` получил условие `selection.keys.length <= 1`. Тест в
`EditorScreen.dnd.test.tsx` прогоняет сценарий: одна страница → Shift → Ctrl-снятие → Shift →
Esc.

**Готово:** typecheck, lint, тесты экранов зелёные. Коммит `feat(b-8): U1 …` (`363a4ee`).

### U2. Панель выделения без подсказки и «Снять» — ✅

- `editor.selection.text` — «Выделено {{count}} стр.». Ключ `selection.clear`, кнопка,
  `RailSelection.onClear`, CSS `.rail__selection-clear` и его `:focus-visible` удалены.
- `.rail__selection-actions` рендерится только при «Выделить в документ»: в режиме наборов в
  панели один `<p>`.
- Esc в `railKeyDown`: если фокус в `.rail__footer` и выделено больше одной, `focusKey`
  ставится на текущую. Это логика удалённого `onClear`. Мутационная проверка: без переноса
  тест подвала падает (фокус на `body`).
- Комментарий и название теста `collapsed` — «Esc» вместо «Снять».

**Готово:** typecheck, lint, тесты renderer зелёные. Коммит `feat(b-8): U2 …` (`83fbca1`).

### U3. Подвал в одну строку — ✅

- `EditorRailFooter`: строки переключателей в `.rail__toggles`. Счётчик и цель — `span.visually-hidden`
  с id `blank-count` и `rotate-target` (`aria-describedby`); сведения — и в `title` строки.
- Тексты:
  - «Пустые», «Обороты на 180°»;
  - `toggleTitle.off_*` / `on_*` с числом через формы множественного числа;
  - `rotateBacksTitle` начинается с «Действует на {{target}}.»;
  - все шесть отсылок «добавить пустые» в локали — «Пустые».
- CSS: `.rail__toggles` (`flex-wrap: wrap`, `gap --space-5 --space-10`), `.toggle-row__count`
  удалён.
- Тесты: подвал — одна строка в порядке «Пустые» → «Обороты на 180°», описания скрыты, `title`
  с числом и целью, `on` после включения, «не найдено» и «оцениваются…», режим наборов — один
  тумблер. Имя чекбокса 180° в шести тестовых файлах — «Обороты на 180°». Негативная проверка
  тоста в `App.blank.test.tsx` — на новом тексте.

**Готово:** typecheck, lint, `vitest src` (106 файлов, 2001 тест) зелёные. Коммит
`feat(b-8): U3 …` (`0edf509`).

### U4. Доки, референс, смоук — ✅

- UI_SPEC → «Подвал ленты (M4, S4–S6; B-8)»: две строки, скрытые описания и `title`, порядок
  Tab без «Снять»; «добавить пустые» → «Пустые» по всему документу.
- DESIGN_SYSTEM:
  - описание `--color-text-on-inverse-muted` — ghost-пара инверсной кнопки, токен оставлен
    (KTD-5);
  - панель выделения и переключатель — строка `.rail__toggles` без видимого счётчика;
  - `tokens:sync` — без изменений.
- `npm run design:snapshot` — обновились `reference/index.html` и `reference/app.css`.
- Агентский CDP-смоук `temp/smoke-b8.mjs` на эмуляторе, сценарий с пустыми оборотами:
  - собранное приложение — зелёный;
  - подвал одной строкой, 34 px;
  - описания не видны (0×0);
  - `title` «Скрыто 3 пустых оборота…» и «Действует на обороты основного документа…»;
  - кнопка split пропадает при выделении двух;
  - панель — «Выделено 2 стр.» и «Выделить в документ»;
  - Esc — фокус на миниатюре 4л, кнопка split вернулась;
  - консоль чистая;
  - снимки подвала — `temp/b8-footer-*.png`.
