## Сессия 1 — реализация

### U1. Индикатор ожидания — ✅

- `ScanScreen`: лента обёрнута в `.scan-screen__slot`; пока `strip` пуст — `ScanWait` (три
  точки, `role="status"`, «Ждём первую страницу»). «Пуст» считается по страницам прохода
  (`passPages`): на оборотах и в наборе точки заново, при досканировании лента сразу с прежними
  страницами.
- Уход — `useLeavingWait` рядом с `useLeavingCard`: `leaveWithGhost` + `animate`
  `opacity 1 → 0` за `--duration-fast` `--ease-standard`, и под reduced-motion тоже (KTD-3).
- CSS по handoff'у; reduced-motion — в общем блоке экрана.
- Ключ `scan.strip.waiting` (KTD-1).
- Второй `role="status"` на экране сломал два теста с `getByRole('status')` — счётчик теперь
  берётся первым из `getAllByRole`.
- Тесты:
  - точки до первой страницы в одном слоте с лентой, снятие с первой страницей;
  - досканирование без точек;
  - обороты набора — точки заново;
  - уход копией 150 мс `ease`, `inert` и `aria-hidden`, под reduced-motion и без WAAPI.

**Готово:** typecheck, lint и `vitest src` (106 / 2014) зелёные. Коммит `feat(b-9): U1 …`
(`4e5f101`).

### U2. Доки, референс, смоук — ✅

- UI_SPEC → `scan`, «Ожидание первой страницы»; DESIGN_SYSTEM → «Экран scan»; пометка в
  handoff'е о ключе и способе ухода.
- `design:snapshot`: обновились стили референса. Сцены с пустой лентой в референсе нет — точек
  на картинке нет.
- Агентский CDP-смоук `temp/smoke-b9.mjs`: эмулятор, 3 листа, задержка страницы 1,5 с.

**Грабли — точки нулевой ширины.** Смоук по геометрии показал: слот шириной 0, точки по 0 px
через каждые 4 px. Причина — экран выравнивает детей по центру (`align-items: center`), пустая
лента ширины не даёт, а точки в слоте с `position: absolute; inset: 0` сжимаются (`flex-shrink`).
jsdom раскладку не считает, тест этого не видит. В CSS handoff'а то же самое: в макете ширину,
видимо, давала лента. Исправление:

- у слота `align-self: stretch` (во всю ширину экрана);
- у точек `flex: none`;
- смоук проверяет размер точек 6 × 6.

После правки слот 996 px, точки 6 px с шагом 10. Снимок — `temp/b9-wait-*.png`.

Итог смоука:

- точки до первой страницы, «Ждём первую страницу»;
- с первой карточкой сняты, копия ушла за 400 мс;
- слот 74 → 74 px;
- на оборотах точки снова;
- консоль чистая.

**Гейт:** typecheck, lint, format:check и `test:all` зелёные: 118 файлов / 2286 тестов,
интеграция 20 / 208 (4 пропущены). Смоук зелёный и в `dev` под StrictMode. Коммит
`docs(b-9): U2 …`.
