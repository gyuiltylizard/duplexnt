# Модалка: скроллбар на время анимации высоты (журнал)

Замечание автора 2026-11-04: в модалке `device` при раскрытии «Дополнительно» окно растёт, и
справа на секунду появляется скроллбар. Та же природа, что у модалки `add` в B-44 (там сводку
убрали по другой причине, скроллбар ушёл попутно). Плана нет: один класс в `Modal`, одно правило
CSS, тест движения. ADR нет. Ветка `fix/modal-resize-scrollbar`.

## Причина

`Modal` при смене содержимого анимирует высоту окна от прежней к новой за 200 мс (B-4, KTD-4), а
тело окна `.modal__body` — `overflow: auto`. Пока высота едет, содержимое выше окна, и тело
честно показывает полосу прокрутки — до конца анимации. Проба на `out/` до фикса не снималась,
но замер после (ниже) показывает перехлёст содержимого до 60 px в первые кадры — ровно то, что
тело раньше прокручивало.

## Что сделано

1. **`Modal`:** на время анимации высоты окно несёт класс `modal--resizing`; снимается по
   `finish` / `cancel` только той анимацией, что ещё текущая (событие отмены приходит
   асинхронно, уже после старта следующей), и сразу при отмене в эффекте без замены. Класс — прямо
   на элементе через `classList`: состояние React перерисовало бы окно и тем же эффектом
   перезапустило анимацию. React переписывает `className` только при его смене, поэтому класс
   переживает рядовые рендеры; при смене `className` снаружи эффект ставит его заново.
2. **CSS:** `.modal--resizing .modal__body { overflow: hidden }` в `app.css`, рядом с телом.
3. **Тест движения** (`Modal.motion.test.tsx`): класс стоит, пока анимация идёт, снимается по
   `finish`; рендер поверх идущей анимации отменяет её, и класс снят вместе с отменой.
4. **UI_SPEC**, таблица движения: «тело окна на это время без прокрутки».

## Проверка живьём

`out/`, изолированный каталог, `--lang=ru-RU`, CDP: модалка `device`, клик «Дополнительно»,
замеры таймером каждые 12 мс:

| t, мс  | класс | overflow тела | перехлёст содержимого, px | ширина скроллбара |
| ------ | ----- | ------------- | ------------------------- | ----------------- |
| 13–191 | есть  | hidden        | 60 → 0                    | 0                 |
| 205+   | нет   | auto          | 0                         | 0                 |

Скроллбар не появляется ни в одном кадре; после анимации тело снова `auto` — длинная модалка
на низком окне прокручивается, как прежде. `requestAnimationFrame` для замеров не годится:
окно без фокуса, Chromium придерживает кадры (первый пришёл через 750 мс), таймер — нет.
