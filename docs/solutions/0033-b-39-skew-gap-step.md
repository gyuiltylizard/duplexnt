# B-39 — Дыра опоры детектора наклона: ступень вместо прямой (журнал)

Находка автора на приёмке 2026-11-01: из трёх листов детектора пустых одинаковой структуры
(шапка сверху, большая цифра и слово FRONT в середине, блок текста снизу) `p01-s01-0001`
выровнен, а `p01-s01-0006` и `-0007` — «наклон строк не сходится». Плана нет — правка в одной
функции детектора, критерий — таблица фикстур (прецедент — [solution 0030](0030-skew-shape-tolerance.md)).
ADR нет. Вторая смена детектора после [solution 0029](0029-b-19-straighten-versions.md):
выправленные страницы прежнего детектора пересчитываются фоном, `derived/` руками не чистится.

## Диагноз

Сканы — из `session/pages/` (по правилу «находки с живого — по JPEG, не по скриншоту»), боевым
`measureSkewJpeg`, оценки — из кэша `derived/<сессия>/skew/`:

- у всех трёх чернила только в двух кучках: шапка (u ≈ 0,06–0,15) и блок текста (u ≈ 0,77–0,90);
  цифра и FRONT в середине дают полосы с уверенностью 1–2,4 при пороге 3 — не считаются. Дыра
  опоры 0,63 высоты > `MAX_SUPPORT_GAP` 0,4 → профиль прямой по двум узлам (u = 0 и 1) со
  строгим порогом остатка 0,1°;
- физически же веер — ступень: верх под одним углом, низ под другим, перелом около цифры.
  Прямая через две кучки внутри каждой кучки наклонена на «наклон × полуширина кучки», и
  остаток растёт с веером — строгий порог режет именно сильный веер;
- 0001 прошёл случайно: при 50 мм внизу валидной осталась одна полоса (вторая — уверенность
  2,88 < 3), прямая легла на одну точку, остаток сверху 0,085 едва уложился в 0,1. У 0006 и 0007
  внизу валидны обе, полоса на u ≈ 0,77 даёт остаток 0,15–0,19;
- прямая к тому же экстраполировалась до краёв листа: у 0001 профиль +1,10° / −0,49° при
  измеренных +0,92° / −0,27° — края перекручены, контраст ×1,95 это скрыл.

Пересчёт по измеренным полосам (50 мм):

| Лист | Верх (полосы) | Низ (полосы)  | Остаток прямой | Остаток ступени | Исход до правки     |
| ---- | ------------- | ------------- | -------------- | --------------- | ------------------- |
| 0001 | 0,88 / 0,95   | −0,27         | 0,085          | 0,035           | выровнен            |
| 0006 | 0,53 / 0,51   | −0,67 / −0,64 | 0,158          | 0,030           | «не по чему мерить» |
| 0007 | 0,97 / 1,01   | −0,52 / −0,47 | 0,196          | 0,042           | «не по чему мерить» |

**Штриховка не ловушка.** Строгий порог для прямой был введён против фикстуры `fan-graphic`
(журнал 0030: при общем пороге 0,2° она выправлялась ×2,31 — «плохо»). Разбор полос показал: это
настоящий веер — текст сверху +0,97°, текст снизу −0,15°, косая штриховка в середине
отбрасывается по уверенности 2–3,5. Остаток прямой 0,144° — тот же эффект модели, что у листов
автора; остаток ступени 0,02°. После коррекции оба текстовых блока 0,00° (уверенность 40–150),
рамка прямоугольная (глазами — `docs/output/b-39-fan-graphic-straightened.jpg`). Чистого
отличителя между штриховкой и листами автора по полосам нет (доля чернил, согласие половин
одинаковые), и он не нужен. Решение автора 2026-11-01: принять — штриховка выправляется.

Проба «профиль ступенью» (в каждой кучке константа — взвешенное среднее): остаток по повторному
измерению у `sheet-digit` 0,52 мм против 0,54 у узлов — выигрыша нет, а `sheet-front` уходит в
`notImproved` (×0,98). Узлы остаются.

## Исправление

- `src/core/detect/skew.ts` → `fitProfile`: профиль — всегда узлами по полосам (за крайними —
  константа); остаток формы — min(остаток гладкого семейства, остаток ступени) и при дыре опоры
  тоже; гладкое семейство при дыре — прямая (квадратике не на что опереться), допуск —
  строгий `SHAPE_RESIDUAL_MAX_DEG` 0,1°, при плотной опоре — `SHAPE_RESIDUAL_DENSE_MAX_DEG` 0,2°.
  Прямая по двум узлам u = 0 и 1 убрана. `SKEW_DETECTOR_VERSION` 5 → 6.
- Результат на сканах автора (30 мм, по целым): 0001 — остаток 0,046°, веер 4,11 мм, ×3,26;
  0006 — 0,076°, 4,07 мм, ×5,30; 0007 — 0,099°, 5,15 мм, ×5,97 (у 0007 запас до порога 0,001°;
  запасной проход 50 мм дал бы ступень 0,04° — вторая страховка). Таблица фикстур: исходы всех
  прежних сканов без изменений, кроме `fan-graphic` → `willStraighten` 30 мм ×2,73, веер 3,87 мм;
  профили листов с дырой опоры (`fan-sparse`, `sheet-*`) теперь узлами внутри кучек — веер
  4,87 / 3,06 / 3,30 мм вместо 5,74 / 3,91 / 4,20 по экстраполированной прямой; после коррекции
  `level`, 0,31–0,38 мм.
- Фикстура `sheet-digit-color-200` — лист 0007 байт в байт из `docs/input/` (baseline JPEG без
  EXIF / ICC / XMP, 3 канала, 200 dpi; печатная страница проекта без личных данных); таблица
  ожиданий; тест «дыра опоры (B-39)»: у `fan-sparse`, `sheet-*`, `fan-graphic` разрыв опоры >
  `MAX_SUPPORT_GAP`, остаток ≤ 0,1°, узлы профиля — ровно на валидных полосах, θ в пределах
  измеренных углов (экстраполяции нет), веер > 2 мм. Закрепы «штриховка — `unmeasurable` /
  `shape`» в трёх тестах переписаны; причина `shape` у фикстур больше не встречается.
- `test/integration/straighten.test.ts`: после коррекции лист со штриховкой целиком «не
  измерить» — сдвинутая штриховка даёт ложные углы −0,6…−0,9° с уверенностью 3,8–4,5, а текст
  сверху и снизу 0,00°; страж R24 судит по уверенным полосам (≥ 2× `CONFIDENCE_MIN`, не меньше
  `MIN_BANDS`): max|θ| 0,002°, веер 3,87 → 0,01 мм. Допуск веера после коррекции при дыре опоры —
  1 мм, как у половин и запасного прохода: две кучки по 3–4 полосы, узлы ложатся на шум каждой
  полосы (±0,08° у полос с уверенностью 6–8), `sheet-digit` после коррекции `level`, веер 0,54 мм
  при прежнем допуске 0,5.
- Техбаза: п. 4 гейтов (дыра опоры → ступень и узлы, детектор v6), заметки спайка и «Две
  колонки», «Предел метода» (сама штриховка не измеряется — лист выправляется по тексту);
  README фикстур; `bugs.md`.
