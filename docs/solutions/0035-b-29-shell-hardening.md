## Сессия 1 — оболочка, страж, ADR 0008

### U1. Схема интерфейса — ⏳ в работе

**Спайк на `out/`** (первый шаг, до остального кода): схема `duplexnt-app` с привилегией только
`standard`, без `secure`. Итог на собранном приложении с эмулятором, два прохода, 6 страниц:

- документ — `duplexnt-app://app/index.html`, origin `duplexnt-app://app`, `isSecureContext`
  = `false`;
- модульный скрипт Vite с `crossorigin`, стили и шрифты (Golos Text, IBM Plex Mono — `woff2`
  относительными адресами `./assets/…`) загружаются; `'self'` в CSP им достаточно;
- миниатюры и полная страница с `duplexnt-page` показываются (не смешанное содержимое, потому
  что страница не на «безопасной» схеме); ошибок CSP, консоли и сети нет;
- API безопасного контекста интерфейсу не нужен — `secure` не берём (KTD-1 подтверждён);
  `corsEnabled`, `supportFetchAPI`, `codeCache` не понадобились. Привилегии `duplexnt-page` не
  менялись.

**Реализация.** `src/main/app-protocol.ts`: константы схемы, привилегии литеральным типом (как у
`page-protocol.ts`), `resolveAppFile` и `handleAppRequest` с инъекцией чтения файла. Правила:
только `GET`; хост `app`; без userinfo, порта и строки запроса; **любой `%` и `\` в пути —
отказ** (имена сборки — ASCII без спецзнаков, поэтому раскодировать нечего: `%2e%2e`, `%252e`,
`%2f`, `%00`, `%20` отклоняются одним правилом, а путь без `%` равен своему раскодированному
виду); сегмент — `[A-Za-z0-9_-]+(\.[A-Za-z0-9_-]+)*` (отсекает `.`/`..`, пустые сегменты,
хвостовую точку и пробел, `::$DATA`, букву диска); тип — по белому списку ровно того, что кладёт
сборка (`html`, `js`, `css`, `woff2`, `woff`); второй рубеж — путь строго под каталогом с
разделителем после корня. Ответ: `nosniff`, `no-store`; любой отказ и ошибка чтения — 404.
`src/main/index.ts`: обе схемы в одном `registerSchemesAsPrivileged` до `ready`, обработчик — в
начале `start()` до первого окна, `loadRenderer` вне dev-сервера зовёт `loadURL` схемы;
`loadFile` больше нет.

Грабли спайка тестов: разборщик URL нормализует путь до обработчика — `./` схлопывается,
хвостовой пробел снимается, адрес без пути под Node даёт пустой `pathname` (в Chromium — `/`).
Это принятые случаи, а не обход: проверки идут по уже нормализованному пути.

**Тест сборочного CSP (B-28)** — `test/integration/build-csp.test.ts`: сборка во временный
каталог (`electron-vite build --outDir`, ~3,5 с), мета-тег ровно равен `buildCsp({profile:
'build'})` и он единственный, профиля dev нет; плюс связка со схемой — каждый файл сборки
`resolveAppFile` умеет отдать (новый тип ассета не станет молча 404 в упакованном приложении),
а ссылки `index.html` относительные и указывают на существующие файлы.
