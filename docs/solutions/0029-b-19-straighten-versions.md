## Сессия 1 — реализация

**Отклонение от плана (осознанное): порядок юнитов U2 → U1 → U3.** Контракт U1 (факт с
`detector` / `stale`) заполняется из `StraightenedFile.detector` и `isCurrentStraightened`, которых
до U2 нет; typecheck на границе U1 без хранилища не прошёл бы. Содержание юнитов — по плану.

### U2. Раскладка и хранилище — ✅ зелёный

`layout.ts`: `straightFileName` / `straightRecordName` с обеими версиями, основа имени у детектора
«неизвестен» (`UNKNOWN_DETECTOR = 0`, константа здесь, а не в `straightened.ts`, — её читает
строитель имени) — прежний формат без `.d`; `parseStraightFileName` обоих форматов (явный `.d0` —
не имя пары); шаблоны `STRAIGHT_FILE` / `STRAIGHT_THUMB_FILE` обоих форматов — потребители
`removeByPrefix` в `reconcile.ts` и `session-store.ts` без правок (находка ревью плана).
`straightened.ts`: схема записи с необязательным `detector` и сверкой имени; `isCurrentStraightened`;
пары каталога — по листингу (`pairsIn`), предпочтение — текущая, затем по убыванию геометрии и
детектора; `load` убирает негодные и лишние пары сверх выбранной (пересчёт, прерванный до чистки,
не копится); `store` пишет текущую пару рядом и убирает прочие известной геометрии
(`retireOthers`, под `hold` — в отложенные); `discard`. `thumbnails.ts`: кэш под именем самого
JPEG, `stillWanted` сверяет обе версии, прочие миниатюры ключа — по листингу (перебор
`1 … version − 1` с детектором невозможен). Грабли: `prefer-optional-chain` на цепочке условий
листинга — переписано ранними выходами. Тесты: `straightened.versions.test.ts` переписан (пять
сценариев: прежняя геометрия, чужой детектор, две пары при открытии + «от будущего» + сирота,
`discard` без и под `hold`, вложенные `hold`); миниатюры, `reconcile` и `session-store` — оба
формата имён в чистке. Коммит `98379ce`.

### U1. Контракт — ✅ зелёный (с оговоркой)

`StraightenFact` + `detector`, `stale`; `StraightenMark` + `detector`, `recalc`
(`STRAIGHTEN_RECALC`); `withFile(input, fact)` считает `recalc` из `stale` и `deferred`;
`PageImageRef` + `detector`; `pageImageUrl(…, version, detector)` — сегмент `<g>.<d>`,
`page-protocol.ts` разбирает его (`VERSIONS`, детектор от нуля); `straightenFactsOf` — `detector`
и `stale` через `isCurrentStraightened`; `EditorThumb` / `EditorRail` — пропсы `straightDetector`
/ `straightRecalc`. Литералы фактов и пометок дополнены в 14 тестах (ядро, renderer, эмулятор).
Табличный тест статуса — семь новых строк (пересчёт ждёт / отложен / откат / ровная / текущий
файл без исхода). **Оговорка:** коммит `8a32e9c` ушёл при двух красных файлах node-проекта
(литералы имён `.v1` в тестах службы и очереди, по плану — U3); гейт `npm test` зелёный с U3.

### U3. Очередь и факты — ✅ зелёный

`needs()` через `hasCurrent` (`isCurrentStraightened`); `retire(key)` в `enqueue`: вердикт
текущих версий не «выправлять» при паре — `discard` → `onChange`; детектор в дайджесте снимка
пакета. Тесты очереди: пересчёт пар чужого детектора и прежнего формата (новая пара рядом,
прежняя убрана), снятие по вердикту `level` / `unmeasurable` сразу и под `hold`, `abort` посреди
пересчёта — прежняя пара на месте; факты `stale` для трёх видов не текущих пар; дайджест по
детектору. `npm test` 143 / 2557. Коммит `f5a1406`.

### U4. Renderer — ✅ зелёный

`useLateStraighten`: порция по `recalc === 'pending'`, импорт `STRAIGHTEN_GEOMETRY_VERSION` убран;
запись порции хранит `before` и `recalc` по странице; отложенные (`disk` / `fail`) порцию не
держат и при закрытии выходят из неё — порция из одних отложенных тоста не даёт, смешанная даёт
«пересчитано — выровнено ещё N» только по впервые выровненным (R9). `straightNoteText`: у
`straightened` с `recalc` `disk` / `fail` — `inspector.straight.note.recalc.*`. Тест хука
переписан без подмены модулей (шесть сценариев), тест текстов — строки и сводка выделения без
учёта `recalc`; экран — строка инспектора с кнопкой «Оставить оригинал», адрес карточки меняется
версией детектора. UI_SPEC 6.10 «Поздние статусы» — здесь же (R10: текст в существующей секции,
мок не нужен). `npm test` 143 / 2563. Коммит `5916e7c`.

### U5. Эмулятор — ✅ зелёный

`straighten-detector.emulator.test.ts`: подмена `SKEW_DETECTOR_VERSION` модулем
`src/core/detect/skew` (литерал в фабрике — `vi.mock` поднимается, внешние константы недоступны);
«вчерашняя» сессия — переименование пар на прежний детектор или прежний формат без поля, кэш
оценок на прежний детектор. Четыре сценария: (1) × 2 формата — прежний вид с `recalc: 'pending'`,
`pending: 0`, сохранение прежним файлом, пересчёт фоном, записи с новым детектором, журнал тот
же, повтор пакета `batchStale`; (3) новый детектор ставит «ровная» (обёртка исполнителя по
размеру страницы) — пара убрана, `level`; (4) пакет, пока коррекция стоит у ворот, — PDF из
прежних байтов, затем новая пара. Хелперы `straightJpegOf` / `straightRecordOf` в
`test/support/straighten.ts`; литералы `.v1` / `.v2` в четырёх эмуляторных тестах — на них;
тест смены геометрии — пометки с `detector` и `recalc`. Грабли: `straightened.test.ts` не
попал в список литералов `.v1` плана (имена через `${V}`), поправлен здесь; проверка пометки сразу
после открытия в сценарии «ровная» была гонкой с мгновенным измерением — снята. Гейт на ветке:
`npm test` 143 / 2563, `test:integration` 32 / 280 (+ worst-case 3 / 5), typecheck, lint,
format:check зелёные. Коммит `a2797de`.
