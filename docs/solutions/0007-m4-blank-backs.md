## Сессия 1 — фикстуры с живого ET-3850, детектор и калибровка

### U1. Фикстуры детектора с живого ET-3850 — ⏳ в работе

Инфраструктура готова, сканы — за автором (снимает спайком `escl-job-trace.mjs` по списку из
чата, по одному листу на запуск с `--wait-loaded`). `test/support/fixtures.ts`: `SCANS_DIR`,
`SCAN_NAME` (`<что>-<gray|color>-<dpi>`), `scanFixture`, `scanFixtureNames`, `pageFixtureOf`
(номер синтетической страницы или имя скана — для PDF из смешанных лотков). Эмулятор:
`TrayEntry = number | string`, имена сканов проверяются при загрузке сценария и перезарядке
(`traysOf`), а не при подаче. Guard `test/guards/scan-fixtures.test.ts` разбирает сегменты
заголовка JPEG без `sharp`: ни EXIF, ни ICC, ни XMP, ни Photoshop/Adobe, имена по конвенции.
README фикстур дополнен. Тест «лоток по именам» в `server.test.ts` красный до появления
`blank-gray-300.jpg` — осознанно, как сигнал.

**Отклонение от плана (осознанное):** скрипт импорта `scripts/import-scan-fixture.ts` не
пишется (FYI doc-review): ET-3850 отдаёт baseline JPEG без метаданных — копия и guard.

### U3. Режим пустых оборотов: настройка, команда, ряд `setup`, журнал v6 — ✅ зелёный

Сделан раньше U2, пока автор снимает фикстуры (от U1–U2 не зависит). `src/shared/blank.ts`
(`BLANK_MODES`, `DEFAULT_BLANK_MODE = 'hide'`); `SessionEdits.notBlank`, `EMPTY_EDITS`,
`sameEdits`; `Snapshot.blankMode` (настройка) и `SessionSnapshot.blankMode` (сессия);
команда `setBlankMode` (мост, preload, схема `z.enum(BLANK_MODES)`, обработчик, служба —
принимается без сканера, пишет настройки и шлёт снимок). Настройки v3: `settingsV2Schema`
оставлена для чтения, `parseSettings` поднимает v1 и v2 с режимом по умолчанию. Журнал v6:
`journalV5Fields`/`journalV5Schema` для чтения, `upgradeToV6` (`blankMode: 'keep'`,
`notBlank: []`), `newJournal` — `keep` (то же получает пересобранный сверкой журнал);
`beginPass(origin, intent, blankMode = 'keep')` замораживает режим, когда проход открывает
сессию (новый журнал или повторное использование пустого); служба передаёт
`settings.get().blankMode`. `normalizeEdits`: `notBlank` — уникальные живые ключи,
удалённая страница пометку сохраняет; порядок ключей результата — как у `EMPTY_EDITS`
(сверка сравнивает журнал по сериализации — иначе переписывала бы файл при каждом запуске).
`hasEdits` считает пометку правкой. Ряд «Пустые обороты» в `setup` — на `Segments`, доступен
и без сканера (настройка приложения, не устройства); «Сбросить параметры» шлёт и
`DEFAULT_BLANK_MODE`. Локаль: `setup.params.blank*`.

**Грабли:** литералы снимков и правок в ~25 тестовых файлах — типобезопасные дополнены
по `tsc`, нетипизированные (внутри `journalOf(..., {edits: {...}})`) ловились только
падением сверки «journalRebuilt»; журналы-сиды старых версий (`journalV4Of` и ниже) строятся
из текущего вычитанием полей — при подъёме версии вычитать надо и новые поля.

**Готово:** typecheck/lint/format/`npm test` (кроме теста лотка по именам) и
`test:integration` зелёные. Коммит `feat(m4): U3 …` (`6a895be`).

**U1 закрыт** после сканов автора (2026-10-22): одиннадцать сканов перенесены из
`local-test-data/device/trace/` в `scans/` под именами меток, байт в байт; страж (полный
прогон) и guard метаданных зелёные; тест лотка по именам зелёный. Коммит `feat(m4): U1 …`
(`b808dfa`).

### U2. Детектор пустых страниц — ✅ зелёный

`src/core/detect/blank.ts`: чистая `inkRatioOf({data, width, height})` — гистограмма
обрезанной области (поля `MARGIN_RATIO` 4 %), белое бумаги — перцентиль `PAPER_WHITE_PERCENTILE`
0.9 снизу, чернила — темнее белого на `INK_DELTA` 40; `isBlank(ratio)` — ниже `BLANK_THRESHOLD`
(ориентир 5e-4), `null` — не пусто; `blankRatio(bytes, pixelLimit)` — `sharp`: маркеры JPEG,
`metadata` и предел пикселей как у миниатюр, `greyscale` → `resize` до длинной стороны
`WORKING_LONG_SIDE` 1400 внутри → `raw`; сбой — `null`. `BLANK_DETECTOR_VERSION = 1`.
Тип `BlankDetector` — для инъекции в службу (U4). Юнит-тест (`npm test`) — синтетические
серые массивы: чистый и серый лист, блок внутри полей, тень по кромке, порог дельты,
вырождение, вердикт на границе. Интеграционный `test/integration/blank-detector.test.ts` —
табличный по именам сканов (`blank-*`/`bleed-*` → пусто; `pencil-*`/`text-*`/`signature-*`/
`punched-*` → пусто; `pencil-*`/`text-*`/`signature-*` → не пусто), печатает доли и требует
двукратного запаса; синтетическая страница с цифрами — не пусто, битый JPEG и не JPEG —
`null`, предел ниже размера — `null`.

**Калибровка на сканах (2026-10-22), доли чернильных пикселей при ориентирах KTD2 — ни одну
константу менять не пришлось:**

| Скан                     | Доля    | Класс    |
| ------------------------ | ------- | -------- |
| `blank-gray-200/300`     | 0       | пусто    |
| `blank-color-300`        | 0       | пусто    |
| `blank-gray-600`         | 8.5e-7  | пусто    |
| `bleed-gray-300`         | 9.4e-6  | пусто    |
| `punched-gray-300`       | 6.6e-5  | пусто    |
| `pencil-faint-gray-300`  | 3.04e-3 | не пусто |
| `pencil-faint-color-300` | 3.01e-3 | не пусто |
| `text-line-gray-300`     | 3.08e-3 | не пусто |
| `signature-gray-300`     | 3.19e-3 | не пусто |
| `text-gray-300`          | 4.84e-2 | не пусто |

Порог 5e-4: в 7,6 раза выше худшего пустого (дырокол) и в 6 раз ниже лучшего непустого
(бледный карандаш); запас между классами 45× при требуемых 2×. Подавление одиночных точек не
понадобилось.

**Отклонение от плана (осознанное):** в плане (U2, Test scenarios) дырокол отнесён к «не
пусто» — ошибка: чистый лист с дырками дырокола и есть пустой оборот, который пользователь
хочет скрыть. В таблице `punched-*` — класс «пусто».

**Готово:** typecheck/lint/format/`npm test`/`test:integration` зелёные. Коммит
`feat(m4): U2 …` (`bc51646`).
