# B-24 — токены проходов по ролям и «ПУСТО» в доке (журнал)

Пункт бэклога B-24 после разбора 2026-11-01: контраст серых токенов ушёл в B-36 («Только по
жалобам»), остались расхождения дизайн-системы с кодом. Плана нет — переименование токенов и
правка доки, значения цветов не меняются. ADR нет: развилки нет, схема данных не затронута.
Чинится до любого handoff'а Claude Design — он работает по `DESIGN_SYSTEM.md`.

## Диагноз

- **Цвета проходов.** Дока задавала `--color-pass-1/2/3` как «проходы 1–2, 3–4, 5+», а код
  с M3.5 красит по ролям: `pass-1` — кромка лица в иллюстрации сборки `merge`; `pass-2` — тег
  «об» на миниатюре и кромка оборота; `pass-3` — тег «Д1» на миниатюре, тег набора на `scan` и
  `merge`, кикер набора на `flip`. Выбора цвета по номеру прохода в коде нет нигде (ни одного
  вычисляемого класса) — расхождение только в доке и в именах.
- **Тег на миниатюре.** Дока описывала плашку из макета (`top/left`, фон `--color-pass-N`, текст
  `on-accent`), код — цветной текст в подвале карточки (mono, `--font-size-xxs`,
  `--tracking-wide`).
- **«ПУСТО».** С M4 на `--color-text-subtle` (решение автора), дока писала `text-faint` в трёх
  местах: таблица токенов, раздел миниатюры, открытый вопрос о контрасте.

## Исправление

- Токены по ролям — словами ядра (`fronts` / `backs` / `added`): `--color-pass-fronts` (accent),
  `--color-pass-backs` (amber-600), `--color-pass-added` (violet-600). Блок `:root` в
  `DESIGN_SYSTEM.md` — источник правды, `tokens.css` — `npm run tokens:sync`; пять CSS-файлов
  renderer'а, три упоминания в `UI_SPEC.md`.
- `DESIGN_SYSTEM.md`: строка таблицы цветов перечисляет роли и места; тег в подвале миниатюры
  описан как в коде; «ПУСТО» — в строке `text-subtle` и в разделе миниатюры (пилюля на
  `--color-bg-paper`); открытый вопрос «Янтарный в двух ролях» — на новом имени и с тегом «об»;
  открытый вопрос о контрасте ссылается на B-36 вместо «Входящих».
- Handoff'ы, брифы и архив макета (`docs/design/handoffs/`, `briefs/`, `archive/`) не
  трогались — исторические артефакты на момент утверждения.
- Референс Claude Design переснят (`npm run design:snapshot`): кроме переименований в нём
  накопленный дрейф прошлых правок UI (снимок был старше) — производное, перезаписывается.

**Гейт:** typecheck, lint, format:check, `npm test` 143 / 2564 зелёные; снимок `design` 11 / 11.
Смоук: значения токенов не менялись, вид экранов тот же по построению. Коммит `7575c6a`.
