# Лендинг — страница проекта на GitHub Pages

Адрес: `https://gyuiltylizard.github.io/duplexnt/`. На него ведёт бейдж BETA в подвале инспектора
(`PROJECT_PAGE_URL` в `src/main/index.ts`) и ссылки из README. Статический сайт без сборки,
передан дизайном готовым (B-40); правится руками, тест `test/tooling/landing.test.ts` держит
ссылки и файлы в порядке.

## Где что лежит

```
docs/
  index.html         страница целиком: разметка, инлайновые стили, английский текст
  .nojekyll          Pages отдаёт файлы как есть, без сборки Jekyll
  assets/
    js/locales.js    переводы (сейчас — русский) по ключам data-i18n из index.html
    js/main.js       выбор языка, карусель, раскрывашки роадмапа, история версий, пасхалка
    img/             скриншоты editor/setup, картинка «Мотивация», значок
    fonts/           Golos Text и IBM Plex Mono локально (без CDN) + fonts.css
```

GitHub Pages раздаёт **весь каталог `docs/`** с ветки `main` (Settings → Pages → Deploy from a
branch → `main` / `/docs`): спека, журналы и прочие `.md` тоже доступны по прямым адресам как
сырые файлы — это нормально, репозиторий публичный. Входная точка — `docs/index.html`; все пути
внутри относительные, поэтому сайт работает и из подпапки `/duplexnt/`.

## Два языка

- Английский текст — прямо в `index.html`; его видят поисковики и браузеры без JavaScript.
- Русский — в `assets/js/locales.js` под теми же ключами, что в атрибутах `data-i18n`,
  `data-i18n-html` (строки с разметкой) и `data-i18n-attr` у элементов `index.html`.
- Язык выбирается до отрисовки: параметр `?lang=ru` / `?lang=en` → выбор, сохранённый
  переключателем → язык браузера (`ru*` → русский, остальное → английский). Пока подставляется
  перевод, страница скрыта, не дольше 3 секунд.

Правка текста: английский — в `index.html`, русский — в `locales.js` под тем же ключом. Новый
элемент с текстом получает новый ключ в обоих местах.

## Что обновлять на каждом релизе

1. **История версий** (`<section id="changelog">`): новая версия сверху — дата и список
   изменений по-английски в `index.html`, перевод под ключами `versions.N.*` в `locales.js`;
   прежняя первая версия уезжает в «earlier versions».
2. **Роадмап** (`<section id="roadmap">`): закрытые пункты и новые — по `docs/roadmap.md`.
3. **Скриншоты** `assets/img/editor.webp` и `setup.webp`, если интерфейс менялся заметно.
4. **Кнопки «Скачать»** ведут на `https://github.com/gyuiltylizard/duplexnt/releases` — на список
   релизов: у GitHub `/releases/latest` показывает последний не-pre-release, а до `1.0.0` все
   сборки — beta. При выходе `1.0.0` обе кнопки перевести на `/releases/latest`. Прямой ссылки на
   `.exe` на лендинге не бывает: скачивание — только со страницы Releases, рядом с
   `SHA256SUMS.txt`.

## Правила

- Файлы лендинга в `.prettierignore`: форматер переставил бы инлайновые стили и JS. Не
  форматировать, не минифицировать заново.
- Страж приватности проверяет лендинг только по списку значений (паттерны UUID/адресов вне его
  области) — примеры адресов, если понадобятся, только из документационных диапазонов
  (`192.0.2.x`).
- Pages на Linux чувствителен к регистру имён файлов — тест сверяет регистр ссылок с файлами.
- Новых внешних ресурсов (CDN, аналитика, шрифты с чужих серверов) не добавлять.
