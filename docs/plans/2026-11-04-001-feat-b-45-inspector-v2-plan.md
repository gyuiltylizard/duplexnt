# feat: инспектор v2 и тулбар `editor` (B-45)

## Summary

Перекомпоновка правой колонки экрана `editor` по прототипу автора (handoff
`docs/design/handoffs/2026-11-inspector-v2.md`, мок `docs/design/mock/ui-improvement/`,
утверждён 2026-11-04; решения при внедрении — в том же handoff'е): ПРОВЕРКА уходит внутрь
ДЕТАЛЕЙ, первичная кнопка («Сохранить…» / «Собрать документ») — под ДОКУМЕНТЫ В НАБОРЕ на всю
ширину, плашка «Есть ручные правки» — в правую зону тулбара с мигающей точкой, точка «не
сохранено» и позиция «документ N из M · стр. K из L» из тулбара убираются, подвал инспектора —
логотип, ссылка на проект и плашка BETA, высоты секций инспектора анимируются. Поведение
(гарды, команды, undo, тосты) не меняется — только раскладка, показ и движение.

## Problem Frame

Правая колонка выросла по вехам: ПРОВЕРКА — отдельная секция под документами, плашка правок —
подвал инспектора, первичная кнопка — в тулбаре далеко от списка документов, к которому
относится. Автор собрал прототип, где действие стоит у своего объекта, служебный блок ПРОВЕРКА
спрятан в ДЕТАЛИ, а состояние «есть правки» занимает освободившийся правый слот тулбара.
Снимок «до»: `docs/design/reference/index.html#editor` на `1d01510`.

Вопросы handoff'а сняты разбором с автором 2026-11-04 (handoff, «Решения при внедрении»):
ссылка «о проекте» остаётся под логотипом; «Собрать документ» — в тот же слот инспектора;
свёрнутые ДЕТАЛИ при точке в ПРОВЕРКЕ несут янтарную точку; ПУСТОЙ ОБОРОТ остаётся и
анимируется; длительность и кривая — токенами; точка «не сохранено» уходит без замены.
Развилок уровня ADR нет.

## Requirements

**Инспектор**

- R1. Порядок секций: ДЕТАЛИ (внутри после `dl.facts` — подраздел ПРОВЕРКА с кикером и
  прежними пунктами) → ПУСТОЙ ОБОРОТ → ВЫРАВНИВАНИЕ → ДОКУМЕНТЫ В НАБОРЕ → подвал. Отдельной
  секции ПРОВЕРКА нет (handoff, «Что изменилось»).
- R2. ПРОВЕРКА видна только при раскрытых ДЕТАЛЯХ (`hidden` вместе с телом). Пока в ней есть
  хоть один пункт с точкой, в свёрнутой строке ДЕТАЛЕЙ перед «стр. N» стоит `dot dot--warning`
  с `title` «В проверке есть замечания»; при раскрытых точки нет (решение 3).
- R3. Последний элемент секции ДОКУМЕНТЫ В НАБОРЕ — первичная кнопка на всю ширину: вне
  режима наборов «Сохранить документ» / «Сохранить N файлов» (недоступна при пустой ленте),
  в режиме наборов «Собрать документ» с прежними причинами недоступности в `title`
  (решение 2). Тексты и правила — прежние (handoff, «Placement»).
- R4. Плашки правок в инспекторе нет. Подвал (`margin-top: auto`): слева логотип 22 px
  (монограмма D’ инлайн-SVG по `build/icon-small.svg`), под ним ссылка «Duplexn't · о проекте
  ↗» (B-42, поведение прежнее); справа плашка BETA 22 px по рецепту handoff'а (решение 1).
- R5. Инспектор — колонка, секции `flex-shrink: 0` (handoff, CSS).

**Тулбар**

- R6. Правая зона: при `assembly.hasEdits` — `.edits-bar` на всю ширину зоны без подложки и
  рамки: мигающая `dot dot--warning`, текст слева, «Вернуть» справа (`btn--tinted`,
  `disabled` при `locked`, открывает `revert`); без правок зона пуста. Кнопок сохранения и
  сборки и точки «не сохранено» в тулбаре нет.
- R7. Центр: метка и название документа, кнопка «+ Новый документ с этой страницы» как прежде;
  `.editor-screen__doc-pos` убран. Режим наборов по центру — без изменений.

**Движение (handoff, «Motion»)**

- R8. Высота секций инспектора анимируется от прежней к новой за `--duration-section`
  (240 мс) по `--ease-section` (`cubic-bezier(0.4, 0, 0.2, 1)`), `overflow: hidden` на время
  анимации, замер `offsetHeight`. ДЕТАЛИ: раскрытие — высота + проявление тела с задержкой ¼;
  свёртывание — тело видимо до конца, гаснет за 60 %, `hidden` в конце; стрелка
  поворачивается. ПУСТОЙ ОБОРОТ и ВЫРАВНИВАНИЕ: появление `0 → h` с проявлением, смена текста
  `h1 → h2`, исчезновение — спейсер `h → 0` на месте секции. Скролл инспектора сохраняется.
- R9. Мигание точки правок — `--duration-loop` / `--ease-loop`. Под `prefers-reduced-motion`
  анимаций высоты нет, точка не мигает; без WAAPI (jsdom) интерфейс в каждом кадре как без
  анимации (правила B-4).

**Доступность и прочее**

- R10. `.edits-bar` — `role="status"`, точка `aria-hidden`; ПРОВЕРКА — `h3` под `h2` секции;
  порядок Tab: ДЕТАЛИ → (ПУСТОЙ ОБОРОТ) → ВЫРАВНИВАНИЕ → документы → первичная кнопка →
  ссылка на проект. BETA — текст, не интерактивна.
- R11. Токены `--duration-section` и `--ease-section` — в блоке `:root` дизайн-системы и в
  таблице движения; `tokens.css` — через `npm run tokens:sync`.
- R12. Локали ru/en: новый ключ `inspector.detailsWarning` («В проверке есть замечания»);
  ключи `editor.saveFiles`, `editor.save`, `editor.assemble`, `editor.edits.*`,
  `inspector.checks`, `inspector.about*` переиспользуются; `editor.docPosition` /
  `editor.pagePosition` удаляются, если больше нигде не нужны.

## Key Technical Decisions

- **KTD-1. Высота секций — один хук на инспектор, без состояния React.** `useInspectorMotion`
  в `useLayoutEffect` после каждого рендера сверяет `offsetHeight` секций (по ключу секции) с
  прошлым замером и запускает WAAPI-анимации поверх конечного состояния — по образцу анимации
  высоты `Modal` (B-4, KTD-4) и мока (`animateInspector`). Класс/стиль `overflow: hidden`
  ставится на время анимации прямо на элемент. Отклонено: состояние открытия в CSS-переходах
  `max-height` — рывки на неизвестной высоте и конфликт с `hidden`.
- **KTD-2. Свёртывание ДЕТАЛЕЙ с видимым телом.** Пока высота едет, `hidden` на теле не
  ставится: React рендерит тело с `hidden`, хук на время анимации снимает атрибут и возвращает
  по `finish`. Это единственное место, где показ расходится с разметкой на 240 мс; под
  reduced-motion и без WAAPI — сразу `hidden` (R9).
- **KTD-3. Уход секции — спейсер.** Исчезнувшая секция (ПУСТОЙ ОБОРОТ, ВЫРАВНИВАНИЕ) заменяется
  `aria-hidden` спейсером прежней высоты, который схлопывается и удаляется, как в моке.
  Отклонено: ghost-копия узла (`leaveWithGhost`) — здесь нужна только высота.
- **KTD-4. Предупреждения ПРОВЕРКИ — данными.** Пункты собираются функцией
  `checksOf(t, assembly)` → `{ warning, node }[]`, чтобы свёрнутая строка знала «есть точка»
  без рендера списка. Отклонено: дублировать условия в двух местах.
- **KTD-5. Первичная кнопка — в инспекторе одним слотом.** `EditorInspector` получает
  `primary: { kind: 'save' | 'assemble', label, disabled, title?, onClick }` от экрана; тулбар
  теряет `onSave` / `onAssemble` / `saved`. Гарды и команды остаются в экране.
- **KTD-6. Логотип — React-компонент `AppMark`** с геометрией `icon-small.svg` (без
  c2pa-метаданных), `aria-hidden`, размер токеном `--size-beta` = 22 px. Отклонено: импорт
  SVG-файла как ассета — байты мастера с метаданными в бандле.

## High-Level Technical Design

Только renderer: `EditorScreen` (пропсы), `EditorToolbar` (правая зона, центр),
`EditorInspector` (структура, ПРОВЕРКА внутри ДЕТАЛЕЙ, первичная кнопка, подвал),
`EditorInspectorStraight` (без изменений поведения), новый `useInspectorMotion`, новый
`AppMark`, CSS `editor-screen.css`, токены в `DESIGN_SYSTEM.md` → `tokens.css`,
`state/motion.ts` (новые имена токенов). Ядро, мост и снимок не меняются.

## Scope Boundaries

Вне: другие экраны и модалки; поведение команд, гардов и undo; переносимость ширины левой зоны
тулбара при 1280 px («Новое сканирование» не помещается — известно и до v2, handoff
«Открыто»). **Deferred to Follow-Up Work:** частичное сохранение (бэклог, «Входящие»).

## System-Wide Impact

Референс дизайна перегенерируется (сцены `editor`, `save`, `add`, `newscan`, `mismatch`).
Снимок, мост, ядро — без изменений. Локали: один новый ключ, два удаляемых.

## Risks & Dependencies

- Анимация высоты против React-рендера (отмена при новом рендере, `hidden` на теле) —
  де-рискуется тестом движения и живой пробой на `out/` (CDP, замер таймером, как в 0042).
- `flex-shrink: 0` на секциях — проверить прокрутку длинного инспектора при низком окне.

## Acceptance Examples

- AE1. Редактор с двумя документами: справа в тулбаре пусто, под ДОКУМЕНТЫ В НАБОРЕ —
  «Сохранить 2 файла» на всю ширину; клик открывает `save`.
- AE2. Поворот страницы: в тулбаре справа появляется «● Есть ручные правки — Вернуть», точка
  мигает; «Вернуть» → `revert`; после отката плашка исчезает.
- AE3. Свёрнутые ДЕТАЛИ в режиме «Скрывать» с найденными пустыми: янтарная точка перед
  «стр. N»; раскрытие — ПРОВЕРКА под фактами, точки в строке нет, высота едет плавно.
- AE4. Переход с выровненной страницы на ровную: ВЫРАВНИВАНИЕ схлопывается, ДОКУМЕНТЫ
  поднимаются плавно; обратно — секция вырастает с проявлением.
- AE5. Режим наборов (проходы не сошлись): под ДОКУМЕНТЫ В НАБОРЕ «Собрать документ»
  недоступна с «Не хватает 1 оборота»; после уравнивания — доступна, сборка как прежде.
- AE6. Подвал: логотип, под ним «Duplexn't · о проекте ↗» (открывает браузер), справа BETA.
- AE7. `prefers-reduced-motion`: ДЕТАЛИ раскрываются скачком, точка правок не мигает.
