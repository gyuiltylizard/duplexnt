# feat: Английская локаль интерфейса (B-41)

## Summary

Вторая локаль интерфейса — английская, до первого публичного релиза: публичная витрина (B-40)
без английского интерфейса бессмысленна. Перевод всех строк в `locales/en/common.json`, язык как
настройка приложения (файл настроек v5 → v6), выбор по умолчанию из системной локали, тот же
язык в main-процессе, смена языка сразу без перезапуска, переключатель на `setup` по
утверждённому handoff'у. Одна поездка к Claude Design: переключатель и ревью английских текстов
по референсу, который умеет рендериться на обоих языках. Входы: карточка B-41, решения автора
2026-11-03, исследование кода и журналов 2026-11-03.

## Problem Frame

Каркас под вторую локаль есть с M0: `i18next`, типизированные ключи от русской локали,
плюрализация через `Intl.PluralRules`, алиас `@locales`, запрет импорта локалей в ядро и preload
линтером. Перевода и выбора языка нет. Снимок «до», сверен с кодом 2026-11-03:

- `locales/ru/common.json` — 724 листовых ключа, 31 группа плюралей (`_one/_few/_many/_other`);
  ~65 строк с `{{count}}` без форм (русский обходит склонение через «стр.»); тегов `<Trans>`
  нет, подстановки `{{…}}` в 279 строках. Карточка называла «707 строк, 124 группы» — это цифры
  аудита текстов, не ключи;
- `src/renderer/src/i18n.ts` инициализируется синхронно с `lng: 'ru'`; `resources` держит одну
  локаль; тест `i18n.test.tsx` ждёт `Object.keys(resources)` равным `['ru']`;
- типы ключей выводятся из русской локали (`types/i18next-resources.d.ts`): расхождение ключей
  английской локали typecheck не поймает;
- настройки (`src/core/storage/settings-store.ts`, `SETTINGS_VERSION = 5`) не знают языка;
  читает их ядро внутри `openPassService`, main к файлу не обращается;
- main импортирует русскую локаль напрямую для одного диалога — «хранилище не читается»
  (`src/main/index.ts`, `storageUnreadable`), который показывается до открытия настроек;
- референс дизайна `test/design-snapshot/reference.test.tsx` рендерит сцены только по-русски:
  ожидания по русским литералам, `<html lang="ru">`, один выходной каталог
  `docs/design/reference/`;
- 33 jsdom-файла с 566 запросами по русским литералам.

Решения автора 2026-11-03: переключатель — через бриф → мок → утверждение, одной поездкой с
ревью английских текстов; сначала перевод и язык в настройках без переключателя; по умолчанию
`ru*` → русский, иначе английский; смена языка применяется сразу; строки `new Error('…')` в ядре
остаются русскими; README на двух языках — в B-40; jsdom-тесты идут на русском.

## Requirements

**Локаль и тексты**

- R1. `locales/en/common.json` несёт перевод каждого ключа русской локали; набор базовых ключей
  (без суффиксов плюралей) и набор подстановок `{{…}}` в каждой строке совпадают с русской
  локалью в обе стороны, и это держит тест.
- R2. Английские плюрали — формы `one/other`; там, где русская строка обходится без форм, а
  английская их требует, суффиксы добавляются только в английской локали.
- R3. Данные пользователя не переводятся; имя документа по умолчанию («Документ N» / «Document
  N») — плейсхолдер, не хранится и считается из текущего языка при показе и при сохранении;
  имя, введённое пользователем, — данные, при смене языка не меняется.
- R4. Тесты на коды ошибок, причины, запрет рабочих терминов и плюрали идут по всем локалям;
  jsdom-тесты продолжают идти на русском.

**Язык как настройка**

- R5. Язык хранится в файле настроек версии 6; файлы версий 1–5 читаются и поднимаются
  значением «не выбран», файл переписывается только при следующей записи.
- R6. Язык по умолчанию: системная локаль с префиксом `ru` → русский, любая другая →
  английский; определяет main, ядро Electron не импортирует.
- R7. Явный выбор переживает перезапуск и не зависит от смены системной локали; «Сбросить
  параметры» язык не трогает.
- R8. Смена языка применяется сразу: интерфейс перерисовывается без перезапуска, `<html lang>`
  обновляется; уже показанные тосты не переводятся задним числом. Диалогов main после старта
  сегодня нет; появятся — берут язык из снимка службы.
- R9. Диалог «хранилище не читается», который показывается до чтения настроек, идёт на языке
  системной локали по правилу R6.

**Интерфейс и дизайн**

- R10. Переключатель языка на `setup` реализован по утверждённому handoff'у; до него в
  интерфейсе нет способа сменить язык — он определяется правилом по умолчанию, а для живых
  проверок — ключом `--lang` или записью в файл настроек.
- R11. Референс дизайна рендерится на обоих языках из одного прогона в один каталог, сцены
  ищутся не по русским литералам; русский референс остаётся эталоном раскладки.
- R12. Английская копия прошла ревью дизайн-агента по референсу; правки внесены в
  `locales/en/common.json`.
- R13. Смоук экранов на английском пройден на `out/` и на установщике: узкие места раскладки,
  мерянные под русский (тулбар редактора 2 × 130 px, кнопка состояния выравнивания 128 px,
  модалки `device` и `save`), без переполнений — переполнение в этих местах блокирует merge;
  прочие находки раскладки вне списка AE5 идут в `docs/bugs.md`.

**Документы**

- R14. Спека («Локализация», таблица стека, «На будущее»), `docs/design/README.md` (интерфейс
  больше не «один — русский»), UI_SPEC (пометка о локали, русская копия остаётся контрактом),
  бэклог и журнал обновлены.

## Key Technical Decisions

- KTD-1. **В файле — `language: 'ru' | 'en' | null`, где `null` значит «следовать системе».**
  Эффективный язык считает ядро: `stored ?? systemDefault`, а `systemDefault` main передаёт
  опцией при открытии службы. Так старые файлы поднимаются без записи (как прежние миграции),
  «следовать системе» остаётся семантикой, а не потерянным фактом, и ядро не трогает Electron.
  Отклонено хранение резолва при первом запуске: оно записывало бы файл при чтении и
  замораживало язык у тех, кто системную локаль поменял.
- KTD-2. **Словарь языков — в `shared`** (`LOCALES = ['ru', 'en'] as const`, `Locale`) по
  образцу `BLANK_MODES` / `STRAIGHTEN_MODES`; схема `z.enum(LOCALES)` в ядре; тот же словарь
  типизирует `resources` в `i18n.ts`.
- KTD-3. **Язык едет в снимок** (`Snapshot.language` рядом с `blankMode` и `straightenMode`),
  команда `setLanguage` — по чеклисту ADR 0005 (карта в `shared`, схема в ядре, preload,
  обработчик, `stubApi`). Новое поле снимка трогает все фикстуры снимков по репо.
- KTD-4. **Renderer применяет язык из снимка до первого кадра.** `App` и так ждёт снимка;
  хук у корня в `useLayoutEffect` (не `useEffect` — тот отработал бы после первого кадра, и
  не в теле рендера — React предупредит об обновлении чужих компонентов) зовёт
  `i18n.changeLanguage` синхронно (ресурсы вшиты, `i18n.language` меняется сразу) при каждом
  изменении `snapshot.language` и ставит `document.documentElement.lang`. `i18n.ts` по-прежнему
  стартует с `ru`: это держит 33 jsdom-файла и `makeSnapshot` по умолчанию с `language: 'ru'`.
- KTD-5. **Main без i18next.** Main импортирует обе локали и выбирает объект по языку одной
  функцией. Единственный диалог со строками сегодня — `storageUnreadable`, и он идёт по
  системной локали (`app.getLocale()` доступен внутри `start()`, после `ready`). Правило на
  будущее: диалог main после старта берёт язык из `service.snapshot().language`; кода «на
  вырост» не пишем. Заголовок окна и `<title>` — бренд `APP_NAME`, не локализуются.
- KTD-6. **Паритет локалей — тестом, не типами.** Типы ключей остаются от русской локали;
  тест сравнивает базовые имена ключей после снятия суффиксов плюралей в обе стороны и набор
  подстановок `{{…}}` в каждой паре строк. Английские суффиксы там, где русский без форм, —
  законны: i18next при `count` ищет `key_one/_other` и падает на `key`.
- KTD-7. **Один референс на оба языка.** Генератор рендерит каждую сцену дважды, с
  `changeLanguage` между прогонами, и пишет в тот же `docs/design/reference/` одну
  `index.html` с переключателем `RU | EN` (атрибут `data-lang` у сцен); ассеты (CSS, шрифты,
  картинки страниц) общие. Ожидания сцен — через `i18n.t(...)` по ключу, подписи сцен — по
  ключам. Отклонён второй каталог: он удвоил бы картинки и сломал правило «папка отдаётся
  дизайн-агенту целиком».
- KTD-8. **Переключатель — только по handoff'у** (правило «новый UI — сначала мок»). До него
  интерфейс живёт на языке по умолчанию; это не блокирует перевод, настройку и референс.
  Контрол-кандидат — `Segments` «Русский · English» в ряду приложения на `setup`; названия
  языков не переводятся. Решает мок.
- KTD-9. **Строки ядра остаются русскими.** `new Error('…')` в `src/core` и `src/shared` —
  ошибки программы на языке проекта, до пользователя доходят только текстом неожиданного сбоя.
- KTD-10. **Даты и единицы не меняются:** `Intl.DateTimeFormat('sv-SE')` для ISO-штампа в
  имени документа, «dpi», «мм»/A4 — строки локали или константы.

## High-Level Technical Design

Выбор языка при запуске и при переключении:

```mermaid
sequenceDiagram
  participant Main as main
  participant Core as PassService / SettingsStore
  participant UI as renderer (App)
  Main->>Main: app.getLocale() → systemDefault (ru* → ru, иначе en)
  Main->>Core: openPassService(dataRoot, { systemDefault })
  Core->>Core: settings v1–v5 → language null; v6 → как записано
  Core-->>Main: snapshot { language: stored ?? systemDefault }
  Main->>UI: loadRenderer
  UI->>Core: getSnapshot
  Core-->>UI: snapshot
  UI->>UI: i18n.changeLanguage(language), html lang, первый экран
  UI->>Core: setLanguage('en') (переключатель, U6)
  Core->>Core: settings.update({ language: 'en' }) → файл v6
  Core-->>UI: snapshotChanged → changeLanguage сразу
```

Отказ `storageUnreadable` случается до открытия настроек: main показывает диалог на
`systemDefault`, без обращения к ядру.

- **Тесты:**

  - «Сбросить параметры» не шлёт `setLanguage` (тест `SetupScreen`).
- **Гейт:** typecheck, lint, `npm test`, `test:integration` зелёные. Коммит `feat(b-41): U1 …`.

### U3. Язык в renderer и в main

- **Что:** хук у корня `App` в `useLayoutEffect` применяет `snapshot.language` к i18n и
  `<html lang>` до первого кадра и при каждом изменении; main выбирает объект локали по языку
  одной функцией и показывает `storageUnreadable` по `systemDefault`; резолв `app.getLocale()`
  → `ru|en` одной чистой функцией под тестом.
- **Требования:** R6, R8, R9. **Зависит от:** U1, U2.
- **Файлы:** `src/renderer/src/App.tsx`, новый `src/renderer/src/state/use-language.ts` и тест;
  `src/main/index.ts`, новый `src/main/shell/system-locale.ts` и тест; `src/renderer/index.html`
  (без изменений — `lang` ставится в рантайме).
- **Образец:** `installShortcutGuard` / `debug-guard.ts` — чистая функция с инъекцией `app`;
  `useSyncExternalStore` снимка в `App.tsx`.
- **Тесты:**
  - резолв: `'ru'`, `'ru-RU'` → `ru`; `'en-US'`, `'uk'`, `'de'`, `''` → `en`;
  - хук: снимок с `'en'` → сразу после применения `i18n.language === 'en'` и
    `document.documentElement.lang === 'en'`; смена снимка → смена языка без перезагрузки;
    снимок с `'ru'` (все существующие тесты) ничего не меняет;
  - main: функция выбора объекта локали отдаёт английские строки `startup.*` для `'en'` и
    русские для `'ru'`.
- **Гейт:** typecheck, lint, `npm test` зелёные; живьём на `out/`: `--lang=en-US` → английский
  интерфейс и `lang="en"`, без ключа → русский на русской системе. Коммит `feat(b-41): U3 …`.

  своём языке и с атрибутом `lang` у каждой опции, доступное имя группы из локали, поведение
  при смене (сразу) и на время ожидания команды, «Сбросить параметры» не трогает; (б) ревью
  английской копии по референсу `EN` по всем сценам (`setup`, `device`, `scan` × 2, `flip`,
  `merge`, `editor`, `save`, `add`, `newscan`, `mismatch`): термин-карта, тон, длина в узких
  местах (тулбар 2 × 130 px, кнопка 128 px, модалки, плашка прерванного прохода, подписи
  состояний). Два артефакта от дизайн-агента: handoff переключателя с `## Copy` в колонках
  `ru | en` и правки английской копии списком «ключ → текст». Автор утверждает.
- **Требования:** R10, R12. **Зависит от:** U5.
- **Файлы:** `docs/design/briefs/language.md`, `docs/design/handoffs/`, `docs/design/mock/`.
- **Test expectation:** none — проектная работа.
- **Гейт:** handoff утверждён автором. Без него U6 не начинается. Коммит `docs(b-41): U4 …`.

### U6. Переключатель на `setup` и правки копии

- **Что:** переключатель по handoff'у: ряд или контрол в `SetupScreen`, `setLanguage` через
  мост, состояние из снимка; правки английской копии из ревью — в `locales/en/common.json`
  (русские правки, если дизайн-агент их предложит, — на слово автора, с оглядкой на jsdom-тесты);
  UI_SPEC § 2 — переключатель и пометка о локали; референс перегенерирован.
- **Требования:** R7, R8, R10, R12. **Зависит от:** U4.
- **Файлы:** `src/renderer/src/screens/SetupScreen.tsx` и тест, `setup-screen.css`,
  `locales/ru/common.json` (строки контрола), `locales/en/common.json`, `docs/design/UI_SPEC.md`,
  `docs/design/reference/`.
- **Образец:** ряды «Пустые обороты» и «Выравнивание» на `setup` (`Segments`, `selected` из
  снимка, `onSelect` → команда).
- **Тесты:**
  - переключатель показывает текущий язык из снимка; выбор другого шлёт `setLanguage` один раз
    с нужным значением; повторный выбор текущего не шлёт;
  - отказ команды (`storageFailed`) — тост по существующему пути, язык в снимке прежний,
    выделение остаётся на прежнем языке;
  - на время ожидания команды второй выбор игнорируется (двойной клик шлёт одну команду);
  - «Сбросить параметры» не трогает переключатель (из U1);
  - подписи контрола не переводятся: «Русский» и «English» одинаковы в обеих локалях, у
    каждой опции атрибут `lang` своего языка.
    Переключатель живёт на `setup`, во время прохода этот экран не показывается — смена языка
    посреди прохода невозможна по построению; открытые модалки перерисовываются через `t()`.
- **Гейт:** typecheck, lint, `npm test` зелёные; живьём на `out/`: переключение туда-обратно
  без перезапуска, после перезапуска язык сохранён. Коммит `feat(b-41): U6 …`.

### U7. Документы, смоук в en и закрытие

## Scope Boundaries

Вне этого плана:

- README, витрина и формы Issues на двух языках — B-40;
- третья локаль и выбор языка из меню (меню в упакованном приложении снято);

- перевод jsdom-тестов на ключи локали;
- перекраивание раскладки под английский: русский задаёт раскладку, английский короче;
  находки смоука вне мест, перечисленных в AE5, — в `docs/bugs.md`, не в этот план;
- локаль установщика NSIS: electron-builder выбирает язык мастера по системе сам.

## System-Wide Impact

- **Снимок и фикстуры.** Новое поле `Snapshot.language` меняет все конструкторы снимков по репо
  (16 файлов); `stubApi` приводится `as unknown as Api`, пропажу `setLanguage` typecheck не
  ловит — добавлять руками.
- **Файл настроек.** Приложение до B-41 увидит файл v6 как несовместимый и будет жить на
  дефолтах без записи (KTD-35 M0) — поведение уже описано и покрыто.
- **Референс дизайна.** `index.html` вдвое больше по разметке; картинки и CSS общие. Дизайн-агент
  получает оба языка в одной папке.
- **Имена файлов.** «Document N» вместо «Документ N» в имени PDF по умолчанию на английском —
  строка интерфейса, не данные пользователя (R3).

## Risks & Dependencies

| Риск                                                                         | Де-риск                                                                                                                     |
| ---------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Handoff задерживается                                                        | Сессия 1 от него не зависит; U6 и U7 ждут, перевод и настройка уже в ветке                                                  |
| Ревью дизайн-агента правит русские строки и роняет jsdom-тесты               | Русские правки — только на слово автора, отдельным коммитом с правкой тестов                                                |
| Английское слово без переноса не влезает там, где русская фраза переносилась | AE5: замеры CDP узких мест на `out/`; переполнение в местах AE5 блокирует merge и чинится в U6, вне списка — `docs/bugs.md` |
| `app.getLocale()` до `ready` пуст                                            | Резолв — внутри `start()`; чистая функция трактует пустую строку как `en`                                                   |
| Типы ключей не ловят расхождение en                                          | Тест паритета ключей и подстановок (KTD-6)                                                                                  |
| `changeLanguage` при старте даёт мигание                                     | `useLayoutEffect` до первого кадра — `App` ждёт снимка; ресурсы вшиты, вызов синхронный                                     |

Зависимости: i18next 26.4.2 с `Intl.PluralRules`; Electron 44 — `app.getLocale()` и ключ
`--lang` для смоука.

## Acceptance Examples

- AE1. Чистая установка на английской Windows → первый экран по-английски, `lang="en"`, файл
