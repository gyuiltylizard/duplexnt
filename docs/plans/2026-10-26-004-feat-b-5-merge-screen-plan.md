# feat: редизайн экрана merge (B-5)

## Summary

Экран `merge` по handoff'у Claude Design `2026-10-b5-merge.md` (утверждён автором 2026-10-26):
диаграмма рядов и формулы заменены иллюстрацией «сортировки» (вариант 1b «пары», без лотка),
заголовок «Сопоставляем лица и обороты», одна строка состояния с хвостом про пустые обороты,
тег набора. Логика паузы, ожидание оценок и тексты статуса — прежние.

## Problem Frame

Замечание автора с приёмки M2: диаграмма из рядов лишняя. Бриф `briefs/merge.md`, мок и
handoff — от Claude Design по референсу B-6. Решения автора при планировании (2026-10-26):
сначала B-5, затем B-4; задержку ухода на 600 мс после поздних оценок **не** делаем — итог
дублирует тост редактора.

## Requirements

- R1. Иллюстрация `.sort` в режимах `--ok` (сошлось), `--short` (меньше оборотов, принят
  коротким), `--extra` (лишние обороты), `--fronts` («Обороты не нужны») — разметка, базовые
  стили и раскадровка из handoff'а; под `prefers-reduced-motion` — стоп-кадр 2300 мс.
- R2. Заголовок: «Сопоставляем лица и обороты»; набор — «…набора» и тег «НАБОР ДN» в цвете
  набора; «Обороты не нужны» — «Собираем лицевые стороны».
- R3. Строка состояния: прежние тексты исхода (`merge.status.*`) в `merge-screen__main`, хвост
  пустых оборотов — отдельным `merge-screen__tail` (проявляется при смене); при несовпадении
  (`--short` / `--extra`) — янтарная с точкой. `role="status"`, `aria-live="polite"`.
- R4. Снимаются диаграмма, формулы, подписи рядов (ключи локали — тоже).
- R5. Тайминги, ожидание оценок без потолка, модалка `mismatch`, пометки ленты — без изменений.

## Key Technical Decisions

- **KTD-1. Иллюстрация — внутри `MergeScreen`, стили — `screens/merge-sort.css`** (база `.sort`
  из handoff'а + раскадровка `2026-10-b5-merge.sort.css` как есть). Handoff предлагает
  `components/` и `app.css`, но `feed` и `turn` в коде живут в своих экранах и их CSS —
  держимся кода; отдельный файл — чтобы 1,5 тыс. строк кадров не тонули в стилях экрана.
- **KTD-2. Режим — из той же классификации исхода, что статус** (`assemblyOutcome` для пачки,
  решение и `backsState` для набора): `frontsOnly` → `--fronts`; `fewer` / `accepted` с
  оборотами не больше лиц → `--short`; `extra` и принятый длинный → `--extra`; `ok` → `--ok`.
- **KTD-3. Тег набора — `НАБОР Д{{set}}`** (номер, как у остальных ключей набора), а не
  `{{name}}` handoff'а.
