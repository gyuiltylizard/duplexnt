# Plans

Планы фич и вех — замороженные артефакты решений. Один файл на задачу:
`YYYY-MM-DD[-NNN]-<type>-<slug>-plan.md`, frontmatter `status:` (`в работе` / `заморожен` /
`done`). Завершённый план не удаляется.

Пайплайн: задача берётся из `../backlog.md`, оформляется планом здесь и помечается
«в работе»; по завершении — журнал в `../solutions/`, статус `done`. Правила — в
`../duplexnt.md` → «Процесс».

Если план делает генератор, форму держит он; без генератора — `../templates/plan.md`.

`inputs/` — рукописные брифы и скоуп-контракты автора на вход планированию.
