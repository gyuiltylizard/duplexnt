# plans/inputs — входные брифы автора

Рукописные скоуп-контракты и брифы, подаваемые на вход планированию: «какие пункты входят,
какие решения уже приняты, что вне». Не генерируются агентом; после старта плана —
заморожены (план ссылается сюда как на origin). Имя — свободный `<slug>.md`.

Отличие от `../../input/`: то — локальная inbox без git и без права ссылок; это —
зафиксированный вход, на который ссылаются планы.
