# docs/input — личная inbox-папка (сырьё на разбор)

Сюда закидывается всякое для последующего разбора: заметки, выгрузки, черновики,
скриншоты, куски текста. Содержимое **не под git** (игнорится, кроме этого README) и **не
источник правды** — на файлы отсюда нельзя ссылаться из планов, журналов и бэклога.

Разобрал файл → перенеси результат туда, где ему место, а исходник удали:

- сырая идея → `docs/backlog.md`, раздел «Входящие»;
- баг → `docs/bugs.md`, раздел «Входящие»;
- замороженный вход для планировщика (скоуп-контракт и т.п.) → `docs/plans/inputs/`;
- визуальный референс → `docs/design/`;
- всё остальное — по карте доков (`docs/docmap.md`).
