# Contributing

This project does not accept unsolicited pull requests. Please use
[GitHub Issues](https://github.com/gyuiltylizard/duplexnt/issues) to report bugs, suggest
improvements, or discuss potential changes. Code contributions are accepted by invitation only.

Issues may be written in English or Russian. Two forms are available: a bug report and a
suggestion — pick the one that fits, and fill in what you can.

## Before you attach anything

Issues and their attachments are public and cannot be deleted. Do not attach scans of real
documents. If you share logs, screenshots or scanner responses, replace the device's network
address, serial number and UUID with placeholders — for example `192.0.2.10`,
`X000000000` and `00000000-0000-4000-8000-000000000000`.

## Other devices

Duplexn't talks eSCL and should work with any scanner that supports it, but it has only been
tested on an Epson EcoTank ET-3850. If your issue is about another device, be ready to help with
testing: the maintainer does not keep a collection of multifunction printers.

## Security

Please report vulnerabilities privately through the repository's **Security** tab (_Report a
vulnerability_), not in public Issues.
